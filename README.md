# SPACE Project · v0.5E 정부 산업·섹터 건설구획

HTML/CSS/JavaScript + Three.js 기반 모항성계 게임 프로토타입입니다. 기존 3D 태양계·표면 19개 프리셋을 보존하면서 **정부 건설구획 → 광업 → 행성 정부 원광 재고 → 제련 → 합금**의 게임 시간 기반 산업 루프를 추가했습니다. [v0.5E 구현·잠정 정책·조작](docs/v0.5E/IMPLEMENTATION.md), [검증 기록·스크린샷](docs/v0.5E/VERIFICATION.md), [승인된 초안](docs/v0.5E/REQUEST_KO.md), [UI 보강](docs/v0.5E/UI_SUPPLEMENT_KO.md)을 참고하세요.

## 정부 산업 조작

천체 → 표면 지도 → 섹터를 선택합니다. 왼쪽 정보, 오른쪽 육각형 정부 구획, 오른쪽 하단 생산·소비/행성 재고가 표시됩니다. 빈 구획에서 조건·비용을 확인하고 건설을 지시합니다. 같은 구획을 다시 누르거나 뒤로가기로 일반 정보에 돌아가고 X로 패널을 닫습니다. 모바일 가로 패널 너비는 44.5%, 세로 높이는 43%이며 지도를 계속 조작할 수 있습니다.

정식 시작 재정·재고는 미정입니다. 경제를 임의 지급하지 않으므로 전체 루프 검증은 **로고 5초 내 7회(또는 `?dev=1`) → DEV → 산업 개발 시나리오 열기**를 사용하세요. 별도 캠페인에 지구 100,000 C·합금 10,000 U·수소 500 U와 기존 광석/유한 수소 원천의 조사 상태를 한 번만 제공합니다. 광업을 건설하고 다른 섹터에 제련을 건설한 뒤 DEV의 +30/+180게임일 명령으로 진행을 확인할 수 있습니다. 일반 배속은 기존 0.1~100×입니다.

채굴은 원본을 보존한 별도 잔량을 감소시키고 품질별 lot의 원천·가공 난도를 보존합니다. 광업의 수소 동반회수는 확인된 같은 섹터 유한 원천·실제 광석 채굴이 있을 때만 발생하며 ≤100 U/월입니다. 제련은 수소 없이도 가동하고, 자동 사용 시 처리 속도만 최대 +15%입니다. 수율은 저14/중33/고52%입니다.

캠페인 저장 버튼에서 시계·시설·잔량·재고를 함께 저장/내보내기/검증·백업 후 복원합니다. 정식/개발 저장은 분리되어 있고 손상 저장은 자동 덮어쓰지 않습니다. 시설 증설·구형 장비 개량을 제공하며, 취소·교체·철거는 정책 미정 버튼으로 표시합니다. 운영비·전력·인력도 null입니다. **새 ZIP은 만들지 않습니다.**

## 자원 지질 조작

SPACE 로고5초 내7회 → 천체 선택 → 표면 지도 → **자원**. 기본은 미설정값 보존이며, 다른 시드의 재배치는 전체 ore 교체/초기 인지 이관 여부를 선택하고 미리보기 → 확인 → 원본 백업 → 적용합니다. 7개 검수 지도·개별 매장지/품질/기술 가정·고급 JSON 편집과 Undo를 제공합니다. v0.5C 자동 설정의 지형/인구 작성도 유지합니다.

기본 v2 프리셋은 태양계19개 모두 실제 등록되어 있습니다. **기존 로컬 v1/v2 초안이 우선**하며 자동 덮어쓰기를 하지 않습니다. 자원 패널의 공식 프리셋 불러오기 또는 v1→v2 이관은 별도 미리보기/확인/백업을 거칩니다. 파일 UI에서 두 스키마를 가져오고 현재 버전으로 내보낼 수 있습니다.

지구는 사용자 원본의8893000000명/도시화/지형/환경/시나리오를 보존하고 ore만783억→786억 U로 재배분했습니다. 광맥은 육지·대륙붕 우선, 해양 표면형은 고난도 해저 단괴입니다(수심이 없어 육해혼합 구역으로 대륙붕 근사). [확정 예산·품질과 잠정값](docs/v0.5D/REVIEW.md)을 구분했습니다. 품질별 별도 매장량은 없고 실제 ore를 한 번만 합산합니다. 1 U=10톤, 기본 합금 수율 저14/중33/고52%입니다. 정적 수소 데이터는 유한/대기채집 잠재 공급원입니다. v0.5E의 별도 런타임은 확인된 유한 원천의 부산물 회수와 제련 보조만 운영하며, 대기 채집·함선 연료는 미구현입니다.

지구 육해는 Natural Earth 1:50m Land v5.1.2(Public Domain), 다른 천체 환경·미확정 매장량/초기 인지/달·화성 식민지 수치 등은 게임용 잠정값입니다. [미래 상태 분리 계약](docs/architecture/TERRAFORMING_DATA_CONTRACT.md)을 유지하며 정부 광업·제련 외 민간 경제·성장·테라포밍은 미구현입니다.

## 실행

Node.js 20+와 Python 3가 있으면 별도 패키지 설치나 빌드 없이 실행합니다.

```sh
npm run dev
# http://localhost:5173
```

정적 파일은 `dist/`에 있습니다. ES 모듈이므로 `file://` 대신 HTTP 서버를 사용하세요. Three.js와 OrbitControls는 MIT 라이선스와 함께 저장소에 포함했습니다. 외부 웹폰트를 요청하지 않고 시스템 폰트를 사용합니다.

## 기능과 조작

- 기본 화면은 최소 HUD와 지도입니다. 설정에서 천체 찾기·시점·궤도·이름·자전축·보조 기준 평면을 조절합니다.
- **천체 클릭·터치 → 옆 정보 탭 → 탭의 `확대` 버튼**으로 접근합니다. 선택만으로 자동 확대하지 않습니다. 확대 범위는 천체 또는 주변 궤도를 고릅니다.
- 탭은 대상의 공전과 카메라 이동을 따라갑니다. 화면 가장자리에서 뒤집고 제한하며, 대상이 시야 밖이거나 다른 구체에 가려지면 숨깁니다. 선택은 유지합니다.
- 지도 빈 부분을 누르면 육각 섹터가 선택됩니다. 천체 메시와 작은 천체의 화면 보조 선택이 섹터보다 우선합니다. 그리드 밖·숨긴 그리드의 빈 부분, 탭 닫기, Esc로 선택을 해제합니다.
- 육각형은 **중심→꼭짓점 210 게임 AU**로 모든 항성계에서 같습니다. 필요한 최소 링 수만 늘립니다. 태양계는 3링/37칸입니다.
- 태양·행성 8개·위성 11개·소행성대·카이퍼대, 실제 지도·구름·토성 고리를 유지합니다.
- 시간 일시정지와 0.1×–100× 프리셋, 확대 후 공전 추적을 지원합니다. **1×는 현실 1초당 게임 10초**이며 UTC 시·분·초를 표시합니다. 창을 숨긴 동안에는 시간이 진행하지 않습니다.

| 입력 | 동작 |
|---|---|
| 좌클릭 드래그 / 한 손가락 | 카메라 회전 |
| 우클릭 드래그 / 두 손가락 이동 | 화면 이동 |
| 휠 / 핀치 / 오른쪽 아래 ± | 확대·축소 |
| 천체 메시·이름·설정의 천체 찾기 | 선택과 정보 탭, 궤도 강조 |
| 정보 탭의 확대 | 부드러운 접근 및 천체 추적 |
| 오른쪽 위 섹터 버튼 | 섹터 표시·숨김 |
| H / Esc | 전체 보기 / 선택 해제 |
| Space | 시간 일시정지·재개 (입력·버튼에 포커스가 없을 때) |

모바일 가로 화면이 우선입니다. 개발 검증용 `?dev=1` 또는 로고 제스처를 켜면 개발자 도구에 시험 항성계 전환이 나타납니다. `?dev=1&system=small`은 작은 시험계, `?dev=1&system=wide`는 이동·경사·다중 항성 시험계입니다. 정식 플레이 콘텐츠나 실제 천문 자료가 아닙니다.

## 행성·위성 표면 지도

행성이나 위성을 선택한 후 정보 탭의 **표면 지도**를 누릅니다. 선택만으로는 줌하지 않으며 기존 확대 버튼도 유지합니다. 표면 구역은 지구·금성 92개, 목성 642개, 토성 492개 등 크기 정책에 따라 다르고, 각 격자는 오각형 12개와 나머지 육각형으로 구성됩니다. 기존 위성 11개와 개발 시험계도 같은 기능을 사용합니다. 가스/얼음 거대행성의 격자는 고체 지표가 아닌 대기 기준층입니다.

앞면 구역을 눌러 ID·위경도·면적·이웃을 조회합니다. 텍스처와 격자는 같은 자전 프레임에 붙습니다. 항성계의 210 AU 육각형·행정구역과는 별개의 구면 좌표이며, 표면 진입 중 행정 편집은 종료합니다. 상단 버튼으로 이전 지도에 돌아갑니다.

**개발자 모드:** SPACE 로고를 5초 안에 7회 누르거나 `?dev=1`로 시작합니다. 명시적 종료·재진입이 가능하고 새 탭 기본은 꺼짐입니다. 개발자 드로어에서 시험 항성계도 선택합니다. 숨김 제스처는 보안 인증이 아니며 브라우저 로컬 도구입니다.

개발자 모드의 표면 편집에서는 지형/환경, 원래 자연 매장량, 초기 POP·도시화·기반시설·소속, 초기 지식과 미래 시설 메타데이터를 수정합니다. **1 U=10톤, 1 POP=100만 명**입니다. 미설정은 null이며 사용자 입력 0과 구분합니다. 실제 채굴·인구 성장·생산·탐사·전투는 없습니다. 일반 모드에서는 개발자 원본 자원 정보나 파일/편집 UI를 노출하지 않습니다.

JSON은 천체 하나씩 내보내고, 가져오기 검증·미리보기·덮어쓰기 확인 후 적용합니다. 로컬 초안은 시스템/천체별로 보존하고 Undo와 백업을 제공합니다. 내보낸 파일은 [정적 프리셋 manifest](dist/data/planet-surfaces/README.md)에 등록해 다른 브라우저의 초기 데이터로 사용할 수 있습니다. 2100은 시나리오 메타데이터이며 기존 천문 epoch·게임 시계를 바꾸지 않습니다.

일반 HUD의 전체화면 버튼은 표준 API를 지원할 때만 진입합니다. Esc/버튼으로 돌아와도 선택과 편집 데이터가 유지됩니다. 미지원·권한 제한 환경에서는 브라우저 메뉴/홈 화면 추가 안내를 표시합니다. iPhone/Safari 실기기 전체화면은 미검증입니다.

## 행정구역 편집과 저장

상단에서 `행정 섹터` → `행정 도구` → `셀 편집 시작`을 선택합니다. 셀을 눌러 미리보기 선택을 바꾼 뒤 이름·색을 지정하고 `새 구역 생성·적용`을 누릅니다. 태양과 겹친 중심 셀도 편집 모드에서는 선택할 수 있습니다. 일반 보기에서는 천체가 우선합니다.

대상 구역을 고르면 선택 칸 추가/제거, 이름·색 변경, 인접 구역 흡수, 삭제와 실행 취소를 사용할 수 있습니다. `링 선택`은 실제 공전 궤도와 별개인 기초 육각 링을 고릅니다. 고리 모양과 가운데 구멍을 허용하며, 연결 단절·중복·다른 항성계 셀은 거부합니다. 같은 구역 내부선만 흐려지고 `탐사 섹터`로 돌아가면 기본 경계가 모두 복구됩니다.

행정구역은 기존 `localStorage` 키에 버전 있는 JSON으로 저장하고, 산업 시계·시설·잔량·재고는 새 캠페인 키에 함께 저장합니다. 각 저장은 항성계별로 분리됩니다. 정적 인구·시나리오는 표면 템플릿에 남기며 오프라인 진행은 적용하지 않습니다. 손상 자료는 원본을 보존하고 명시적으로 백업·복원합니다. 배포 사이트와 로컬 실행은 서로 다른 브라우저 저장소입니다.

## 이전 v0.5D 실행 ZIP

아래 패키지는 이전 v0.5D 버전입니다. v0.5E는 ZIP을 새로 제공하지 않습니다. 완료된 배포의 `/downloads/SPACE_Project_v0.5D_HTML.zip`에서 HTML 실행 패키지를 받습니다. HTML·JS·Three.js·표면 이미지·라이선스와 `serve.py`를 포함합니다. 압축 해제 후 `python3 serve.py`(Windows: `py serve.py`)를 실행하고 `http://localhost:8765`를 여세요. ES 모듈을 사용하므로 HTML 파일 직접 열기 대신 로컬 HTTP 서버가 필요합니다.

```sh
python3 scripts/package-release.py
```

위 명령은 이전 릴리스 패키지 도구입니다. v0.5E 배포에는 Sites용 tar 아카이브만 사용합니다. GitHub main은 병합하지 않고 별도 작업 브랜치의 검증된 코드를 기존 비공개 Sites 실행 링크에 배포합니다.

## 공용 데이터와 좌표

`createSystemContext()`로 `systemId`, 명칭, 중심, 기준 평면, 항성·행성·위성·영역 배열을 묶어 `SystemViewer`에 주입합니다. 태양계 고유 ID와 표현 메타데이터는 `createSolContext()` 어댑터에 둡니다. 항성계 변경은 기존 선택·추적·탭·렌더 자원을 정리합니다.

v0.3 규칙은 변경하지 않았습니다. **1 게임 AU = 140/53 월드 단위**이며, 궤도 장반경 표시는 수성 53·금성 79·지구 100·화성 142·목성 280·토성 420·천왕성 570·해왕성 730입니다. Planet Size는 고정 월드 지름입니다(지구 15). 태양 Star Size 90은 고정 월드 지름 70으로 변환합니다. 섹터와 거리 계산은 게임 AU에서 수행한 뒤 렌더링에서만 환산합니다. 실제 km·실제 AU는 별도의 천문 참고 자료입니다.

## 한계와 후속 범위

지도·행정·표면 작성과 정부 광업/제련 산업을 구현했습니다. 산업 시계·시설·잔량·재고와 행정구역은 별도 저장합니다. 카메라·선택은 복원 대상이 아니며 배속은 새 접속 시1×입니다. 함선·이동·LOS·민간 경제·연구·안개·실제 쌍성 역학은 미구현입니다. 섹터는 고정 공간 인덱스이며 이동 경로나 물리적 벽이 아닙니다. 소천체는 입자 군집으로 개별 명령·충돌은 없습니다. 정식 경제 시작 조건 및 취소·교체·철거 정책은 미정입니다.

실제 지도는 구면 텍스처이며 높이 지형은 없습니다. 일부 위성은 대표 표면을 재사용합니다. [천문 자료·라이선스·근사 한계](docs/SOURCES.md)와 [결정 기록](docs/DECISIONS.md)을 확인하세요. 이전 [v0.3 보고](docs/v0.3/REVIEW.md)는 이 변경의 선행 기록입니다.
