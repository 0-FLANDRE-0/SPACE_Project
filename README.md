# SPACE Project · 모항성계 프로토타입

HTML/CSS/JavaScript + Three.js로 만든 **태양계 기반 3D 지도**입니다. 이번 빌드는 모항성계를 관찰하고 천체·궤도를 선택하는 Phase 0의 첫 단계입니다.

## 실행

Node.js 20+와 Python 3가 있으면 별도의 의존성 설치나 빌드가 필요 없습니다.

```sh
npm run dev
# http://localhost:5173
```

정적 파일은 `dist/`에 있습니다. 임의의 정적 HTTP 서버로도 실행할 수 있습니다. ES 모듈을 사용하므로 HTML을 `file://`로 직접 열지 마세요. Three.js와 OrbitControls는 MIT 라이선스와 함께 저장소에 포함했습니다. 웹폰트는 선택적으로 로드되며 연결되지 않으면 시스템 폰트로 표시됩니다.

## 이번 빌드에서 가능한 것

- 황색 항성인 태양, 행성 8개, 대표 위성 11개, 소행성대·카이퍼대.
- 실제 경사각·이심률과 공전 주기 비율을 참고한 3차원 공전. 위성 궤도는 모행성을 따라 이동합니다.
- 천체 또는 왼쪽 목록 선택 → 상세 정보와 선택한 궤도 강조. 위성을 선택하면 모행성 궤도도 보조 강조합니다.
- 천체 가까이 보기, 공전 중 선택 천체 추적, 자유 회전·이동·줌.
- 입체·상부·측면 시점, 전체 보기, 이름·궤도·황도 기준면 표시 전환.
- 시간 일시정지·재개, 1×·10×·50× 배속. 창을 숨긴 동안은 진행하지 않습니다.
- 모바일 터치 조작과 좁은 화면용 목록.

## 조작

| 입력 | 동작 |
|---|---|
| 좌클릭 드래그 / 한 손가락 | 카메라 회전 |
| 우클릭 드래그 / 두 손가락 이동 | 카메라 이동 |
| 휠 / 두 손가락 확대 | 확대·축소 |
| 천체·이름·왼쪽 목록 클릭 | 선택 및 궤도 강조 |
| 더블클릭 / 상세 패널 버튼 / F | 선택 천체 주변으로 접근 |
| Space | 시간 일시정지·재개 (버튼에 포커스가 없을 때) |
| H / Esc | 전체 보기 / 선택 해제 |

## 파일 구조

| 파일 | 역할 |
|---|---|
| `dist/src/data.js` | 천체 정의와 변경 가능한 표시 비율 |
| `dist/src/model.js` | 시뮬레이션 시간, 케플러 궤도, 부모·위성 위치, 선택 상태 |
| `dist/src/scene.js` | Three.js 렌더링, 카메라, 선택 판정, 궤도·이름 표시 |
| `dist/src/textures.js` | 절차적으로 생성한 행성 표면과 고리·광원 이미지 |
| `dist/src/main.js` | UI 명령과 시뮬레이션·렌더링 연결 |
| `tests/` | 궤도·시간·선택 회귀 테스트와 브라우저 검증 |
| `docs/DECISIONS.md` | 현재 결정, 임시 가정, 후속 범위 |

## 검증

```sh
npm run check
npm test
```

브라우저 검증은 실행 중인 서버와 Playwright/Chromium이 있는 환경에서 수행합니다. `tests/browser-smoke.mjs`는 `PLAYWRIGHT_MODULE`, `CHROMIUM_EXECUTABLE`, `BASE_URL`로 해당 환경을 지정할 수 있습니다. 구체적인 실행 결과는 `docs/VERIFICATION.md`를 참고하세요.

## 시각화의 한계와 다음 단계

천체 크기·궤도 간 거리·위성 간격은 **각각 다른 비율로 압축**했습니다. 초기 위상과 2200년 시작 날짜는 시연용이며 실제 천체력이 아닙니다. 표면 그림은 간단한 절차적 표현입니다. 소행성대는 입자 군집이며 개별 소행성 명령이나 충돌은 아직 없습니다. 현재 상태는 새로고침하면 초기화됩니다.

함선·LOS·행성 주변 이동·자동/수동 우회·개발·건설·자원 생산·저장/불러오기는 이번 빌드에 포함하지 않았습니다. 다음에는 이 지도를 기반으로 함선 1척과 행성 주변 이동을 검증할 수 있습니다. 원래 인계서의 Phase 1은 이후 작업입니다.
