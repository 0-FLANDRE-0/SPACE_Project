## 1. 이번에 만들 것

1. **연속 확대:** 성계에서 확대만으로 행성 추종 → 궤도 층 → **표면 섹터 단계**까지 끊김 없이. 표면 단계 = 표면 모드(별도 모드 진입 없음).
2. **행성 정보 카드:** 표면 단계에서 표시.
3. **섹터 패널:** 섹터를 누르면 열림, **아래로 더 길게**, 열리면 **행성 중심을 오른쪽 빈 공간으로 이동**.
4. **분포 보기 버튼을 섹터 패널 상단으로.**
5. **"표면 지도" 버튼 = 자동 확대 지름길.**
6. **상단 자원 바.**
7. **탐사 "가능성" 표시 수정.**

## 2. 연속 확대 — [사용자 확정 2026-11-05]

1. M1b의 확대 단계(고 → 중 → 저 → 표면)를 그대로 쓰되, **표면 단계에 들어가면 표면 섹터 입력이 바로 활성**된다. 지금처럼 "표면 지도" 버튼으로 별도 모드에 들어가지 않아도 섹터를 누를 수 있어야 한다.
2. 표면 단계의 섹터 선택·강조·산업 패널·분포 겹쳐보기는 기존 표면 모드의 렌더러/판정/패널을 **재사용**한다. 같은 기능을 두 벌로 만들지 않는다.
3. 기존 표면 모드 전용 상단 바(`#surface-toolbar`, "← 항성계 지도" 등)는 연속 확대 흐름에서 쓰지 않는다. 나가기는 **축소**(또는 기존 "전체 보기"). 행성 이름 등은 행성 카드로 옮긴다.
4. **나가기:**
   - 표면 단계 밖(저궤도 이상)으로 축소 → 섹터 패널 닫힘, 섹터 선택 해제.
   - 행성권 밖으로 축소·팬 → 행성 카드 닫힘, 추종 해제(M1b 규칙).
   - 경계에 히스테리시스(M1b 값 재사용 가능).
5. **누르기 우선순위:** 함선(3D·아이콘) > 섹터. 함선 이동 지점 선택 중에는 궤도점·라그랑주 > 섹터. M2 섹터 다중 선택 중에는 섹터 선택이 우선.
6. 카메라 최소 거리·회전 등 기존 표면 모드의 시점 제한은 표면 단계에서 동일하게 적용(천체 관통 금지).
7. 행성·위성 모두 동일. 표면 격자가 없는 천체(항성·소행성대 등)는 표면 단계가 없다.

### 2.1 "표면 지도" 버튼 — [사용자 확정]
- 남긴다. 누르면 **현재 선택/추종 중인 천체의 표면 단계까지 자동으로 확대**(기존 전환 애니메이션 재사용)한다. 별도 모드로 들어가지 않는다.
- M2 탐사 "정밀: 섹터 지정"이 표면 지도를 열던 동작도 이 자동 확대로 바꾼다.

### 2.2 개발자 도구
- 표면 편집기·생성 패널·자원 지질 패널·입출력은 **개발자 모드에서** 표면 단계 상태로 열 수 있게 유지한다(기존 개발자 서랍 진입 그대로). 일반 플레이 화면에는 나타나지 않는다.

## 3. 행성 정보 카드 — [사용자 확정: 표면 단계에서 행성 정보 / 구성은 Claude 제안 임시]

- 표면 단계에 들어가면 작은 카드 표시(위치 [임시]: 자원 바 아래 왼쪽).
- 내용: 천체 이름·종류, 인구, 섹터 수, **탐사 상태**(대략 %, 정밀 완료 섹터 수/전체), 시설 요약(가동/정지 수), 전력 부족 경고(있을 때만).
- 자원 수량은 상단 자원 바가 이 천체 기준으로 바뀌므로 카드에 중복 표시하지 않는다.
- 섹터 패널이 열리면 카드는 접히거나 패널 상단 머리글로 합친다 [임시, 보고].

## 4. 섹터 패널 — [사용자 확정]

1. 섹터를 누르면 기존 섹터 정보·정부 산업 패널이 왼쪽에 열린다(내용 유지).
2. **세로로 더 길게:** 화면 아래쪽까지 늘린다. M2에서 품질 막대 등을 보려면 스크롤하던 문제를 줄인다. 내부 스크롤은 남은 넘침에만.
3. **아래 시간 바와 겹치지 않게:** 667×375 같은 좁은 가로 화면에서 패널과 시간 바가 겹치면, 패널이 열린 동안 시간 바를 오른쪽 빈 영역 쪽으로 옮기거나 패널 하단을 시간 바 위에서 멈춘다 [임시, 보고]. 모든 시험 화면에서 겹침 0.
4. **행성 중심 이동:** 패널이 열리면 행성 중심이 패널 오른쪽의 **빈 영역 가운데**로 부드럽게 이동하고, 닫히면 돌아온다.
   - 카메라 위치를 옆으로 옮기지 말고 **투영 중심만 이동**(예: `camera.setViewOffset` 또는 동등한 렌즈 이동)해서 회전·확대가 계속 행성을 축으로 동작하게 한다.
   - 화면 회전·크기 변경·패널 크기 변경 시 다시 계산. 레이캐스트(섹터·함선 판정)가 이동된 투영에서도 정확해야 한다.
   - 세로 화면처럼 패널이 아래쪽에 붙는 배치에서는 위쪽 빈 영역으로 옮긴다 [임시].
5. **분포 보기 버튼(매장량·인구·시설, M2 탐사 기본 보기)을 섹터 패널 상단에** 둔다 [사용자 확정]. 섹터를 고르지 않은 상태에서도 분포를 바꿀 수 있도록 행성 카드에 같은 전환을 작게 두는 것은 허용 [Claude 제안, 임시].

## 5. 상단 자원 바 — [사용자 확정 §20, 세부는 임시]

### 5.1 구성
| 칸 | 범위 | 내용 |
|---|---|---|
| 크레딧 | 국가 고정 | 정부 금고 잔액 + 월 변화 |
| 인구 | 국가 고정 | 전체 인구, 누르면 천체별 |
| **기준 표시** | — | 현재 보고 있는 천체 이름 / 성계 전체 보기면 **"전체"** |
| 원광 | 현재 기준 | 합계(품질 등급은 펼침에서) + 월 변화 |
| 합금 | 현재 기준 | 수량 + 월 변화 |
| 수소 | 현재 기준 | 수량 + 월 변화 |
| 물·산소 | 현재 기준 | **런타임 자원 정의가 생기기 전까지 숨김**(자리만 데이터로) |
| 전략 자원 | 현재 기준 | 총량 한 칸, 누르면 종류별. **정의된 전략 자원이 없으면 숨김** |
| 전력 | 현재 기준 | 숫자 없음. **부족할 때만 경고 아이콘** |

- **기준 천체:** 추종 중이거나 선택한 행성·위성(궤도 정거장 재고는 그 천체에 합산 또는 별도 행 [임시]). 성계 전체 보기 = 모든 천체 합계.
- **월 변화:** 정부 산업의 기존 월간 요약(생산·소비)에서 가져온다. 음수는 위험 색, 바닥까지 남은 개월이 짧으면(예: 3개월 미만 [임시]) 경고 색.
- **잔여물은 바에 넣지 않는다.**
- 데이터 원천: 기존 `planetInventory`·`governmentTreasuries`·인구 데이터·산업 월간 요약. 새 경제 계산을 만들지 않는다.

### 5.2 펼침
- 자원 칸을 누르면 아래로 펼쳐져 **천체별 수량(+월 변화)** 목록. 행을 누르면 그 천체로 카메라 이동(기존 `focus`).
- 원광 펼침에는 품질 등급(하/중/상)별 수량. 인구 펼침은 천체별 인구.
- 한 번에 펼침 하나. 바깥을 누르거나 같은 칸을 다시 누르면 닫힘.

### 5.3 배치
- 상단 왼쪽 로고 옆부터 가로로. 기존 상단 오른쪽 버튼(지도 모드·섹터·전체 보기·전체화면·설정)과 **겹치지 않게 재배치**한다(한 메뉴로 묶기, 아이콘만 남기기, 두 번째 줄 등 [임시, 보고]).
- 844×390 가로에서 한 줄에 들어가야 한다. 숫자는 축약(1.2만, 3.4억 등 기존 한국어 축약 규칙 재사용).
- 개발자 모드 실제값은 바에 절대 쓰지 않는다(플레이어 지식 기준 재고만).

## 6. 탐사 "가능성" 표시 수정 — [Claude 제안, 사용자 묶음 승인]

M2에서 "가능성"이 천체 평균 섹터 매장량(Z) 대비로 매겨져 6억 U 섹터도 "거의 없음"이 되고, 대략 탐사 전에도 표시된다.
1. **대략 탐사가 시작되기 전에는 가능성 등급을 표시하지 않는다**(예측 범위·확인량은 기존대로).
2. 문구를 **비교 표현**으로: "천체 평균보다 많음 / 평균 수준 / 적음 / 매우 적음". 지도 범례도 같은 문구.
3. 등급 경계 값(0.35·0.85·1.4)은 유지.

## 8. 자동 테스트

1. 확대 단계 → 표면 단계 진입 시 섹터 입력 활성, 축소 시 해제(히스테리시스), 행성권 이탈 시 카드 닫힘.
2. 누르기 우선순위(함선 > 섹터, 이동 지점 선택 중 궤도점 > 섹터, 탐사 다중 선택 중 섹터).
3. "표면 지도" 버튼 = 표면 단계 자동 확대, 별도 모드 상태 없음. M2 섹터 지정 흐름 통과.
4. 섹터 패널 열림 시 투영 중심 이동, 닫힘 시 복원, 이동 상태에서 섹터·함선 레이캐스트 정확.
5. 패널·시간 바·자원 바·하단 함선 버튼 겹침 0(1440×900, 844×390, 667×375, 390×844).
6. 자원 바: 기준 전환(천체/전체), 합계 = 천체별 합, 월 변화 = 산업 월간 요약, 펼침 목록·카메라 이동, 미정의 자원 칸 숨김, 플레이어 지식 외 값 미노출.
7. 가능성: 대략 탐사 전 미표시, 비교 문구.
8. 기존 기능 회귀: 산업 패널 실채굴·포장, 분포 보기 3종, 개발자 표면 편집기 열기, M1b 궤도·라그랑주, M2 탐사 전체 흐름, 새로고침 초기화.
9. 기존 전체 테스트·공식 산출물 불변.
