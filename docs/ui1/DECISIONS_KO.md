## 미정 데이터의 처리

- 런타임에 크레딧의 월간 원장이 없으므로 `creditDeltaC=null`, 화면에는 **월 변화 미집계**를 표시한다. 국가 금고가 미설정이면 **미정**이다. 0으로 만들지 않는다.
- 자원 월 변화는 기존 산업 화면과 같은 현재 게임월의 생산·소비 누계다. 미래 월의 예측 또는 새 경제 계산이 아니다.
- 원광은 기존 `industryOreInventory()`의 자유+봉인 재고. 합금/수소는 기존 planetInventory 투영이며 포장 장부를 다시 더하지 않는다.
- 거주 인구가 정해지지 않은 천체는 **미설정**. 지구는 공식 92개 섹터 8,893 POP를 참조한다.
- 미래 물·산소 칸만 UI 메타데이터에 예약했다. 런타임 정의가 없으면 숨긴다. 전략 자원은 실제 정의의 명시적 strategic/category 표식이 있어야 한다. 자원 정의는 추가하지 않았다.
- 전력은 소유 시설의 공개 정지 사유에 실제 전력 부족/정전이 있을 때만 경고한다. UI가 새로운 전력 부족 계산을 하지 않는다.
- 정거장 재고는 별도 런타임 저장 원천이 없으므로 행성 재고에 임의 가산하지 않는다.
