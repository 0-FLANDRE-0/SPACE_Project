SPACE 로고5초 안7회 → 천체 정보의 **표면 지도 → 자원**. 고정/시드 자동 총량, 표면·광맥·심층 비율과 매장량 가중 평균 품질, 시드·편차, 원본/실효 품질과 기술 가정, 개별 매장지/초기 인지 JSON을 검토·편집합니다. 미설정 채우기가 기본입니다. 다른 시드의 전체 재구성은 **전체 ore 교체** 선택 → 미리보기 → 범위/인지 이관 검토 → 확인 → 현재 JSON 다운로드/로컬 백업 → 적용입니다. Undo와 기존 파일 UI의 v1/v2 왕복을 지원합니다. 정적 공식 파일은 로컬 대안을 작성해도 바뀌지 않습니다.

검수 지도7개: ore총량 / 표면형 / 광맥형·연결선 / 심층형 / 매장량 가중 고품질 확률 / 채굴 난도 / 확인 상태. 같은 groupId의 광맥은 구면 이웃 중심을 따라 연결하고, 선택 구역 상세에서 해당 광맥의 전체 tileId 목록을 보여줍니다. 기존 단일 배치 색상 geometry를 재사용하며 연결선은 소수 배치입니다. 개발자 종료/천체·시스템 변경/닫기 때 Worker와 검수 레이어·비공개 DOM을 정리합니다.

일반 모드는 해당 문명이 **인지한 매장지의 확인량만** 표시합니다. 실제 총매장량·기본 품질·그룹·숨긴 목록은 노출하지 않습니다. 숨김 개발자 모드는 인증/암호화가 아니며 클라이언트 원본 자체를 비밀로 보호하지는 않습니다.

지구/금성의 형태별 품질 타깃은 지시서 그대로입니다. 개별 확률에는 편차가 있으며 해당 매장량으로 가중하면 지정 평균을 유지합니다. 지구 전체 기대 확률 **46.55/46.40/7.05%**, 초기 기대 합금수율 **0.25495**. 금성 **14.00/27.10/58.90%**, 기대 수율 **0.41531**. 이들은 확률적 기대값이고 품질별 확정 매장량이 아닙니다.

화성의 정확한 품질은 **잠정** surface55/40/5, vein28/42/30, deep15/35/50%. 확정된 상대 경향을 만족하며 UI에서 변경 가능합니다. 달의 저80%는 확정, 중17/고3%는 잠정입니다. 달 처리난도≥80, 금성 채굴난도≥80은 별도의 잠정 난도 하한이며 품질 수율을 중복 감산하지 않습니다. 개별 난도/편차 강도도 잠정 튜닝값입니다.

1 U=10톤, 0.001 U=10kg. 배분의 진실값은 안전 정수 quanta입니다. 십진 문자열→BigInt로 단위를 읽어 큰 매장량의 이진 곱셈 오차를 피하며 실제 0.0001 U 등은 거부합니다. 형태 예산→셀 배분은 결정적 최대잔여 방식입니다. 모든 매장지 ID는 유일하고 그룹은 공유되어도 각 셀의 실제 U만 한 번씩 합산합니다.

## 나머지 프리셋과 시드

[19개 수치·시드·확정 구분](preset-report.json)에 모두 기록합니다. 이 보고서의 populationPersons는 입력된 셀만 합한 값이며 populationConfiguredCells0인 천체는 인구 미정입니다.

수성/나머지 고체 위성은 실제 반지름을 지질 규모의 참고값으로 쓰는 **게임용 잠정** 예산에 시드 풍부도0.25~3배와 부재 확률6%를 적용합니다. 이 범위·기준400억 U·크기 지수1.5·상한1e12 U는 조정 가능한 튜닝값입니다. 가스 대기층은 ore0이며 대기 수소 채집 잠재 위치를 갖습니다. 얼음형과 지구에는 유한 수소 원천을 둡니다. 수소를 광석 제련으로 만들거나 시작 재고로 지급하지 않습니다.

달 **0.2 POP=200,000명**, 화성 **0.05 POP=50,000명**을 각각 한 셀에만 두었습니다. 수치·위치·도시화/기반시설·초기 인지율은 모두 잠정이며 `PROVISIONAL_SCENARIOS`와 공식 생성 스크립트에서 변경 가능합니다. 나머지 초기 인구/문명은 임의 생성하지 않았습니다.

`generateBodyResources({systemId,body,grid,worldSeed,policy,settings,...})`는 Sol ID 분기 없이 임의 행성/위성에 동작합니다. Sol 확정값은 별도 프로필/어댑터에만 있습니다. 고정 모드는 총량/비율/평균을 보존하고 배치·개별 확률을 바꿉니다. 가변 모드는 총량·평균·비율·규모·난도도 시드에 따라 바뀝니다. world/system/body/resource/group/tile의 독립 키를 사용하며 Math.random/시각/호버/프레임에 의존하지 않습니다. 정적 Sol 파일은 canonicalSeed의 결과 snapshot이고 브라우저가 재생성하지 않습니다.

표면형은 넓게, 광맥형은 실제 neighborIds를 따라 연결된 여러 셀에, 심층형은 일부 셀에 배치합니다. 그룹별 공유 편차+약한 국지 편차를 매장량 가중 중심화하고 모든 셀에 공통 alpha를 적용해 평균을 보존합니다. 개별 clamp로 평균을 깨지 않습니다. 저장 double 정밀도에서 평균 오차1e-6 이하(실제 테스트1e-10)입니다. 단일 매장지/100% 고정 성분은 가능한 편차가 제한됩니다.

## 버전·원본·지식·채굴 예제

템플릿 **schemaVersion2**를 도입했습니다. grid.generatorVersion/frequency/orientationId/fingerprint는 그대로1/기존값이며 자원 generatorVersion1, migrationVersion1은 각각 별개입니다. 기존 v1 strict validator를 유지하고 v2만 확장 필드를 허용합니다. 명시적 v1→v2 이관은 원래 양/ID/시나리오/null/0를 유지하고 미분류 ore에 표면형·60/38/2라는 **미검증 레거시 가정**을 붙입니다. 실제 배분 확정과는 다른 작업입니다.

**ore의 authoritative 양은 geology.cells[].deposits[].initialReserveU 한 곳**입니다. resourceConfiguration은 목표/작성 설정이고 수량에 더하지 않습니다. v1과 v2를 병렬 합산하지 않습니다. 기존 저장소 키 이름은 호환을 위해 유지하고 내용은 검증된 v1 또는 v2입니다. 명시적 교체 시 손상 원본 raw 또는 이전 정적 템플릿도 로컬 :backup에 보관합니다. 저장 실패는 메모리 상태와 JSON 내보내기를 안내합니다.

초기 자원 지식은 문명별 티어 조사 진행과 매장지별 탐지율/확인율/추정 신뢰도로 분리합니다. tier조사100%가 전체 자원100% 발견을 뜻하지 않습니다. 새 센서 tier를 추가해도 이전 기록을 보존합니다. 지구 기존 인지는 높고 달/화성은 일부, 기타 천체는 숨김이라는 정책만 두며 정확한 비율은 잠정입니다. 배치 교체로 참조가 깨지면 거부합니다. 개발자가 별도 **인지 이관**을 체크하면 같은 셀/형태의 기록만 옮기고 이관 불가 기록 수를 미리 보여주는 대안을 만들 수 있습니다. 기존 v1의 셀별 발견 ID는 조용히 삭제/확대하지 않고 잘못되면 거부합니다.

`sampleGradeBatch`는 배치 seed/depositId/serial로 결정적 품질 물량을 반환합니다. 최대256 quanta는 개별 Bernoulli, 큰 배치는 경계 제한 정규 근사를 사용해 O(1)입니다. 큰 배치의 정확한 이항 분포/매우 희귀한 꼬리 분포를 보장하는 통계 시뮬레이터는 아닙니다. 권위 있는 quanta 합계는 입력과 정확히 같고 등급 판정이 질량을 생성하지 않습니다. display U 합에는 통상적인 부동소수점 표현 오차가 있을 수 있습니다.

기본 제련 수율 저0.14/중0.33/고0.52는 정확히 적용하며 잔여량은 별도 residueU로 반환합니다. 채굴/선광은 최종 품질 확률, 제련은 수율을 각각 보정하는 독립 입력입니다. 기술 공식은 잠정 예제이며 실생산/재고/잔량/시계에 연결하지 않습니다. 미래 희귀 부산물은 compositionTags와 전용 정제 기술 계약만 예약합니다. **아스트로지늄은 매우 희귀한 우주 원천의 특수 드라이브 연료라는 예정 설정만** 문서화하며 등록/매장/생산/소비하지 않습니다.
