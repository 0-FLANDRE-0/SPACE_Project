## 1. 발견된 문제 (검수 결과)

### 1.1 지구 광맥이 1줄·2섹터에 집중됨 — **필수 수정**

현재 `sol-earth-v2.json`의 광맥형은 다음과 같다.

| 항목 | 현재 값 |
|---|---|
| 광맥 그룹 수 | **1개** (`g1-sol-earth-d71207a1-vein-0`) |
| 광맥 셀 수 | **2개** (`00072`, `00081`) |
| 광맥 총량 | 51,090,000,000 U (지구 전체의 65%) |
| 단일 셀 최대 | `00081` = 약 **28,000,000,000 U** → **지구 전체 ore의 약 35.6%** |
| 광맥 후보 셀 (`landFraction ≥ 0.2`) | 40개 |

후보가 40개인데 2개만 사용했다. 섹터 하나가 지구 광석의 1/3 이상을 가진 것은 의도한 지질 분포가 아니다.

**원인:** `connectedGroups()`가 광맥 수를 `1 + floor(rng × 5)`(1~5)로, 길이를 `max(2, round(후보수 × (0.025 + rng × 0.12)))`로 정한다. 지구 공식 시드가 하필 **1줄, 길이 2**를 뽑았고, 고정 프리셋이라 그대로 확정되었다. 최소 커버리지나 집중도 상한 검사가 없다.

참고: 화성(4줄)·수성(5줄)은 정상이다. 금성은 1줄이지만 12셀이라 덜 심각하나, 아래 규칙을 똑같이 적용한다.

### 1.2 품질 편차가 설정보다 약 10배 작음 — **조정**

`resourceConfiguration.jitter = 0.04`인데, 실제 매장지별 고품질 확률 편차는 대부분 **±0.4%p 안팎**이다(예: 지구 표면 고품질 1.69~2.47%, 금성 심층 고품질 81.56~82.29%).

**원인:** 형태 전체에 **공통 α 하나**를 적용하기 때문에, 그 형태에서 가장 낮은 성분(예: 금성 심층 저품질 1%)이 음수가 되지 않도록 α가 크게 줄고, 그 결과 다른 성분의 편차까지 같이 작아진다.

## 2. 광맥 배치 보정 규칙

### 2.1 최소 커버리지

광맥 그룹 수와 길이를 다음 규칙으로 정한다. 모든 수치는 **잠정 튜닝값**이며 설정 파일에서 조정 가능하게 한다. Sol 전용 분기를 만들지 말고 공용 생성기 규칙으로 구현한다.

| 항목 | 규칙 |
|---|---|
| 광맥 그룹 수 | 고정 예산(`fixedBudget`) 천체: **최소 3개**, 최대 6개. 가변 예산 천체: 최소 2개, 최대 6개. 단, 후보 셀이 부족하면 가능한 만큼만 만들고 그 사실을 보고서에 기록 |
| 그룹당 길이 | **최소 3셀** (후보 셀이 허용하는 경우) |
| 전체 광맥 셀 수 | 후보 셀의 **최소 25%** (지구: 후보 40개 → 최소 10셀) |
| 그룹 간 분리 | 서로 다른 그룹은 셀을 공유하지 않는다 (기존 계약 유지). 서로 인접해도 되지만 같은 그룹으로 합쳐 세지 않는다 |

시드는 여전히 그룹 수(범위 안), 각 그룹의 시작 위치·길이·분기·셀별 양을 바꾼다. "최소 커버리지를 맞추려고 모든 시드가 같은 모양이 되는" 결과는 불합격이다.

### 2.2 집중도 상한

| 검사 | 상한 (잠정) |
|---|---|
| 단일 셀의 ore 총량 (표면+광맥+심층 합) | 천체 전체 ore의 **10% 이하** |
| 단일 광맥 그룹의 총량 | 광맥형 예산의 **50% 이하** (그룹이 2개 이상일 때) |

- 상한을 넘으면 초과분을 **같은 형태의 다른 매장지로 결정적으로 재분배**한다. 형태별 예산 합계는 정수 quanta로 정확히 유지한다.
- 후보 셀 수가 너무 적어 상한을 수학적으로 지킬 수 없는 천체는 예외로 처리하고, 보고서에 이유를 기록한다.
- 위 상한도 잠정 튜닝값이며 설정 가능하게 한다.

### 2.3 유지해야 할 것

- 지구 광맥은 기존 정책대로 **육지·대륙붕 후보(`landFraction ≥ 0.2`) 우선**. 해양 표면형 해저 단괴 정책(`extractionDifficulty ≥ 80`, `discoveryTier ≥ 3`)도 그대로.
- 광맥 그룹은 실제 `neighborIds`로 연결되어야 한다(기존 연결성 검사 유지).
- 확정 4개 천체의 총량·형태별 예산은 1원 단위도 바뀌면 안 된다.
- 가변 예산 천체(수성·위성들)의 **총량, 형태별 비율, 형태별 품질 타깃은 바뀌지 않아야 한다.** 이번 보정은 배치와 개별 편차만 바꾼다.

## 3. 품질 편차 확대 규칙

### 3.1 목표 폭

사용자 지정: **매장지별 품질 확률은 형태 평균에서 최대 약 ±5%p까지 달라도 된다.** 가중평균 보존 계약(v0.5D 7절)은 그대로 유지한다.

### 3.2 성분별 독립 폭 (공통 α 하나로 묶지 말 것)

각 형태(`surface`/`vein`/`deep`) 안에서 성분별 최대 편차 `A_c`를 따로 정한다.

```text
A_low  = min(0.05, 0.75 × target_low,  0.75 × (1 − target_low))
A_high = min(0.05, 0.75 × target_high, 0.75 × (1 − target_high))
```

예시:

| 천체·형태·성분 | 타깃 | 최대 편차 A |
|---|---:|---:|
| 지구 표면 고품질 | 2% | ±1.5%p |
| 지구 심층 고품질 | 33% | ±5%p |
| 금성 심층 저품질 | 1% | ±0.75%p |
| 금성 심층 고품질 | 82% | ±5%p |
| 달 표면 저품질 | 80% | ±5%p |

### 3.3 절차

1. 기존과 같이 그룹 공유 편차 + 국지 편차로 `dLow_i`, `dHigh_i`를 만든다(광맥 그룹 내 상관 유지).
2. **각 성분을 따로** 매장량 가중 중심화한다: `δLow_i = dLow_i − Σw·dLow / Σw`, `δHigh_i`도 동일.
3. **각 성분을 따로** 배율을 정한다: `αLow = A_low / max|δLow|`, `αHigh = A_high / max|δHigh|`. 중심화된 벡터에 상수를 곱해도 가중평균 0이 유지되므로 평균 보존이 깨지지 않는다.
4. `P_low = t_low + αLow·δLow`, `P_high = t_high + αHigh·δHigh`, `P_medium = 1 − P_low − P_high`.
5. `P_medium`이 `[0.001, 0.999]`를 벗어나는 매장지가 하나라도 있으면, **그 형태의 모든 매장지에** 공통 축소 계수 `k`(0<k≤1)를 `αLow`, `αHigh` 양쪽에 곱한다. 개별 clamp는 금지(평균이 깨짐).
6. 저장 정밀도 반올림 후 가중평균 오차 ≤ 1e-6, 각 매장지 합계 = 1, 음수·NaN 없음을 검증한다.

### 3.4 "실제로 넓어졌는지" 검사

- 매장지 5개 이상이고 타깃 ≥ 10%인 성분은, 실제 사용된 최대 편차가 **A_c의 60% 이상**이어야 한다(축소 계수 k<1이 적용된 형태는 `k × A_c`의 60% 이상). 현재처럼 ±0.4%p에 머물면 불합격.
- 적용된 `A_c`, 축소 계수 `k`, 실제 최소/최대 확률을 형태별로 보고서에 남긴다.
- `resourceConfiguration.jitter` 단일 값 대신 새 정책을 설명하는 필드(예: `qualityJitterPolicy: "per-component-v2"`, `maxDeviation: 0.05`)를 기록한다. 기존 필드를 남긴다면 의미를 문서화한다.

## 4. 버전·재생성

- 같은 시드에서 결과가 바뀌므로 **자원 `generatorVersion`을 1 → 2**로 올린다. 격자 `grid.generatorVersion`·fingerprint는 그대로.
- `canonicalSeed`는 유지해도 되지만, 결과가 v1과 다르다는 것을 `migration`/문서에 기록한다.
- ore depositId가 바뀌므로 `initialResourceKnowledge`의 `depositId` 참조도 **새 ID 기준으로 재생성**하고, 끊어진 참조가 없음을 검증한다.
- 기존 v1·v0.5D(자원 generatorVersion 1) 로컬 초안은 자동으로 덮어쓰지 않는다(기존 보호 정책 유지).

## 5. 테스트 추가

1. **지구:** 광맥 그룹 ≥ 3, 광맥 셀 ≥ 10, 그룹당 ≥ 3셀, 모든 그룹 연결.
2. **집중도:** 19개 프리셋 전부 단일 셀 ore ≤ 천체 총량의 10%, 단일 광맥 그룹 ≤ 광맥 예산의 50% (예외 천체는 명시적 허용 목록과 사유).
3. **확정값 불변:** 지구·금성·화성·달 총량, 형태별 U, 형태별 가중평균 품질 — v0.5D와 동일.
4. **가변 천체 불변:** 수성·위성들의 총량·형태 비율·형태별 타깃이 v0.5D 결과와 동일.
5. **편차 폭:** 3.4절 조건. 모든 확률 합 = 1, 범위 0~1.
6. **시드 다양성:** 같은 지구 고정 예산에 서로 다른 시드 10개 → 광맥 그룹 수·위치·길이가 의미 있게 달라야 함. 모든 시드에서 2.1·2.2절 규칙 충족.
7. **재현성:** `generate-sol-presets.mjs` 재실행 시 19개 파일 바이트 동일.
8. **지구 원본 보존:** 격자·`startingScenario`·지형·환경 원본과 완전 동일, ore만 변경 (기존 테스트 유지).
9. 기존 122개 테스트 + 브라우저 스크립트 전부 통과.
