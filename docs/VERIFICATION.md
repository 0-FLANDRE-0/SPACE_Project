# 검증 기록 — v0.2

검증일: 2026-10-29. 대상: 실제 거리 단위·태양계 자료·모바일 가로 화면 개선.

## 사용자 흐름

정적 페이지 로딩 → 로컬 천체 수치·실제 표면 지도 로딩 → AU 기준 항성계 관찰 → 행성 선택·궤도 강조 → 주변 위성 궤도 보기 → 표면 접근 → km 눈금·실제 반지름·자전축 확인 → 가로 화면 터치 조작.

서버는 정적 자산만 제공합니다. API·DB·서버 환경변수는 없습니다. 외부 천문 사이트는 개발 시 참고 자료를 수집할 때만 사용합니다.

## 수치·소스 검사

`npm run check`: 소스 모듈 6개 문법 검사 통과.

`npm test`: 11개 테스트 통과.

- AU와 km 환산, 지구 반지름과 달 궤도 장반경.
- 별도로 조회한 JPL Horizons 지구 위치 벡터와의 비교. 2026-10-29에서 0.0003 AU 이내. 지구–달 질량중심 근사와 지구 본체의 차이를 포함합니다.
- 타원 폐곡선, 실제 3D 궤도면, 근일점 인수 적용, 오른손 좌표계.
- 트리톤의 역행 궤도. 기울기와 음의 주기를 중복 적용하지 않음.
- 이동하는 모행성 주변에서 유지되는 위성 궤도.
- IAU 자전축 기준 지구 약 23.44°, 화성 약 25.19°, 금성 약 177.36°, 천왕성 약 97.77°.
- 자전 중 축 프레임 유지와 금성·천왕성의 역행 자전 방향.
- AU → km 눈금 전환과 화면 픽셀 길이의 일관성.
- 일시정지·배속·프레임 분할, 선택 상태, 유효한 부모 참조, 시대별 궤도 요소 변화.

## 브라우저 회귀

Chromium + Playwright, WebGL 소프트웨어 렌더러. 데스크톱 1440×1000, 터치 가로 화면 844×390와 667×375.

```sh
npm run dev
PLAYWRIGHT_MODULE=/opt/codex/cua_node/lib/node_modules/playwright-core/index.mjs \
CHROMIUM_EXECUTABLE=/usr/bin/chromium node tests/browser-smoke.mjs
```

Playwright가 설치된 환경에 맞게 모듈·실행 파일 경로를 바꿀 수 있습니다.

통과 항목:

- HTTP 200과 WebGL 초기화. 천체 20개·소천체 영역 2개.
- 지구 선택 시 궤도 불투명도 0.90, 비선택 화성 0.055.
- 주변 궤도 보기에서 달 표시, 표면 보기에서 2K 실제 지구 지도 로딩·실측 반지름 사용·km 눈금 전환.
- 일시정지·재개·배속. 카메라 드래그·휠 조작 후 실제 메시 클릭 선택.
- 위성 선택, 소행성대 경계 강조, 이름·궤도·황도면 전환.
- 측면·전체·내행성 보기, 안내 열기·닫기.
- 가로 화면에서 터치 선택·접근·정보 접기·펼치기, 수평 오버플로 없음.
- 토성 메시의 북극 방향이 고정 자전축 프레임과 일치함.
- 브라우저 JavaScript·콘솔 오류 없음.
