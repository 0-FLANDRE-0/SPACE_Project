# 검증 기록

검증일: 2026-10-29. 빌드: 모항성계 지도 v0.1.

## 검증한 사용자 흐름

정적 HTML 진입 → 로컬 ES 모듈·천체 정의 로딩 → Three.js 지도 렌더링 → 천체 선택 → 시뮬레이션 선택 상태 변경 → 정보 패널과 궤도 강조 → 카메라 회전·확대 후 같은 천체를 화면에서 다시 선택.

서버는 정적 자산만 제공합니다. 이 빌드에는 API·DB·서버 환경변수가 없습니다.

## 자동 검사

`npm run check`: 게임 소스 모듈 5개의 JavaScript 문법 검사 통과.

`npm test`: 6개 테스트 통과.

- 모든 행성·위성의 궤도가 한 공전 주기 후 닫힘. 역행 위성 포함.
- 경사진 궤도에 유한한 높이 변화가 있고 지구 궤도는 기준면에 유지됨.
- 지구가 이동해도 달과 지구 사이 거리가 달 궤도 범위를 유지함.
- 일시정지·배속·프레임 분할 시 시간 진행의 일관성.
- 선택 궤도와 모행성·위성 보조 강조 구분.
- ID 유일성, 위성 부모 참조, 잘못된 선택 명령 거부.

## 브라우저 검증

Chromium + Playwright, WebGL 소프트웨어 렌더러로 수행. 데스크톱 1440×1000, 모바일 390×844.

```sh
PLAYWRIGHT_MODULE=/opt/codex/cua_node/lib/node_modules/playwright-core/index.mjs \
CHROMIUM_EXECUTABLE=/usr/bin/chromium node tests/browser-smoke.mjs
```

환경에 따라 설치된 Playwright 모듈과 Chromium 실행 파일 위치를 바꾸면 됩니다.

검증 항목:

- HTTP 200, 초기 WebGL 지도 로딩, 천체 20개와 소천체 영역 2개.
- 지구 선택: 지구 궤도 불투명도 0.90, 비선택 화성 궤도 0.055.
- 지구 가까이 보기와 달의 위치·이름 표시.
- 일시정지 시 시간·행성 좌표 고정, 재개·50× 배속 시 진행.
- 실제 마우스 드래그·휠로 카메라 변경 후, 행성 메시를 클릭해 선택 성공.
- 달 선택 시 위성 궤도 강조, 소행성대 선택 시 경계 강조.
- 이름·궤도·황도 기준면 표시 전환.
- 측면 보기와 전체 보기 복귀, 안내 대화상자 열기·닫기.
- 모바일에서 수평 오버플로 없음, 터치로 토성 선택·접근, 상세 정보 접기·펼치기.
- 브라우저 JavaScript 오류·콘솔 오류 없음.

스크린샷은 로컬 `artifacts/`에 저장되며 Git에는 포함하지 않습니다.

## 한계

실제 모바일 GPU·Safari·Firefox에서 별도 성능/호환성 검증은 하지 않았습니다. 브라우저의 WebGL 지원이 필요합니다. 소프트웨어 렌더러에서의 통과는 저사양 기기의 프레임 속도를 보장하지 않습니다. 천체력 정확성, 함선 이동·충돌·건설·저장은 이번 검증 대상이 아닙니다.
