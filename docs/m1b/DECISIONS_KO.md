- **[M1b 제안 규칙 적용]** 현재 행성권 내부 간선은 선회+이동+충전의 빠른 방식을 자동 선택(동률 추진), 밖은 드라이브다. 행성권 안 드라이브도 천체 기준 좌표계를 사용한다. 내부 장애물은1.02R, 외부 여유는기존 min(0.4gAU,0.2R)을 유지한다.
- **[구현]** 모든19행성/위성에서 기존 표면격자 그대로 저1.05/중1.3/고1.6R의 점·이웃/수직 간선을 만든다. 고궤도 frequency 축소는 하지 않는다. 점은 표면 자전을 추종하는 임시안을 사용한다. 그래프는 진입 방향을 상태로 둬 선회 비용을 비교하고, LOS가 열리면 더 이상 그 경로를 확장하지 않는다.
- **[카메라 임시]** 중심 부근 천체로 확대하면 자동followId를 설정하고 고→중→저→표면 선을 표시한다. 진입6고궤도반경/해제7, 중심오차0.45/0.8고궤도반경, 중6R·저3.5R·표면2R와0.15R 히스테리시스다. 먼저 천체 공전 이동을 카메라에 반영한 다음 해제 여부를 판단해 고배속 위성 추종을 유지한다. 기존 표면 선택/산업 모드는 독립적으로 유지한다.
- **[D-096/임시 공식]** 태양–행성40 + 행성–위성55 = 라그랑주95점을 추가한다. L3/4/5는 현재 부모 좌표계에서 반/±1/6주기 위상, L1/2는 M1b 지시서의 행성권·위성궤도·이웃간격 계수를 따른다. 질량 기반 실제 라그랑주 계산은 아니다. 필요하면 안전 여유 밖으로 밀고 진단을 반환한다.
- **[표시·정위치 임시]** 이동 선택 중에만 라그랑주 마름모를 표시한다. 항성계에서는 태양–행성, 행성 확대에서는 해당 위성 쌍을 표시한다. 이름은60gAU 이내 근접/키보드 포커스에서 보인다. 도착 후 holdingAt에점ID를 저장하고 함께 움직인다. 궤도 점은 현재 표시 층만 GPU Points 한 번으로 강조하며 DOM점을 만들지 않는다.
