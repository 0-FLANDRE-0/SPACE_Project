# 미결정 사항과 후속 연결

이번 PR은 자원/패키징 기반이며 가격·원가·발전 수치·연구 수치의 채택이나 ECON-SIM-4 합격 보고가 아니다.

## 결정하거나 연결해야 하는 항목

| 항목 | 현재 | 후속 |
|---|---|---|
| 정식 패키징 소재량/회수율/안전성 | 미정; 기본 유료 규격0개 | 승인된 새 immutable spec ID 등록 |
| 포장 전력·직접 C 비용 | null이면 활성화 거부 | 생산/재포장 원가로 별도 승인 |
| 수소 시장 가격 | 기존 후보 유지;0.4/1.2 채택하지 않음 | ECON-SIM-4에서 독립 비교 |
| 포장 처리 설비/시간/능력 | 큐 API만 제공; live 기본null | 실제 설비 처리능력/작업량 주입 |
| 행성 통합 전력 공급 | 명시적 energyWh 입력; 실시간 공급자 미연결 | 발전/전력망 에너지 실제 인도 연결 |
| 정부/민간 포장 예산 | 정부의 명시 국고→현지 이체 구현; 민간 금융 미연결 | 행성/소유자별 허용 재원 검증 |
| 기술 해금 | injected availablePackageSpecs(ownerId) | 연구 완료와 승인 규격 ID 연결 |
| 재포장 미래 소비/경제성 | 예측/이익 미정이면 대기 | 실제 소비 스케줄/비용 편익 제공 |
| 기타 자원 질량 | residue/물/산소/특수 자원 null 또는 미등록 | 자원 정의 승인 후 사용 |
| 원광을 산업 포장 소재로 사용 | 품질 lot 어댑터 미연결로 명시 보류 | 품질/출처 보존 차감·회수 정책 |
| 저장시설/함선/물류 | 동일 U 용량 함수, 계정 이전 API | 실제 시설 한도·배송·무역의 원자적 인도 |

샘플 소재50Q/1,000Q, 회수90%는 테스트에만 존재한다. 고급 소재·여러 재료·다른 액체를 사용하는 사례도 테스트 가상 정의이며 공식 새 자원이 아니다. 자동 개선은 enabled:true이지만 미결정 입력이 있으면 대기하며 연구 직후 재고를 바꾸지 않는다.

## ECON-SIM-3 물리 해석의 후속 수정 — 지금 재계산하지 않음

기존3차의 `물9U → 수소1U + 산소8U`는 **자원별로 U당 질량이 달라진 이번 규격에서 그대로 질량 보존식으로 사용할 수 없다**. 기존 파일·테스트·산출물·해시는 원래 검증 가정의 기록으로 보존한다.

새 수소1U=500kg 기준에서 손실 전 물 분해 양론은 다음과 같다.

```text
물 약4,500kg → 수소500kg + 산소 약4,000kg
```

물/산소의 U당 내용물 질량이 미정이므로 이를 물9U/산소8U로 환산하지 않는다. **수전해 공정 에너지와 포장/액화·보관 소재/전력/C는 별도 비용**이다. 후속 ECON-SIM-4에서 질량 기준의 공정 수지와 두 비용 경계를 새로 정의해야 한다.

정상 핵융합2.5U/월 및 기동/건설 각5U, 제련 보조85U/월, 광업 부산물100U/월, 제련 건설120U는 변경하지 않았다. 물리 해석을 바꿨다는 이유로 기존 경제 합격/실패 판정을 재승인하지 않는다. 정격출력 변경, 신규 식민지 발전 용량 재보정, 발전/산업 투자 회수기간 계산도 이번 범위 밖이다.
