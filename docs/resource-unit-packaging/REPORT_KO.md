# 자원 단위 및 범용 패키징 기반 구현 보고

요청한 범위의 기반 구현과 현행 산업 연결, 세이브 이관, 회귀 검증을 완료했다. `feat/econ-calibration-sim` 원격 HEAD가 `f4bc5e46ad8952b8f6eb981692b32ef94ee1fc08`임을 작업 전/제출 전 확인했고, 별도 `feat/resource-unit-packaging-foundation` 브랜치에서 작업했다. 선행 PR을 병합하거나 main에 쓰지 않는다. 최종 PR/커밋은 제출 메시지에서 제공한다.

**ECON-SIM-4는 구현/실행하지 않았다. 정식 포장 소재비·전력비·C 비용·수소 가격 또는 연구 기술 수치는 채택하지 않았다.**

## 2. 적용된 단위와 현재 게임 동작

광석/합금1U=10,000kg, 수소1U=내용물500kg이다. 모든 물질1U는 동일한 화물/보관1U를 사용하며 포장 세대에 따라 공간이 줄지 않는다. 포장재는 추가 공간을 점유하지 않고 실제 묶인 질량에만 반영한다. 화폐는 C로 분리하고 다른 자원의 미정 질량은 null로 남긴다. 물/산소 U, m³ 상수, 가스 별도 공간 단위는 만들지 않았다.

현재 산업 개발 시나리오는 기존100,000C/합금10,000U/수소500U다. 광업/제련 건설비·기간·수율·처리량·램프업·조건부 수소 생산과 소비는 유지했다. 새로운 수소 질량 정의를 매장량/초기 재고 U에 곱하거나 나누지 않았다. 원광 품질 lot은 기존 경로를 유지한다.

기본 정식 유료 규격은0개다. 기존/초기/현행 신규 광업 수소는 `hydrogen-legacy-unpriced-v1`의 소재{}/회수0인 묶음으로 존재한다. UI에도 **미가격화 임시 호환**임을 표시한다. 나중에 승인된 규격을 연결하면 신규 생산은 최신 해금 규격으로 실제 소재·예산·전력을 지불한다. 부족하면 수소 원천을 깎거나 무료 규격으로 우회하지 않는다. 기존 재고는 소급 변경되지 않는다.

## 3. 실제로 동작하는 패키징 엔진

테스트 전용100U 수소를 포장하면 실제 합금5U·현금·전력을 차감하고,90% 회수의 전량 소비 시4.5U 반환/0.5U 손실을 기록한다. 다른 액체와 임의 소재2종도 같은 엔진으로 동작한다. 설명용 수치를 실제 기본 비용으로 등록하지 않았다.

구형 우선 소비, 규격별 묶음 병합, 일부 소비/회수 나머지, 동일 세대의 결정적 정렬, 신형 생산, 소유자/행성 이전, 원자적 재포장과 실패 시 완전 불변을 구현했다. 회수는 소재를 실제 보유한 현지 소비자에게 귀속된다. 소재/손실/현금/전력의 장부가 보존되어야 저장/실행할 수 있다.

자동 개선은 기본ON이나 실제 설비/처리량·미래 소비·순편익·전력·C가 미정이면 보류한다. 예약된 물량은 합계에 포함하되 재사용하지 못하고, 시간/처리량에 따라 정해진 묶음을 완료해야만 신형 재고로 바뀐다. 나중에 설비를 연결했을 때 과거 대기 시간이 무상 처리량으로 적용되지 않도록 했다. 무제한 즉시 치환은 없다.

## 4. 저장 호환과 원본 보호

v1의 기존 전체 필드는 이관 후 비교 좌표에서 정확히 동일하다. 수소 Q만 소재0인 legacy 묶음으로 연결하며 합금 회수를 만들어내지 않는다. 기존 키 namespace를 유지하되 payload schema2를 사용한다.

원본 백업: `space-project:resource-unit-packaging:backup:v1:<encoded industry key>:<raw fingerprint>[:collision]`. 원문 검증/변환 후 실제 적용 직전에 정확한 원문을 기록·재확인하며 다른 원문과 충돌하면 덮어쓰지 않는다. 백업이 거부되면 이관을 활성화하지 않는다. 반복 불러오기·저장/재로드로 재고가 중복 생성되거나 시험 자금이 다시 지급되지 않는다.

게임 실행은 여전히 개발 transient다. 저장소가 차단되어도 최신 정적 프리셋에서 실행되고 자동 저장/불러오기/마이그레이션을 하지 않는다. v1 파일의 명시 적용만 원본 백업을 요구하며 v2 파일은 저장소와 독립적으로 메모리에 적용할 수 있다. 새로고침하면 진행이 초기화되지만 이번 요청에 따른 수동 이관 원본 백업은 보존한다. 다른 프로젝트 데이터와 공식 Git 데이터는 변경하지 않는다. [자세한 이관 정책](SAVE_MIGRATION.md).

## 6. 미결정·후속 연결

정식 소재량/회수율/안전성, 포장 C/전력, 수소 가격, 처리 설비 능력, 행성 전력 실제 공급자, 민간 금융, 기술 해금, 미래 소비/재포장 순편익 계산, 물/산소/특수 자원의 U당 질량은 후속 결정/연결이 필요하다. 기본 유료 재포장이 대기하는 이유다.

산업 원광을 포장 소재로 쓰는 경로는 품질 lot을 유지하는 어댑터가 없으므로 명시 보류한다. 물류망·함선/창고 본 시스템도 미구현이며 공통 용량/소유권 이전 API만 제공한다.

**ECON3의 종전 물9U→수소1U+산소8U는 새 질량 보존식이 아니다.** 새 수소1U=500kg 기준의 손실 전 양론은 물약4,500kg→수소500kg+산소약4,000kg이다. 물/산소 U는 미정이며 수전해 공정 전력과 포장/액화·보관 비용은 분리해야 한다. 이 사항은 [후속 문서](FOLLOW_UP.md)에 명시했고 기존3차 파일·테스트·보고서·해시는 그대로 보존했다. 과거 결과를 이번 단위 규격에서 새로 경제 검증한 것으로 보고하지 않는다.
