## 실제 제공하는 흐름

SPACE 로고 5초 안 7회 → 천체 정보의 표면 지도 → **자동 설정**. 지형·육해 / 환경 / 매장지 / 인구·문명 / 도시화·기반시설을 독립 선택합니다. 전체/복수 선택/미설정 필드 범위와 시드·프로필·상위 총량을 설정하고 미리보기에서 작성 셀/변경 필드/보호값/총 U/POP/출처를 확인합니다. 검수 지도의 구역 클릭으로 이전값과 예정값을 비교합니다. 확인 체크 후 한 번에 적용하고 Undo 또는 기존 v1 JSON 파일을 사용합니다.

지도는 육해·지형·광석·인구·도시화·미설정의 6개 레이어를 제공합니다. null은 회색, 실제 0은 남색으로 구분합니다. 범례에 단위·min/max·미설정 셀 수와 지형별 색을 표시합니다. 검수 레이어는 개발자 전용이며 종료하면 폼/비공개 값/색상 메시/미리보기를 정리합니다.

기본은 **fill-unset**입니다. `0명`, `1명`, `0/1` 육해 쌍, `[]` 매장지/시설, 기존 광맥과 knowledge를 보존합니다. 육지/물은 함께 변경합니다. 명시적 덮어쓰기는 별도 정책을 선택하고 미리보기·확인 후 이전 v1 JSON을 다운로드하며 기존 저장소 백업·Undo도 사용합니다. 보호할 지식이 사라질 광맥을 참조하면 덮어쓰기도 검증 거부합니다.

## 프로필·시드·입력값

기본 시드는 `{systemId}:{bodyId}:surface-data:v1`입니다. 타일/필드/자원/일련번호 키를 나누어 생성하며 호출 순서나 카메라·세계 시계에 의존하지 않습니다. 새 시드는 사용자 버튼으로 `:next`를 붙이거나 직접 변경합니다. 기존 JSON은 새 생성기 버전이 생겨도 자동 교체하지 않습니다.

| Sol 대상 | 기본 프로필 |
|---|---|
| 수성 | 진공 암석 |
| 금성·화성 | 건조 암석 |
| 지구 | 해양 암석 + 선택 가능한 실제 육지 경계 |
| 목성·토성·천왕성·해왕성 | 대기 기준층 |
| 달·포보스·데이모스·이오 | 진공 암석 |
| 유로파·가니메데·칼리스토·타이탄·엔셀라두스·티타니아·트리톤 | 얼음 표면 |
| 메타데이터 없는 시험/외계 행성·위성 | 미지 암석 / 진공 위성 기본, 개발자 변경 가능 |

얼음 표면은 액체 해양으로 취급하지 않습니다. 대기 기준층은 육지·물 null이며 양의 광석 예산을 거부합니다. 알 수 없는 온도/방사선은 null입니다. 입력한 기온·거주성 등은 프로필 기반 게임용 가정이며 관측값/복사량 계산으로 설명하지 않습니다. 프로필은 지질학적 모델이 아니며 상세 환경은 수동 조정 가능합니다.

자원 총량과 인구는 기본 **빈칸(null)**입니다. 8,500 POP 같은 예시는 기본 프리셋에 등록하지 않습니다. 자원은 등록된 자연 U만 지원합니다. 1 U=10톤, 최소 분배 0.001 U=10kg, 목표/고정 매장량이 이 정밀도와 맞지 않으면 오류로 안내합니다. 자원 예산은 종류별 최대1e12 U, 인구는 최대1e12 정수 명수라는 기존 숫자 안전 한도 안에서 받으며 최종 밸런스 값이 아닙니다.

**예산은 항상 행성 전체 목표**입니다. 선택 영역 밖과 보호되는 기존 매장량/인구를 먼저 빼고, 선택 범위의 미설정 값에 잔여량을 분배합니다. 고정 총량이 목표보다 크거나 남은 목표를 넣을 유효한 셀이 없으면 전체 거부합니다. 이 규칙을 UI에도 표시해 선택한 셀마다 전체 예산을 반복 주입하지 않습니다. 같은 입력의 fill-unset 재실행은 광맥을 중복 생성하지 않습니다.

인구는 면적·육지·거주성·연속 정착 가중치와 선택적 중심 구역으로 배분하며 현실 인구 분포/2100 예측이 아닙니다. 소수 POP는 정수 명수로 변환하고 마지막 1명까지 합계를 보존합니다. 도시화/기반시설은 명시적인 정책을 선택했을 때만 생성합니다. 지식·시설·통치/점유 ID를 임의 완성하지 않습니다.

## 지구 자료와 저장 호환

Natural Earth **1:50m Land v5.1.2**, Public Domain. [원천·체크섬·가공 재현·한계](../../dist/data/planetary-generation/README.md). 259,200점의 구면 면적 가중 적분으로 92개 셀에 육해 비율을 만듭니다. 전체 타일 면적 가중 육지 약28.8472%이며, 경계 자료의 구면 적분 약28.7475%와 약0.10%p 차이입니다. 사하라·아마존·호주·태평양·대서양·남극 대표 좌표를 확인합니다. 런타임 외부 지도 API는 없습니다.

최종 게임 JSON은 schemaVersion1 / `planet-surface-template` 그대로입니다. 시드/프로필/원천/정책은 별도 `planetary-generation` sidecar 다운로드에 기록합니다. JSON export→import→export는 기존 validator와 SurfaceDrafts를 거칩니다. 로컬 초안·손상 원본 보존·저장 실패 경고·Undo·명시적 백업 정책을 우회하지 않습니다. `data/planet-surfaces/index.json`은 계속 비어 있습니다. 검토된 결과만 개발자가 명시적으로 manifest에 등록합니다.

[테라포밍 데이터 계약](../architecture/TERRAFORMING_DATA_CONTRACT.md)에 격자/초기 지질/2100 시나리오/미래 현재 상태의 소유권을 정의했습니다. 현재 환경 override나 잔량이 원래 광맥/초기 인구를 덮지 않는 순수 예제 테스트를 제공합니다.

## 범위와 한계

실제 테라포밍·채굴·성장·경제·전투·연구·탐사 타이머는 미구현입니다. 전체 항성계19개를 순회하여 독립 초안을 만들고 실패/취소를 분리하는 **공용 코어**는 제공하며, 전체 항성계 일괄 실행 드로어는 추가하지 않았습니다. UI에서는 천체 하나씩 검토/적용합니다.

색상 지도는 활성 천체 하나의 배치 메시1개를 추가합니다. 모드 변경은 위치 geometry를 재사용하고 색 버퍼만 갱신합니다. 계산은 Worker에서 수행하고 닫기/천체·시스템 변경/개발자 종료 때 terminate·세대 토큰으로 취소합니다. 실제 모바일 기기/GPU/사파리는 별도 검증 대상이며 작은 가로 화면에서는 폼 내부 스크롤이 필요합니다.
