# v0.5E.1 표면 지도·인구·이동 패널

기준 PR #7 HEAD `ec242b340f7938d14d77dc96cb594b70ae5feb27`. 사용자가 첨부 지시서를 확인한 뒤 대화에서 구현을 승인했다. 후속 브랜치는 `feat/v0.5e1-surface-population-overlays-ui`이며 PR base는 PR #7의 브랜치다. main/선행 PR 병합·리베이스·강제 푸시와 새 ZIP 생성은 하지 않는다.

## 사용자 흐름

- 천체 → 표면 지도. 처음에는 기존 기본 표면이다. 상단 **매장량(알려진) / 인구 분포 / 시설 분포** 중 하나를 선택하고, 같은 버튼을 다시 누르면 기본 표면으로 돌아간다. 모드가 선택·카메라·건설·산업 상태를 취소하지 않는다.
- 실제 섹터를 누르면 기존 좌측 정보/우측 정부 구획/우측 하단 실적·재고가 열린다. 구획 재선택·뒤로가기·X와 산업의 건설/증설/개량/수소 토글을 유지한다.
- 제목바의 버튼 이외 부분을 마우스/터치로 7px 이상 끌어 이동한다. 제목에 포커스 후 방향키(Shift면 5배)도 가능하다. **↺**는 위치 초기화다. 본문은 계속 스크롤하고 외부에서는 지도 조작을 유지한다.
- DEV → **자원/자동 설정/표면 편집/JSON 파일**에서 기존 원본 도구에 접근한다. 일반 상단에는 분포 버튼3개와 뒤로가기·천체 정보만 남긴다. DEV 원본 지도는 명확히 배지를 표시한다.
- 기존 로컬 지구 인구가 새 공식 분포와 다르면 일반 정보의 **인구만 변경 미리보기**에서92개 전/후 POP를 비교할 수 있다. 동의 전에는 변경하지 않는다. 적용은 표면과 산업 저장을 함께 백업하며 인구만 바꾼다. 비교 JSON은 인구만 담고 지질 원본을 노출하지 않는다.

## 수치와 인지의 분리

`confirmedOreAtTile()` 하나로 일반 지도·범례·섹터 정보를 계산한다. 정적 확인 비율 또는 명시적 런타임 확인량에서 `oreExtracted`만 차감한다. 숨은 원천/실제 미발견 잔량/실제 최대값을 스케일에 넣지 않는다. 접근 기술과 최소 개발량은 광산 건설에 쓰는 별도 조건이며 일반 지도 값의 필터로 쓰지 않는다.

양수 확인량이 없다는 사실은 자원 부재의 증거가 아니다. 현행 저장에는 음성 조사 기록이 없어 무인지·확인 소진 셀도 회색으로 둔다. 후속 탐사에서 명시적으로 제공할 수 있는 읽기 전용 negative-evidence 입력만 확장점으로 남기고 현재 게임에는 임의 기록을 만들지 않는다. 탐사 티어100%도 부재 증거로 쓰지 않는다.

인구0은 검정, null은 회색이다. 저장은 정수 명수를 유지하고 일반 정보·범례는 POP로 표시하며 1명도 `0.000001 POP`로 구분한다. 시설은 실제 소유 정부의 `facilityInstances`만 읽고 빈/잠긴 슬롯·초기 시설 메타데이터를 합산하지 않는다. 건설/가동 준비/가동/정지·고갈의 외곽선과 범례를 구분한다.

양수 분포는 원래 섹터값의20/40/60/80 분위 경계를 만들고 중복 경계를 합친다. 동률을 억지로 나누지 않고 실제 사용되는 비어 있지 않은 구간만 표시한다. 값 종류가 적으면 단계 수가 줄어든다. 품질/난도/확인율은 각각0–1/0–100/0–1 절대 스케일이다. 0과 null은 모든 단계 처리에서 분리한다.

DEV 원본이 열린 동안 일반 모드 선택 상태는 기억하되 DEV가 색 버퍼를 소유한다. 닫으면 일반 레이어를 복원한다. 모드/자료 참조/실제 산업 틱 변경 시만 갱신하고 매 프레임 값을 재생성하지 않는다. 양수 색상 메시와 색 버퍼는 모드 전환 중 재사용한다. 일반/DEV 색은 투명한 황색 지형 합성에 묻히지 않도록 불투명 오버레이를 사용하며 선택 테두리를 위에 그린다.

## 저장 안전성

`templateSignature()`를 무시하거나 산업 스키마의 무결성 검사를 약화하지 않았다. 지구 전체 서명은 **8d236561 → 52cbc980**이며 인구만 바뀌었음을 사전에 재현했다.

- 자동 이관 대상은 old 공식 서명8d236561, 현재 new 공식52cbc980, 정확한92개 이전/신규 인구 맵과 패키지 버전이다. 신규 템플릿에서 이전 인구만 되돌렸을 때 구공식 서명이 되는지도 확인한다.
- 전체 산업 상태의 기존 엄격한 검증이 통과한 뒤 raw 원본을 산업 키의 `:population-e1:backup`에 보존한다. 다른 내용의 기존 백업이 있으면 덮어쓰지 않고 멈춘다. 그 뒤 `sourceSignatures.earth` 하나만 바꾼 상태를 저장한다. 이벤트/시설/잔량/배치/재고/장부/시간/fixture·정식 구분을 새로 만들지 않는다. 백업 저장 실패 시 원본은 보존하고 진행을 격리한다.
- 다음 로드는 이미 new 서명이므로 다시 이관하거나 재지급하지 않는다. 다른 천체 서명·임의 지질·알 수 없는 스키마는 기존대로 격리한다. 상태 스키마는1 그대로이며 이번에 허용한 정적 소스 전환은 `ghsl-e2025-earth92-v1`로 명시한다.
- 로컬 표면 초안은 계속 공식 프리셋보다 우선한다. 자동 수정하지 않는다. 명시적 인구 적용은 현재 표면과 산업이 같은 원본을 참조하는지, 인구 외 필드가 동일한지 먼저 검증한다. 수동 지질이 있는 로컬 초안도 그 지질 자체는 바꾸지 않는다.
- 수동 적용은 두 원본의 별도 `:population-e1:{oldSignature}:backup`을 만든 후 두 주키를 쓴다. 두 번째 쓰기 실패 시 첫 쓰기를 원상 복구하고 메모리는 바꾸지 않는다. 복구 쓰기마저 실패하면 저장을 격리하고 남은 백업 경로를 알린다.
- 두 키 이관 뒤 표면 한쪽만 되돌리는 Undo는 만들지 않는다. 해당 이관의 `entry.previous`를 비우고 복원은 두 백업을 사용하는 절차로 안내한다. 이후 일반 편집의 Undo는 기존대로 동작한다. 원본 비교/백업과 별도 산업 파일 가져오기는 유지한다.

브라우저 localStorage에는 다중 키 원자적 트랜잭션이 없으므로 탭/기기 강제 종료가 두 주키 쓰기 사이에 발생하면 두 백업으로 복구해야 할 수 있다. 일반 실패의 보상 쓰기와 원본 보존은 검증했으며 이 강제 종료 창을 완전한 DB 트랜잭션으로 주장하지 않는다.

## 보존 및 후속 항목

기존 산업 생산·건설/투자 비용·시간·슬롯·수율·수소·시계의 `industry-runtime.js`, `industry-policy.js`, `model.js`, `time-control.js`는 바이트 불변이다. 지구 외18개 정적 프리셋과 원본 사용자 지구도 불변이다. 지구의 인구 이외 모든 필드는 유지한다.

인구 가중 도시화율은 기존 섹터별 도시화율을 보존한 결과51.29%로 달라졌다. 도시화·인프라 분포 보정은 후속 결정이다. 1km 픽셀 중심 배정·광역92셀의 공간 해상도, 현재 음성 자원 조사 증거 없음, 실제 모바일/Safari 미검증 범위를 [출처](POPULATION_SOURCE.md)와 검증 보고서에 명시한다. 새 경제/연구/전력/물류/민간/함선 시스템은 추가하지 않았다.
