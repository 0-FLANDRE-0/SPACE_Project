# 결정과 프로토타입 가정

## 현재 사용자 지시

- HTML 기반, Three.js로 3차원 지도 표현. 최종 함선은 2D 그림의 윤곽에 두께를 주는 방식을 검토 중이며 아직 구현하지 않음.
- 이번 빌드는 황색 항성 기반 모항성계. 태양계를 바탕으로 지도부터 구현.
- 행성은 천천히 공전. 선택하지 않은 궤도는 희미하게, 선택한 천체의 궤도는 선명하게 표시.
- 행성·위성·소행성대와 입체적인 위치 관계를 관찰할 수 있어야 함.
- 새 지시가 초기 인계서보다 이번 작업 범위를 좁힘. 탐사·건설까지 한 번에 구현하지 않음.

## 구현 방식

1. 프레임워크·번들러 없는 정적 ES 모듈. 실행·수정이 간단하고 게임 상태와 렌더링 책임을 파일로 분리할 수 있음.
2. Three.js 0.170.0과 OrbitControls를 저장소에 포함. 런타임 CDN 모듈 의존성을 없애고 버전 고정. 폰트는 실패해도 동작하는 선택적 외부 자원.
3. 모바일 가로 화면을 기준으로 카메라 조작·천체 목록·접이식 정보 패널을 배치. 세로 화면도 기본 조작은 가능하나 우선 대상은 가로 화면.
4. 월드 1단위 = 1 AU. J2000 황도 좌표의 오른손 기저를 `(x,z,-y)`로 변환. 이전 버전의 비선형 거리 압축을 제거함.
5. JPL Table 1의 시간 변화가 있는 궤도 요소와 근일점 인수까지 적용. 위성은 2026-10-29 JPL Horizons 접촉 요소를 기준으로 전개. 시작 날짜를 기존 임시 2200년에서 자료 유효 구간 내로 변경함.
6. IAU PCK 극 방향·자전율·주기항을 사용. 축 프레임 아래 로컬 자전 노드를 분리하고 토성 고리도 적도면에 배치. 자세와 자전을 같은 Euler 회전에 섞지 않음.
7. 화면 중심 깊이를 기준으로 AU/km/m 눈금을 자동 전환. 실제 거리와 별개인 먼 천체 표시 크기 보정은 유지하며 표면 접근 시 실제 반지름 사용.
8. 지구 대륙은 실제 표면 지도. 다른 행성도 실재 특징을 가진 Solar System Scope의 CC BY 4.0 지도를 사용하고 게임 조명·대기 효과를 적용. 일부 위성은 달 표면 재사용.
9. 모행성 추적 카메라는 거리 규모를 로그 보간해 항성계에서 표면으로 연속 접근. 표면과 주변 궤도에 각각 접근 버튼 제공.
10. 이 빌드는 브라우저에서 실행. 백엔드·계정·DB 없음. 기존 비공개 Sites와 GitHub 작업 저장소를 유지.

자료와 구체적 근사 한계는 [SOURCES.md](SOURCES.md)에 기록.

## 이후 구현할 이동 구상 — 이번 빌드에는 없음

- 함선은 천체·소행성·지점을 목적지로 이동하며, 도중에 정지하고 새 명령을 받을 수 있음.
- 출발 행성이 목적지를 가리면 행성 표면 방향의 이동점을 생성하고 그 지점 상공으로 돌아 나옴. LOS 확보 후 행성 간 이동으로 전환.
- 항성계 항로의 다른 행성·항성이 경로를 막으면 플레이어가 자동 우회 버튼 또는 수동 경유점을 선택.
- 행성 화면의 표면 클릭을 해당 방향 상공 이동과 연결하는 방향. 고도·감속·도착 조건 등 상세 수치는 추후 결정.
- 입체 공간을 이용한 채굴·거점·물류 입지는 후속 설계 대상.

## 아직 결정하지 않은 것

최종 게임 시간 비율, 함선 미술 방식, 이동·충돌 모델, 실제 궤도 운동 적용 정도, 영구 저장, 건설 UI, 싱글/멀티플레이의 최종 범위는 이 지도 프로토타입으로 확정하지 않음.
