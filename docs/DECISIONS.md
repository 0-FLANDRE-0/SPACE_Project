# 결정과 프로토타입 가정

## 현재 사용자 지시

- HTML 기반, Three.js로 3차원 지도 표현. 최종 함선은 2D 그림의 윤곽에 두께를 주는 방식을 검토 중이며 아직 구현하지 않음.
- 이번 빌드는 황색 항성 기반 모항성계. 태양계를 바탕으로 지도부터 구현.
- 행성은 천천히 공전. 선택하지 않은 궤도는 희미하게, 선택한 천체의 궤도는 선명하게 표시.
- 행성·위성·소행성대와 입체적인 위치 관계를 관찰할 수 있어야 함.
- 새 지시가 초기 인계서보다 이번 작업 범위를 좁힘. 탐사·건설까지 한 번에 구현하지 않음.

## 구현 방식

1. 프레임워크·번들러 없는 정적 ES 모듈. 실행·수정이 간단하고 게임 상태와 렌더링 책임을 파일로 분리할 수 있음.
2. Three.js 0.170.0과 OrbitControls를 저장소에 포함. 런타임 CDN 모듈 의존성을 없애고 버전 고정. 폰트는 실패해도 동작하는 선택적 외부 자원.
3. 월드 좌표는 XZ 기준면, Y 높이. 타원 궤도를 경사각과 승교점 방향으로 변환. 카메라 투영과 독립적인 3D 좌표.
4. Kepler 방정식으로 공전 위치를 계산하되 실제 중력·N체·정밀 천체력 계산은 하지 않음. 공전 주기 비율은 참고값, 기본 속도는 초당 시뮬레이션 0.18일.
5. 태양계 궤도면은 원래 대부분 비슷함. 인위적으로 크게 경사를 바꾸지 않았으며 측면 보기와 황도 기준면으로 고도 차이를 관찰할 수 있음.
6. 행성·위성의 표시 반지름과 궤도 크기는 시각화 전용 값. 실제 정보와 별도 필드이며 최종 게임 밸런스가 아님.
7. 달, 화성 위성 2개, 갈릴레이 위성 4개, 토성 위성 2개, 천왕성과 해왕성 위성 각 1개를 대표로 표시. 전체 위성 목록은 아님. 위성 궤도는 단순화한 기준면과 경사값을 사용.
8. 소행성대 입자는 시드 기반으로 생성한 3D 군집. 성능을 위해 InstancedMesh를 사용하며 각 입자의 독립 궤도·물리·상태는 아직 없음.
9. 이번 지도는 브라우저 안에서만 실행. 백엔드·계정·DB가 필요 없음. Sites는 비공개 시연용 배포, GitHub `0-FLANDRE-0/SPACE_Project`는 작업 코드 저장소.

## 이후 구현할 이동 구상 — 이번 빌드에는 없음

- 함선은 천체·소행성·지점을 목적지로 이동하며, 도중에 정지하고 새 명령을 받을 수 있음.
- 출발 행성이 목적지를 가리면 행성 표면 방향의 이동점을 생성하고 그 지점 상공으로 돌아 나옴. LOS 확보 후 행성 간 이동으로 전환.
- 항성계 항로의 다른 행성·항성이 경로를 막으면 플레이어가 자동 우회 버튼 또는 수동 경유점을 선택.
- 행성 화면의 표면 클릭을 해당 방향 상공 이동과 연결하는 방향. 고도·감속·도착 조건 등 상세 수치는 추후 결정.
- 입체 공간을 이용한 채굴·거점·물류 입지는 후속 설계 대상.

## 아직 결정하지 않은 것

최종 거리·시간 비율, 함선 미술 방식, 이동·충돌 모델, 실제 궤도 운동 적용 정도, 영구 저장, 건설 UI, 싱글/멀티플레이의 최종 범위는 이 지도 프로토타입으로 확정하지 않음.
