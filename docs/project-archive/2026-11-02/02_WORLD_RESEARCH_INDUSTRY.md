# 02. 게임 철학·세계·표면·산업·연구·사회

> **출처 구분:** 2026-11-01 종합 인계서와 이전 기획 11번, GitHub PR #1~#9의 기능 보고 및 현재 PR #13에 포함된 산업 코드. 아래의 [방향 결정]과 [구현 확인]은 다르다.

## 전체 게임의 성격

- **[방향 결정]** 2100년 무렵 인류가 태양계에서 시작해 달·화성의 작은 식민지를 개발하고 다른 항성계로 진출하는, 수십~수백 년 규모의 우주 문명/경제/전략 게임.
- **[방향 결정]** 정부는 국영 시설·함대·전략 투자·연구·징발을 직접 결정. 민간 경제는 자율적으로 생산·수급·투자하며 합성적으로 모델링. **GDP 전체는 정부 국고가 아님.**
- **[방향 결정]** 함선/산업은 수량만 늘리는 소모품보다 실제 제작시간, 자원, 유지보수, 기술, 전력, 재고 위치와 수리·개수에 의미를 둠. 거대 프로젝트로 시장이 흔들리는 사건은 사전 지정된 실패 이벤트가 아닌 **경제의 인과적 결과**여야 함.
- **[방향 결정]** 내적 모델은 복잡할 수 있지만 UI는 과도하게 복잡하지 않도록. 수백만 공컨테이너 객체를 사용자가 직접 관리하게 하지 말 것.
- **[지향점/미정]** 2100~2300 약 200년, 연구 시대 I~VI, 성간 접촉·식민지 독립·정치·원정·분쟁. 시대 진입 연도/의무적 메인 스토리는 미확정. Claude가 제안한 기계문명 침공은 확정된 스크립트가 아님.

## 서로 다른 세계 좌표·지도를 구분

| 층위 | 뜻 | 구현·설계 |
|---|---|---|
| 자유 3D 공간 | 천체/미래 함선 항행·관성·전술 기동 | 현재 천체 뷰어 존재, 함선 실기동 미구현 |
| 항성계 평면 육각 | 우주 지도·행정 구획 | 초기 3링 37셀, 반경 210 **게임 AU**의 셀 구상. 실제 물리 이동의 장벽이 아님 |
| 행성/위성 표면 | 별도 구면 오각·육각 셀 | Sol19 천체 프리셋, 지구92셀; 오각형12개를 포함한 구형 격자, 표면 이웃 그래프 |
| 정적 프리셋 vs 동적 게임상태 | 원래 지질·인구/초기 조건 vs 채굴 후 잔량·시설/손상 | 절대로 동일 장부로 뭉치지 않음 |

- **[구현]** PR #1~#6에서 천체 지도·행정·구면 셀·생성기·지질 프리셋을 순차 구축. PR #8에서 지구 인구 총 **8,893,000,000명**을 92표면 셀로 배분하고 자원·인구·시설의 3종 지도 표기 제공.
- 표면 '인접 1링'은 **구면 표면 셀의 실제 neighbor graph**임. 항성계 평면의 210게임AU 구획과 혼동 금지.
- 게임 AU와 현실 AU, 화면상의 world units는 구분. 역사적 지구100·화성142·목성280·토성420 게임AU 같은 게임 좌표는 실제 궤도 물리값이라고 해석하지 않음.

## 시간·세이브·개발 실행

- **[구현]** 기본 UI 1×는 현실 1초당 **게임 10초**. 전술 0.1/0.25/0.5/0.75/1×, 전략 1/2/5/10/50/100×의 시간 배속 정책. 요청 배속·실효 배속·cap·일시정지를 분리. 프레임 차이에 민감한 RNG/경제 적분을 피하는 방향.
- **[구현]** PR #9 이후 개발용 상태는 transient. 일반 자동 불러오기·자동 저장은 꺼져 있고 새로고침하면 시뮬레이션이 초기화. 명시적 JSON export/import, 과거 원본 보존/필요시 검증 이관은 별개.
- **[미구현/제안]** 오프라인 정산 1.25배·최대60게임일 등은 과거 기획이며 현재 게임 기능 아님.
- **[미정]** 정식 캠페인의 정확한 시작 UTC 날짜와 UI 배속/시간축 정합, 장기 저장 복구 정책.

## 지질·인구·정부 산업

- **[구현]** Sol 19개 천체의 지질·광맥·품질·발견/확인 지식을 분리. surface / vein / deep 등의 자원 원본과 실제 채굴 잔량/로트·인구를 별도 유지.
- **[구현]** 정부 건설 가능 구획은 각 행성 표면 셀별 **1~4 슬롯**. 시설 수준, 환경, 건설/확장·기술 개량·제한 조건과 실제 재고·건설기간을 반영한 개발 런타임.
- **[구현/산업 초기 계약]** 정부 광업 단지: **14,500C + 합금1,200U**, 6개월, 최대 **광석5,000U/월**(현장 난도·램프업·유한 원천의 영향을 받음).
- **[구현/산업 초기 계약]** 정부 제련 단지: **24,500C + 합금3,150U + 수소120U**, 8개월. 무수소 약4,348U/월 처리, 수소 보조 시 최대5,000U/월, 수소 소비 최대85U/월, 처리량 향상 최대15%.
- **[구현]** 품질 low/medium/high의 **합금 산출 비율 14/33/52%**. 수소 보조는 처리 속도를 높이지만 해당 수율을 바꾸지 않음.
- **[구현]** 광업 부산물 수소는 실제 동일 표면 셀의 유한 수소 원천과 생산 활동이 있을 때만 최대 **100U/월**. 무한 생성 금지.
- **[구현]** 광석 원산 광맥·난도·품질을 로트로 기록하고 제련이 소비. 최신 PR #13은 로트를 SCU 현지 봉인/개봉과 원자적으로 연결; 포장된 원광은 제련에 즉시 사용 불가.
- **[개발 fixture 한정]** 지구정부 **100,000C + 합금10,000U + 수소500U** 일회성 시험 시작 재고. 정식 캠페인의 무상 시작 재고가 아님.
- **[미구현]** 시설의 실제 게임 `powerDemandMW`, `monthlyOperatingCostC`, `laborDemandPersons`는 기존 산업 런타임에서 여전히 `null`. ECON-SIM-3의 전력·운영비 모형은 오프라인 검증일 뿐 실게임 연동 완료가 아님.
- **[방향 결정]** 완공 산업·발전·저장 시설은 정지해도 합금 유지보수가 0이 아니어야 함. 실제 연간 비율은 ECON 검증에서 미확정.

## 연구 시스템: 기획과 런타임을 구별

**[방향 결정/게임 본체 미구현]** 당기 연구력, 학문 분야 누적지식 K, 개별 연구 과제 진행도는 서로 다른 값. 발견/연구 가능/연구 완료와 이론→심화→실현 과정을 구분. 돈·시료·현장·연구시설 부족은 '실현 대기'이지 실제 실험 실패가 아님.

- 2026-10-31 테크트리 JSON 초안의 **3대 분류(물리학/사회학/공학), 19개 분야**, 노드13/관계20은 당시 인계자료에서 보고된 구조. **현재 별도 JSON 원문을 재확인한 것은 아님.**
- 분야 예: 컴퓨터공학·입자물리학·역장 조작·에너지·항행·양자역학·천체행성학 / 생물학·군사이론·국가운영·식민지학·경제학 / 재료공학·추진공학·우주역학·산업공학·물류공학·조선공학·거대구조공학.
- 12단계 **초안** K 상한: I 1,000; I+ 1,500; II 3,000; II+ 5,000; III 8,000; III+ 10,000; III++ 12,500(선택); IV 25,000; IV+ 35,000; V 60,000; V+ 100,000; VI 300,000.
- 새 기술 해금은 새 부품/규격 제조 권한이지 기존 함선·용기·설비의 무료 개조가 아님. 실제 연구 기간·실험 확률·분야 성장곡선·연도 배분은 미정.

## 사회·정치·행성 개척 — 대부분 후속

- **[기획]** 달 약 20만 명, 화성 약 5만 명은 초기 식민지 **잠정 초안**. 생명유지·전력·보급·노동·정치안정과 연결해야 함.
- **[기획]** 인구 성장·세수·민간 자율 확장·징발 불만·독립/반란·탐사·테라포밍·행성 지상 작전은 장기 개발 분야. 현재 코어 게임의 완성된 사회/전쟁 시스템이라고 부르지 않음.
- **[기획]** 위치별 자원 부족, 함대 수리비, 전력 공급 실패가 사회 위기를 낳을 수 있어야 하되 사전에 '무조건 파국'인 이벤트로 만들지 않음.
