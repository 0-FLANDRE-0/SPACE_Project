## 새로 아직 결정하지 않은 것

- 식민지 소형 핵분열/태양광 모듈의 정격, 기반 비용, 공기, 연료, 저장, 유지보수. **50/100/250MW 등은 예시 제안일 뿐.**
- 광석의 실제 벌크 밀도별 4SCU/U 물리 인증/화물 강도, 모든 특수 자원의 kg/U·SCU/U.
- 산업·발전 정식 전력 소비, C 운영비, 합금 유지비, 수소 신원가와 정상시장가.
- HAC와 타이탄의 정확한 외형/선체 형식/세부 두께·건조비·모듈·추력·전투 확률 및 AI.
- 실제 물류 운임·시간·경로·섹터 네트워크·수송 하중과 배송 ID/도착 공급자.
- ECON-SIM-4 합격 기준 중 **사용자 최종 승인 전 제안 수치**, 경제 검증 모델의 공식 채택값.

**변경 규칙:** 위 '확정'을 수정하면 새 사용자 발언·날짜·근거를 기록하고 이전 값은 지우지 말고 [대체]로 이동. 모델이나 Claude가 보기 좋게 만든 숫자를 플랑의 결정으로 승격하지 말 것.
