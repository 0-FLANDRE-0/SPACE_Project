# 03. U·SCU·컨테이너·광석 로트·미래 물류

> **최신 확인:** [PR #13](https://github.com/0-FLANDRE-0/SPACE_Project/pull/13) · [PR #12](https://github.com/0-FLANDRE-0/SPACE_Project/pull/12). 이것은 **포장·현지 보관 기반**이지 실제 행성/수송선 배송 완성이 아님.

## 단위 — 오래된 'U=공간' 설계를 덮어씀

| 항목 | 의미 | 계약 |
|---|---|---|
| U | 자원 생산·재고·소비량 | 자원별 kg/U는 다를 수 있음 |
| Q | 원장 정밀도 | **1Q = 0.001U** |
| SCU | 운송·보관 **외형 공간** | **1SCU = 한 변이 1.25m인 정육면체 외형 = 1.953125m³** |
| C | 크레딧 | 거래/임금/건설 비용; U/SCU와 합산 불가 |
| POP | 인구 표시 단위 | 1POP=100만 명 |

**정확히:** `1SCU = 1.25m × 1.25m × 1.25m = 1.953125m³`. SCU는 컨테이너의 **개수**가 아님. 32SCU 1개와 8SCU 4개의 합산 외형점유량은 32SCU로 같지만 제작자재 비용은 다름.

| 자원 | 내용물 질량 / 1U | 장거리 SCU / 1U | 현재 해석 |
|---|---:|---:|---|
| 광석 `ore` | **10,000kg** | **4SCU** | 사용자가 이번 대화에서 합금과 동일한 4SCU 적용 재확인. 개별 원광 벌크 체적의 물리 인증은 별도 |
| 합금 `alloy` | **10,000kg** | **4SCU** | 금속을 통합한 추상 산업 자원 |
| 수소 `hydrogen` | **500kg** | **8SCU** | 극저온·단열을 포함한 외형 공간 |
| 물 `water` | **4,500kg** | **4SCU** | **[사용자 확정 2026-11-02]**, 게임 코드 미등록(아래 Claude 보충 절) |
| 산소 `oxygen` | **4,000kg**(액체) | **4SCU** | **[사용자 확정 2026-11-02]**, 게임 코드 미등록 |
| 잔여물/반물질/아스트로지늄 | 미정 | 미정 | 임의 환산·운송 거래 금지 |
| 크레딧 `credits` | 화폐 | 해당 없음 | 물리 화물 아님 |

'모든 U는 10톤', '모든 U가 1공간 U', '1U=10m³', 합금 90톤/U, 수소 100kg/U 또는 1톤/U 등 과거 아이디어는 현재 유효 규칙이 아님.

## 표준 7종 컨테이너 [현재 구조 규칙]

| 규격 | 외부 치수 m | 외부 부피 m³ | 합금 제작 소재 U/개 | 개봉 후 합금 회수율 |
|---:|---|---:|---:|---:|
| 1SCU | 1.25×1.25×1.25 | 1.953125 | **0.025** | 90% |
| 2SCU | 2.5×1.25×1.25 | 3.90625 | **0.045** | 90% |
| 4SCU | 2.5×2.5×1.25 | 7.8125 | **0.085** | 90% |
| 8SCU | 2.5×2.5×2.5 | 15.625 | **0.160** | 90% |
| 16SCU | 5×2.5×2.5 | 31.25 | **0.270** | 90% |
| 24SCU | 7.5×2.5×2.5 | 46.875 | **0.370** | 90% |
| 32SCU | 10×2.5×2.5 | 62.5 | **0.450** | 90% |

- **[구현 확인]** 실제 코드 `STANDARD_CONTAINERS`의 소재 값은 25/45/85/160/270/370/450Q; 정확한 외형은 위와 같음.
- 빈 컨테이너를 별도의 상품·일련번호·반송 재고로 관리하지 않음. **내용물과 묶인 포장 소재를 갖는 상태/집계 그룹**으로만 추적.
- 컨테이너 제작 시 실제 소재 U는 자유 재고에서 빠지고, 개봉 시 **그 컨테이너에 실제 묶여 있던 소재** 기준으로 90%를 반환. 나머지10%는 물질 손실. 과거 100% 회수 정책과 8SCU 0.05U 재료비는 폐기.
- 소재 레시피는 미래 복수 재료·세대·특수보관 추가를 지원할 수 있음. 연구 완료만으로 이미 존재하는 상자의 묶인 재료가 바뀌지 않음.
- 작은 화물도 표준 1SCU 용기 1개 전체 제작 소재를 지불. **부분 적재=일부 포장재 면제**가 아님.

## 합금으로 합금 포장: 보존식 예

- 합금 내용물 **8U = 32SCU**. 32SCU 컨테이너 **1개** 제작에 합금 **0.450U** 추가.
- 최초 자유 합금 **8.450U** → 봉인 중 내용물8U + 묶인 소재0.450U.
- 최종 개봉 시 내용물8U + 회수0.405U = 자유 합금 **8.405U**, 영구 손실 **0.045U**.
- 같은 32SCU 선적의 용기 비교: 32×1 0.450U, 24+8 0.530U, 16×2 0.540U, 8×4 0.640U, 4×8 0.680U. **대형 용기 규모의 경제**, 단 소량 적재에서는 작은 용기가 이길 수 있음.
- 직접 C, 전력, 냉각/검사·하역비는 **미정 `null`**. 테스트용 예시 비용이 공식 생산가가 아님.
- **수소 기존 보관** `hydrogen-legacy-unpriced-v1`은 역사적 미가격화 패키지이고 구조재0/회수0. 정식 유료 SCU 운송용기로 소급 둔갑하지 않으며, 산업 보관/운송 포장 비용의 **이중 청구 금지**.

## HAC 합금 58,000U를 모두 장거리 선적할 경우 — 이번 대화의 계산 예

> **[가상 물류 예시]** HAC의 58,000U 합금 투입은 과거 **잠정 건조량**임. 실제 항로/건조/공급망이 존재한다고 말하지 말 것.

| 계산 | 값 |
|---|---:|
| 내용물 합금 | 58,000U = 580,000톤 |
| 내용물 공간 | **232,000SCU** |
| 표준 32SCU 상자 | **7,250개** |
| 상자 제작용 추가 합금 | **3,262.5U** = 32,625톤 |
| 개봉 후 회수 합금(90%) | **2,936.25U** |
| 상자 소재 영구 손실(10%) | **326.25U** |
| 외형 총부피 | **453,125m³** |
| 내용물+용기 합금 질량 | **612,625톤**(기타 소재 제외) |

위 580,000톤은 함선 완성 질량도 아님. **투입 건조 소재의 질량**이며 함선 모듈/연료/공정손실을 거쳐 실제 질량을 따로 구해야 함.

## 운송 규칙은 결정됐지만 실제 배송 엔진은 없음

| 원 출발지→최종 목적지 | 표준 SCU 컨테이너 포장 | 실제 배송 상태 |
|---|---|---|
| 같은 표면 섹터 | 면제 가능 | 자동 이동/무료 운임 아님 |
| 실제로 연결된 인접 1링 표면 섹터 | 지역 공급망이 있을 때 면제 가능 | 배송비·시간 발생 가능 |
| 2링 이상 또는 다른 천체 | 필수 | 아직 배차/운송중/도착 처리 엔진 없음 |

인접 다중 홉으로 장거리 포장을 회피하지 못하도록 원래 출발/최종 목적지와 shipment ID를 계약으로 다룸. 새 원장 인도에는 외부 delivered 증명이 필요하지만 **실제 배송 공급자는 미구현**. 우주 화물창 출입구, SCU 적재, 적재질량/가속/하중 및 위험물 안전 인증도 미구현.

## Claude 보충: 물·산소 물리 규격과 수소 포장 개선 — **단위는 사용자 확정, 게임 코드 미적용**

**[사용자 확정 2026-11-02]** 산소는 액체 기준, 물은 실제 액체 부피와 질량을 기준으로 정하며, **아래 물/산소 U 정의(Claude 제안값)를 플랑이 같은 날 확정**했다. 단 **게임 `resource-definitions.js` 등록은 별도 후속 작업**이며 현재 코드에는 없음.

| 자원 | 현재/후보 kg/U | 현재/후보 SCU/U | 상태 |
|---|---:|---:|---|
| 수소 | **500** | **8** | 현행 구현 |
| 액체 산소 | **4,000** | **4** | **사용자 확정**, 코드 미등록 |
| 물 | **4,500** | **4** | **사용자 확정**, 코드 미등록 |

- 확정 단위로 물 **1U(4,500kg)** → 수소 **1U(500kg)** + 산소 **1U(4,000kg)**라는 **게임용 질량 보존 수지**가 된다. 현실 분자량을 소수점까지 엄밀히 맞춘 양론이 아니라 게임 자원 기준의 반올림(실제 0.504t+3.996t). **ECON-SIM-3의 물9U→H1U+O8U는 여전히 구형 가정**이다.
- 액체 산소의 실제 탱크 구조·압력/온도/단열과 수소 냉각비를 별도 평가해야 한다. 모든 포장 기술이 기본 SCU/U를 자동 줄이지 않는다.
- **[Claude 제안]** 슬러시 수소·수소저장합금 등으로 수소 화물 공간을 **8→6→4SCU/U**로 줄이는 기술 계보는 후보. **자원별 U·SCU 정의의 세대/특수 포장 효과와 실제 원가가 검증되기 전까지 구현값 변경 금지**.

## Claude 보충: 화물선 설계·SCU 물량 — 함선·배송 엔진은 아직 없음

- **[사용자 확정 방향]** **중앙 척추 골조형 화물선:** 선수 쪽으로 뻗은 골조에 32SCU(외형10×2.5×2.5m) 컨테이너를 길이 방향으로 적재하고, 선미 쪽에 기관/승무원 등 필요한 구조를 집중. 일반 척추형은 **우주 운용 전용(착륙 불가)이며 매우 느린 함선**. 별도의 소형 올라운더는 **착륙 가능**.
- 아래는 **사용자가 생각한 규모**와 **Claude 제안 수치**가 섞여 있는 기획 표다. 모두 실제 질량/추력/선체 강도·건조비 산출이나 현재 코드의 화물창 용량이 아니다. 32SCU마다 합금/광석 **8U**(화물 내용물80t)를 가정.

| 구상 | 컨테이너 개수 | 총 SCU | 광석/합금 U·내용물 톤수 | 상태·비고 |
|---|---:|---:|---|---|
| 소형 착륙형 올라운더 | **48** | **1,536** | **384U = 3,840t** | **[사용자 확정]** 착륙형, 약60~70m는 기획 구상 |

- **구상/제안:** 중형 가득 실은 합금 재화의 초기 참고 평가 `17,920U ×2.3C/U=41,216C`; 컨테이너 소재는 `2,240 ×0.45U=1,008U`. 성간 대형은 `69,120×2.3=158,976C`, 구조재 `8,640×0.45=3,888U`. **2.3C/U는 동적 시장의 정상 기준**, 실제 운임/선가/시장가격은 미정.
- **[Claude 제안]** 척추형은 노출된 상자 부분 손실·회수, 골조 교체·도주 시 컨테이너 투하, 웜홀 통과 허용 외형은 **만재 시 외곽 기준** 등으로 전술성과 비용을 부여할 수 있다. 전부 검증·확정 전 구상임.
- **[미정/미구현]** 실제 함선·적재중력/하중·최대 이륙 질량·우주항만·궤도 운송·도착 처리·항로 시간·연료·무기/탄약 화물. **탄약은 발 수량으로, 화물 적재는 SCU/질량으로 관리**한다는 방안은 아직 사용자 아이디어/Claude 제안 수준.
- **[사용자 진술]** 현재의 SCU 세계관 규격은 다른 우주게임의 화물 컨셉을 참고한 것이다. 본 게임의 원단위·물질/장부 구조는 별도 결정이며 새 명칭 제안은 확정 아님.
- 지표에서 궤도로 올라가는 운송 단계의 비용·포장/수령은 **기존 동일 섹터/인접 면제 규칙이 자동 적용되는 것으로 보지 않는다**. 궤도층/물류 연결 정책을 따로 결정한다. [Claude 보충 §9](10_CLAUDE_DISCUSSION_SUPPLEMENT.md) 참조.
