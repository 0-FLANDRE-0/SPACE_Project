## 4. 기술별 주요 구별 사항과 누락

- **`극초고온 플라스마 안정화`(I, 기존 approved):** **함선 탑재 핵융합로 기본 해금**(원본 설명·효과 유지). **`함선용 핵융합로 소형화`(I+, 신규 draft)**는 후속 **더 작은 탑재형**을 만드는 연구 제안. 2100년부터 대형 고정식 핵융합이 있다는 세계관과 혼동하지 않음.
- **발전소용 핵융합 모듈 소·중·대:** Claude 보충의 최신 사용자 결정은 **대형=초기, 중형=I+ 기술, 소형=II 초기~중기 기술**. 그러나 **보강 JSON에는 발전소용 중형 핵융합 해금 전용 연구 노드가 없고, II 노드도 없으므로** 이 구체 해금은 기획상 결정이지 JSON의 완성 경로가 아님.
- **`양자 간섭 정밀계측` → `양자역학 전문 연구 개방`**, `양자 상태 제어 실험` → `역장 현상 기초 분석` → `역장 조작 전문 연구 개방`은 **초안 필수 연결**로 존재한다. 분야 개방만으로 즉시 실전 보호막을 갖는 것은 아님. **보호막 등장 시점 II 중반~III 초입**이라는 Claude 보충의 사용자 결정을 따르며 구초안에서 보호막이 존재했다고 주장하지 않음.
- **`고밀도 축전 모듈`**, **`함선용 열관리 재설계`**, **`고출력 배전 보호계통`** 등은 실제 전력 시스템 개량 후보. 신형 부품/연구 해금이 구형 발전/함선 모듈의 무료 자동 개조를 뜻하지 않음.
- **`우주화물 규격화`**, **`행성 간 물류 관제망`**은 물류 취급·관리 연구 후보이고 **현재 SCU 자체를 연구 전에는 사용할 수 없다는 뜻이 아님**. 연구효과의 구체 규모는 미확정.
- 이름/분야 검토: **`레이저 분광기 개량`**은 제목이 계측인데 설명은 레이저 무기 개선이라 불일치. **`중력 역학`**은 컴퓨터공학 분야에 남아 있으나 천체행성학/우주역학 이동 검토 후보. **원문 보존, 사용자 결정 전 자동 개명/이동 금지**.
- 현대 기술(저온 핵융합·반물질·웜홀 심화 등)의 모든 시대 연구노드가 이 JSON에 존재한다고 주장하지 않음. 미래 계보는 [04A 반응로 구상](04A_REACTOR_TECH_AND_UPGRADES.md)·[Claude 보충](10_CLAUDE_DISCUSSION_SUPPLEMENT.md)의 확정/구상 구분을 따를 것.

3. **연구소·협력·보호막·시대 및 드라이브 등 추가 사용자 결정:** [10 Claude 보충](10_CLAUDE_DISCUSSION_SUPPLEMENT.md)을 정정 근거로 사용하고 기존 문서의 충돌 표현은 이 결정으로 갱신.
4. **코드:** 연구 런타임·경제 공식 반영은 미구현/별도 작업. 원본 지질·산업 U·ECON1~3 결과를 임의 변경하지 않는다.
5. **후속 기술 추가:** 발전소용 중형/소형 핵융합 해금과 연구 비용·기간·성능수치는 사용자 확인을 받아 **새 버전**에 명시적으로 추가하고 기존 시안을 소급 덮어쓰지 않는다.
