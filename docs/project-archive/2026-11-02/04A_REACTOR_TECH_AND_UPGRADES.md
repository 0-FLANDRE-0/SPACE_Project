## 1. 초기 핵융합의 존재와 함선용 핵융합 연구를 구별

- **[방향]** 2100년 세계관에서 인류는 대형 고정식 핵융합 발전 기술을 이미 갖춘다. **지상 발전소의 핵융합 존재**와 **작고 가속·진동·열/전력 제약이 있는 함선용 탑재 핵융합로의 안정적 운용**은 서로 별개다.
- **[방향/제안]** 함선 탑재 기술은 소형화·출력 밀도·냉각·안전·제어·시동과 모듈 결합을 개선할 수 있다. 이미 개발된 발전소가 있다고 처음부터 모든 함선에 대형 5GW 모듈이 들어간다고 해석하지 않는다.
- **[미정]** 초기 건설지원함/탐사함에 어떤 발전원이 있는지, 선체별 탑재 가능한 정확한 원자로 형식/최대 전력/크기/배기/연료/열, 탑재 허용 기준은 아직 없음.
- **[미구현]** 게임 본체의 발전 건설·전력망, 함선 원자로 모듈·연구 해금·함선 조립은 현재 개발 HEAD의 완성 기능이 아님.

## 2. ECON-SIM-3 고정식 설비의 역사적 기준

| 종류 | 정격 출력/모듈 | 최대 모듈/단지 | 기반 건설 C+합금 U | 모듈 건설 C+합금 U | 공기(모듈) |
|---|---:|---:|---|---|---|
| 핵융합 | **5GW** | 50 | **15,000C+1,200U** | **6,000C+450U** + 건설 수소 **5U** | 4개월 |
| 핵분열 | **2.5GW** | 35 | **8,000C+650U** | **3,000C+250U** | 3개월 |
| 태양광 | **1.5GW 명목 피크** | 80 | **5,000C+400U** | **2,000C+100U** | 1개월 |

- **[오프라인 입력]** 기반시설 건설 2개월 등은 R3의 후보. 이 표는 **최종 승인된 실제 게임 건설 스펙이 아니다**. 특히 태양광 정격은 월평균 실발전량이 아님.
- **[방향]** 하나의 행성 전력망에서 기존 도시·거주·산업 수요와 신설 수요를 함께 다루되, 기존 지구 약 **8.12TW** 배경 부하 안에 이미 포함된 산업 전력을 중복 가산하지 않는다.
- **[미정]** 핵분열 반응로의 상세 연료 U·핵연료 제조/수명/폐기/안전과 각 발전원의 신형 모듈 보수·열·직접 C 비용.
- **[결과]** 3차의 최종 경제/전력 종합 합격은 **0개**. 기존 모듈 숫자를 게임 공식 최종값으로 채택하거나 4차 재검증을 생략하면 안 된다.

## 3. 핵융합의 기동·연료·유지보수는 다른 항목

**[R3 기존 운전 계약; 4차 재검증 전]**

1. **건설 수소 5U**와 **초기/냉간 기동 수소 5U**는 각각 별도 자원 부담이다.
2. 기동 1회 **2,500C**와 외부 전원 **피크 1,250MW**를 요구하는 기존 구상. 최초 **24시간**에는 외부 전원 1,250MW·출력0, 이어지는 **72시간**에는 외부 입력 감소와 발전량 0→5GW 램프업. 총 기동 **96시간**.
3. 위 선형 램프 모델에서 외부 입력은 **75GWh**, 기동 중 발전은 **180GWh**. **MW(출력)**, **MWh/GWh(에너지)**를 혼동하지 않는다.
4. 정상 운전 수소는 **5GW 모듈당 2.5U/월**. 0.5·1.0U/월은 **미채택 민감도 후보**였다.
5. 현재 수소 **1U=500kg**이므로 정상 공급 수소는 **1.25톤/월**, 건설과 기동 수소 각 **2.5톤**이다. 실제 융합 반응에서 수소 분자 1.25톤이 전부 융합되어 그 에너지가 나온다는 의미로 해석하지 않는다. 연료 동위원소 분리·순환 등은 추상화.
6. **[방향]** 한 번 정상화한 반응로의 출력 제한/일시 정지/냉간 완전 정지 조건은 구분한다. 실제로 완전 정지하고 다시 냉간 기동한 경우에만 적절한 재기동 비용이 붙어야 한다. 정확한 상태전이/요율은 미정.
7. **[방향]** 완공 시설은 정지 중에도 유지보수용 합금/소재가 완전 0이 되지 않는다. 다만 C/합금/전력의 정량 비용·가동/정지 비율은 아직 사용자 확정값이 아니다.

## 4. 연구가 개선할 수 있는 반응로 성능 축

다음 항목은 **[연구 효과 설계 방향/후보]**이고 각 분야의 특정 노드·수치는 보강 테크트리 원문을 확인한 뒤 결정한다.

| 개량 축 | 물리·운영에서 실제로 의미할 수 있는 변화 | 별도 관리해야 할 값 |
|---|---|---|
| 출력·가동 안정성 | 정상 가동 가능 출력/부하 대응, 출력 변동·고장 위험 | 정격 MW, 실발전 MWh, 가용률 |
| 연료·열 효율 | 생산 전력당 연료 소비·전기/열 손실 감소 | U/MWh, 폐열/냉각 부담 |
| 함선용 소형화 | 같은 출력에서 질량·부피·장착 제약 감소 | 출력밀도 MW/t·MW/m³, 설치 가능 공간 |
| 냉간 기동 | 기동 시간, 외부 입력 피크/총량, 기동용 연료와 C 감소 | 시동 MW·MWh·U·C·시간 |
| 신뢰성·안전 | 결함·격리·긴급 정지, 전투 손상 시 사고 위험 완화 | 가동 상태·손상·안전 대응 |
| 유지보수·수명 | 노후/부품·합금·특수 소재 교체량, 실제 수리·정비 시간 | 기간별 U/C/공기 |
| 제어·출력 변화 | 급변하는 추진·무장·센서·방어 전력 수요를 감당 | 발전/배전/축전/부하 우선순위 |
| 연료 처리·저장 | 정제/동위원소/포장/연료 공급 안정성 | 산업용 수소·특수연료와 SCU 비용 경계 |

- **[방향]** 출력, 연료 효율, 출력밀도, 수명, 냉간 시동은 **서로 다른 물리적 특성**. 연구 보너스 하나를 출력·연료·열·원가에 중복 적용해 무상 이익을 만들지 않는다.
- **[방향]** 새 기술 해금만으로 **기존 반응로 모듈이나 함선 장비가 자동으로 무료 교체되지 않는다**. 신형은 새 건설분에 적용하며 기존 설비 개조 시 실제 재료·C·시설·기간·운전 중단이 필요할 수 있다. 소프트웨어 제어 개선을 기존 장비에 어떻게 배포할지는 [미정].
- **[미정]** 정확한 연구 노드별 효과 크기와 중첩, 안정성/효율 상한, 가동 중단 조건, 실제 함선 최대 원자로 출력.

## 5. 반응로 기술 계보 — 논의된 구상, 아직 확정 순서 아님

| 단계 | 과거 대화에서 논의된 방향 | 주의 |
|---|---|---|
| 핵분열 발전 | 기존 행성 전력과 초기/소형 전력 후보 | 상세 핵연료/운전비 미정 |
| 핵융합 발전 | 2100년 대형 고정식 존재. 이후 안정화·출력·함선 탑재 개선 | 함선용은 별도 연구 필요 |
| '저온 핵융합' | 더 쉬운 점화·기동/소형화 계통의 SF적 단계 제안 | 실용적 저온 핵융합은 과학적으로 확립되지 않음; 이름·원리 미정 |
| 펄스식 반물질 촉매/점화 | 극소량의 반물질을 핵융합 점화·제어에 사용하는 미래 기술 구상 | 실제 연구/연료/물리 모델 미정 |
| 직접 반물질 소멸 기반 동력 | 반물질의 고밀도 에너지 변환/추진 응용 | 생산·저장 에너지 수지가 별도로 필요 |
| 고급 반물질 구속·집중 저장/반응 | 더 고급 격리장치·소재를 쓰는 후반 기술 | '반물질 응축'은 과학적 검증명 아님 |
| 중성자 축퇴물질 관련 극단적 반응로 | 특이점급의 별도 추측 기술 | 실용 연료/반응물·보존·안정성 미정; **공식 계보에 자동 추가 금지** |

**주의:** 이 표의 '→'는 과거 논의를 기억하기 위한 **서사적 기술 흐름 후보**이지, 과학적으로 검증된 필수 진화 과정이나 보강 JSON의 정식 prerequisite가 아님. 특히 **새 테크트리 JSON을 확인하기 전에 이 계보로 노드·조건을 생성하면 안 된다**.

## 6. 반물질·아스트로지늄과 에너지 보존

- **[장기 방향]** 반물질은 입자가속기 등의 기술로 극소량 합성할 수 있지만, 생산에 실제 대량 전력을 요구한다. 생산된 반물질을 연료/저장으로 쓰는 과정의 **회수 에너지가 생산·격리·충전의 총 입력 에너지를 넘어서 무한동력**이 되는 모델은 피한다.
- **[장기 구상]** 미래의 **아스트로지늄** 같은 특수 자원을 반물질 구속/반응 제어 장치 제작·운영의 핵심 소재로 요구할 수 있다. 아스트로지늄이 현재 반드시 반물질 동력의 필수 확정 재료라는 의미는 아니다.
- 반물질 **1U**는 물질 자체 수 톤이 아니라 **아주 소량의 내용물 + 고성능 구속·저장·공급장치의 표준 자원 단위**라는 개념. 정확한 반물질 질량/kg/U, SCU/U, 보관 전력·안전 조건/손실률/수명은 [미정].
- 반물질 제조의 전력·C, 특수 포장/극저온·구속, 실제 반응 사용, 함선용 원자로, 공정 열손실 등을 **서로 다른 비용 장부로 분리**한다.
- 고급 반물질 동력은 **합성 효율이 더 나쁜데도 높은 에너지 밀도/선박의 독립 운용/추진 방식에 이점이 있어서 가치가 생기는 것**이 가능하다. 게임에서 '반물질 반응로'라는 이름만으로 원료 생산 전력을 지워버리지 않는다.

## 7. 초기 식민지 소형 전력 문제와 기술 개선의 연결

- **[R3 보고]** 기존 5GW 핵융합/2.5GW 핵분열/태양광 1.5GW 피크는 작은 식민지의 초기 실제 부하에 과대할 수 있다. 달 약 20만·화성 약 5만 명은 **잠정 인구**이며, 평균 4kW/인이라는 비교 가정에서 각각 **0.8GW/0.2GW**.
- **[제안]** 기존 대형 모듈을 허락 없이 10분의 1로 축소하는 대신 **초기 식민지용 소형 발전모듈**(핵분열·태양광 중심, 소형 핵융합은 별도 판단)을 별도 후보로 검토. **50/100/250MW**는 탐색 예시이지 정격 확정 아님.
- **[미정]** 소형 설비의 출력/비용·기술 해금·건설 기간·야간·축전·시동 전원·고장/정비·상한. 소형 장비 제작비가 정격에 무조건 선형 비례한다고 가정하지 않는다.
- 작고 값싼 초기 식민지 전원과, 장기 함선용 고밀도 원자로는 **같은 연구 대상일 수도 있지만 같은 제품이어야 하는 건 아님**.

## 8. ECON-SIM-4와 반응로 기술값의 경계

- ECON-SIM-4는 **미실행**. 기존 R3에 나온 공급부족/전시가격·원가/발전 회수 문제를 최신 kg/U·SCU/소재회수·수전해/액화·연료·소형 전력 후보로 다시 시험해야 한다.
- **[분리]** 미정 전력·C·합금 운영비를 0으로 대입해 통과시켜서는 안 된다. 발전소 대외 판매 수익과 국영 자체 사용/정전 회피 가치를 별도 계산한다.
- **[분리]** 새 테크트리 JSON이 추가됐더라도 연구 해금/성능 보너스를 **게임에 자동 적용**하거나 R3의 역사 수치를 소급 수정하는 일은 없다. 새 연구 기술값은 사용자 확인과 재검증 후 채택.

## 9. 새 테크트리 보강본이 제공되면 확인할 항목

1. 실제 JSON 파일 경로/버전, `catalog`/분야/시대/노드/연결과 구 버전 차이 확인.
2. **노드 이름·계보·선행·시대·자원/C/K·기술 효과**를 파일 원문 그대로 읽고, 과거 대화의 제안과 다른 부분을 명시적으로 대조.
3. 현재 게임 시작의 대형 핵융합 기술과 함선용 탑재 기술의 해금 상태가 모순되는지 검토.
4. 저온 핵융합/반물질 촉매/직접 소멸/구속 기술이 실제 JSON에 있는지 없는지, 제안에만 존재하는지 분리.
5. 반응로 성능이 **출력·효율·소형화·기동·안정성·정비** 중 어떤 항목을 실제로 바꾸는지, 중복 효과 여부 확인.
6. JSON의 `approved`·`draft` 같은 편집기 필드를 사용자가 **현재 최종 승인한 게임 설정**과 자동 동일시하지 않음.
7. 변경/확정된 해금은 기존 함선·설비를 무료 자동개조하지 않도록 설계.
8. 수치 확정 전에는 연구 문서만 갱신하고 **게임 코드·경제 시뮬레이션을 허락 없이 수정하지 않음**.
