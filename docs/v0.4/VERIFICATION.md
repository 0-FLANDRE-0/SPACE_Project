## 실제 브라우저 흐름

정적 서버 HTTP 200 → 로컬 ES 모듈/지도 로드 → 전체 항성계·고정 섹터 → 천체 선택과 옆 탭 → 버튼 확대·추적 → 섹터 선택 → 시험계 전환을 검증합니다. API·DB·서버 환경변수는 없습니다.

Chromium/Playwright와 SwiftShader 소프트웨어 WebGL을 사용합니다. PC 1440×1000, 터치 에뮬레이션 844×390·667×375가 대상입니다.

- 기존 상시 sidebar/관측 패널 없음. 초기 컨텍스트와 210 AU/3링/37칸 확인.
- 실제 목성 메시 클릭 후 **카메라 좌표 불변·전환 없음**. 탭의 확대 버튼으로만 접근.
- 드래그 중 선택 유지, 지구 65일 진행 후 탭 위치 변화, 확대 후 공전 추적.
- 양쪽 화면 가장자리에서 탭 제한·뒤집기, 구체 뒤에서는 숨김/선택 유지.
- 섹터 호버/선택/숨김·다른 섹터 선택 후 재생성 없음, 천체와 태양이 섹터보다 우선.
- 드래그를 클릭으로 처리하지 않음. 평행 레이 거부. 작은 달을 메시 밖 마우스 클릭·터치로 선택.
- 일시정지·배속·궤도/이름/축·보조 기준 평면·도움말·전체/안쪽/상부/측면/근접 보기 회귀. 소행성대 선택과 경계 강조·확대, 참고 상세 펼치기, 토성 메시/자전축 정렬도 확인.
- 지구 2K 지도·AU 눈금 확인. 모든 시점에서 천체의 고정 월드 반지름 유지.
- 작은 시험계 0링/1칸과 다른 이름의 동일 탭. 큰 시험계 6링/127칸, 경사 평면 실제 클릭, 중심 밖 A7V 항성 접근.
- 전환 시 이전 Geometry dispose·라벨 제거·추적/선택 초기화. 반복 전환 후 canvas 1개, GPU Geometry 수가 초기 수준을 넘지 않음.
- 두 모바일 해상도에서 수평 오버플로 없음, 탭 경계·실제 터치 선택·한 손가락 회전·두 손가락 핀치·위성 보조 선택 확인.
- 최종 뷰어 dispose 후 canvas/라벨 0개. JavaScript 예외·콘솔 오류 없음.

최종 667×375 화면에서는 눈금 막대가 잘리지 않도록 70px 안에서 거리 값을 산출합니다. 추가 Chromium 검사에서 8단계 확대마다 실제 막대 폭과 계산된 AU 길이가 일치함을 확인했습니다. [브라우저 로그](browser-smoke.log), [눈금 검사 로그](mobile-scale.log)를 보존합니다.

## 성능 관찰

같은 컨테이너의 1440×1000 전체보기에서 약 2.5초 동안 RAF 프레임과 Three.js render.info를 한 차례씩 기록했습니다. v0.3은 변경 전, v0.4는 회귀 스크립트의 초기 전체보기입니다.

| 측정 | v0.3 | v0.4 |
|---|---:|---:|
| 표본 프레임 | 15 | 16 |
| 약식 FPS | 5.87 | 6.20 |
| draw calls | 54 | 55 |
| triangles | 172,850 | 172,850 |

일반 경계선 배치로 draw call 1개가 추가되고 삼각형 수는 같습니다. 짧은 소프트웨어 렌더링 표본의 FPS 차이를 속도 향상으로 해석하지 않습니다. 실제 기기 성능 측정이 아니며, 넓은 화면의 SwiftShader FPS 자체는 낮습니다. 원본 수치는 `v0.4/performance.json`에 보존합니다. 호버/선택 강조 시 소수의 draw call이 추가됩니다.

## 재현

```sh
npm run dev
npm run check
npm test
PLAYWRIGHT_MODULE=/opt/codex/cua_node/lib/node_modules/playwright-core/index.mjs \
CHROMIUM_EXECUTABLE=/usr/bin/chromium node tests/browser-smoke.mjs
```

환경에 맞게 Playwright/Chromium 경로와 `BASE_URL`을 지정할 수 있습니다.

## 검증하지 않은 항목

실제 모바일 GPU·Safari·Firefox·실기기 장기 조작과 메모리, 수천 개 섹터 스트레스 테스트는 수행하지 않았습니다. 쌍성 중력 계산·개별 입자 충돌·함선·건설·연구·생산·안개·저장은 이번 범위가 아닙니다. 천체력이 장기간의 실제 우주를 정확히 재현한다는 보증도 하지 않습니다.
