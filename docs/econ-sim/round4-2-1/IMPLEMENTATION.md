# ECON-SIM-4.2.1 변경 식·회계 처리

작성 기준 **2026-11-07 Asia/Seoul**. 오프라인 전용. 출발점은 PR #21 HEAD `97e9252320d3e5217e6aad80aab313baa1b1d268`이다. 새 코드만 추가했다. 아래에는 [4.2 구현](../round4-2/IMPLEMENTATION.md)에서 바뀐 부분만 설명한다. 물 단위·반응 질량·소유자별 provenance·유상 시험 준비·기존 SCU/구호/수명주기/원장 감사는 재사용한다.

## 1. 순증산과 경제성

[사용자 승인] `b`는 **최대 수소 보조를 쓴 기존 공정 대비** 순증산이다. `P`를 당월 무보조 처리능력, `P_fast`를 제련 재가동 램프만13% 단축한 능력, `k=0.15`를 기존 보조 증산 계수, `y`를 기존 광석→합금 수율이라 한다.

```text
A = P × (1+k)                       # 기존 최대 보조 처리능력
R = P_fast × (1+k) × (1+b)          # 환원 처리능력
A_actual = min(가용 광석, A)
R_actual = min(가용 광석, R)
Y_A = A_actual × y
Y_R = R_actual × y
```

`H_A`는 `assistedSmelting()`에 보조 수소가 충분하다고 넣었을 때의 기존 소비량, `H_R`는 `Y_R × h`를 반응 양자0.005U로 올림한 소비량이다. 환원 수소가 기존 보조 수소를 대체하며, 같은 작업시간에 두 레시피를 더하지 않는다.

증분 비용은 기존 전력·산업 자산 보수/직접 운영비 규칙으로 계산한다. `e_process`는 광석 처리와 합금 생산의 기존 GWh/U 합계, `C_OM`은 활성비율1인 기존 산업 자산의 직접C+합금보수 시세평가다. `t_R = R_actual/R`다.

```text
ΔY = Y_R − Y_A
ΔH = H_R − H_A
ΔC = max(0, R_actual−A_actual) × e_process × 현지 전력가
     + max(0, R/A−1) × t_R × C_OM

진입/작업 경제성: ΔY × 합금가 > ΔH × 수소가 + ΔC
p* = max(0, (ΔY × 합금가 − ΔC) / ΔH)    # ΔH>0일 때
```

채광·고정 전력은 두 대안에서 같아 이 증분 비교에서 상쇄한다. 실제 정산에서는 계속 청구된다. ΔY≤0이면 환원 작업을 하지 않는다. 즉 **광석 부족을 처리능력 확대나 가짜 광석으로 덮지 않는다.** 가격을 p*에 고정하거나 마진을 만들기 위해 기존 비용을 줄이지 않는다. HTML은 실제 광석 조건의 p*와 광석 충분 가정의 능력 기준 p*를 따로 보여준다. 전자는 광석 제약으로0이 될 수 있다.

[사용자 승인 고정] 속도 개선 `s=0.13`은 제련 램프에만 적용한다. 광산 회복·제련96시간 가열·냉간 재가동 규칙은 그대로다. 합금은 기존 추상 복수 금속 구성이고 산업 믹스를 바꾸지 않았다.

## 2. 월 작업시간 분할

[사용자 승인] `switching`·정식 공정 전환 비용/기간/페널티·진입/해제 개월 히스테리시스가 없다. 자산에 영구 공정 상태를 저장하지 않는다. 기존4.1의 **필수 유지보수 부족 모드** 히스테리시스는 별개이므로 유지한다.

핵융합 정상/기동 H를 먼저 예약한 소유자별 실제 재고를 배분한다. [임시 구현 해석] 부족한 H를 먼저 전부 환원에 쓰면 H당 증산이 큰 기존 보조 공정을 굶길 수 있으므로, 나머지 시간의 보조H를 남겨 둔다.

```text
f_candidate = clamp((H_available−H_A)/(H_R−H_A), 0, 1)
# H_available < H_A 또는 경제성 미달이면 f_candidate=0
환원 합금Q = floor(Y_R × f_candidate × 1000)
환원 처리량 = 환원 합금Q / (1000 × y)
t = 환원 처리량 / R
```

반응 H를0.005U 묶음으로 올림한 뒤 `환원H + H_A×(1−t) ≤ 실제 H`를 만족하도록 필요한 극소량의 합금Q를 줄인다. 남은 `1−t` 시간은 원래 `assistedSmelting()`에 남은 광석·H·기존 램프를 넣어 처리한다. H0이면 완전한 무보조 기존 공정이다. 부분 공급이면 기존 보조가 가능한 시간은 그대로 유지한다. 광석이 한 달 전체 능력을 채우지 못하면 실제 환원 시간은 `f_candidate`보다 작을 수 있다.

실제 전력 공급 비율에 따라 두 처리량을 함께 줄이고, **실제로 나온 환원 합금**에 대해서만 반응 H·물을 정산한다. 기존 공정의 보조H는 별도 sink이며 물을 추가 생성하지 않는다. 실제 처리시간을 중복 사용하지 않는다. 환원용 H가 미지급인데 산출하는 경우 예외로 중단한다.

산업 자산 `activeFraction`은 `1 + t×max(0,R/A−1)`이다. 자산 전체에 대한 기존 보수/직접비 식을 재사용한다. ON에서 선택적 H를 먼저 확보한 후 이 예상 활성비율로 기존 유지비를 지불하고, 건강·현금·전력 제약을 반영해 작업을 다시 계획한다. 선택적 H 구매에 남긴 운영비가 당월 기존 운영에 사용되는 순서다. OFF의 원래 정산 순서는 바꾸지 않았다.

정보의 환원 시간은 완공 제련 세트월 대비 환원 실가동 시간이다. 산출 비중과 다르며, 월 변동은 절댓값 평균 및 시드별 최대를 기록한다. 전환 진동 합격 기준은 삭제했다.

## 3. 현금 안전선

[사용자 승인] 천체·소유자별 **추가 환원 H 매입**과 **새 수전해 설비 주문**에 적용한다. 자체 생산 H를 사용하는 작업시간에는 현금 안전선 검사를 하지 않는다. 기존 전력·유지비·재고 제약은 여전히 적용된다.

[임시 운영비 정의] `monthlyOperatingCost421()`은 당시 완공 운영 자산의 총 운영비를 현지 실질 시세로 평가하고 CPI를 한 번 곱한다. 현금이 없어 실제로 못 낸 비용을0으로 계산하지 않는다. 환원으로 늘어날 작업이 경제적으로 가능하면 **추가 보수/직접비와 연료도** 포함한다.

- 기존 직접C 및 합금보수의 시세 가치, 예상 환원 활성비율의 증분 포함.
- 기존 보수 backlog에서 그 달 처리할 수 있는 보수량×(합금가+보수 인건비).
- 채광·광석 처리·합금·고정 부하·가열·수전해·액화·보관의 기존 전력.
- 보조/환원 H, 핵융합 정상 연료, 핵분열 서비스 연료, 수전해 변동 서비스비.
- 현재 H 재고의 기존 보관 전력 및 boiloff 시세 가치.

자체 생산 전기·재료도 운영비 평가에는 포함하므로 **실제 현금 지출보다 보수적인 자원 가치 기준**이다. 이 평가는 두 번째 현금 청구나 매출 source가 아니다. 새 미래 설비의 아직 시작하지 않은 운영비와 예측하지 않은 모든 미래 지출까지 보장하는 모형은 아니다. 이 정의의 후속 채택은 미정이다.

```text
reserveQ = ceil(월 운영비C × cashReserveMonths ×1000)
spendableQ = max(0, 현재 현금Q − reserveQ)
추가H 매입량Q ≤ floor(spendableQ / 명목 수소가)
새 전해 주문은 건설C + 부족 합금의 실제 매입C를 낸 후에도 reserveQ를 보존
```

부족 시 추가H 주문을 줄이고 전해 투자를 보류한다. 새 전해 주문은 소재·비용 검사를 통과해야 원자적으로 실행된다. 실제 지출 뒤 동일한 사전 quote의 안전선을 확인하고 위반이면 실행을 실패시킨다. 여러 주문은 줄어든 실제 잔액으로 다시 판정한다. 현금 제약 정보는 같은 소유자·같은 월·같은 종류를 중복 세지 않는다. 다른 자원 제약이 동시에 있을 수 있어 안전선이 유일한 원인이라는 뜻은 아니다.

기존 핵융합/일반 보조 H 매입과, 지시서가 고정한 tick0/24의 유상 H-CUT 시험 준비를 임의로 차단하지 않는다. 새 안전선은 그 위의 선택적 환원 H와 모든 새 전해 주문에 적용한다. 시험 준비의 자금 이체·기존 SCU 요청·양의 시세 구매 절차는 양쪽에서 동일하다. ON 전해 주문은 안전선으로 지연될 수 있다. 무료 C/U·정부 비축 방출·물/얼음 공급원·새 배송 엔진은 없다.

## 4. 탐색·기준·재사용

R4.1 반올림 기반 하나. b0.05–0.25, h0.95–1.10, 현금 안전 개월1–6을 LHS32와 h1.06 기준안으로 확인한다. s0.13, 순보충 물0.5L/인/일, 취수비 몫50%, 기존37개 R4·7개 R4.1 축, H 기준가0.4, 정상 핵융합2.5U/월/5GW는 고정한다. 후보와 새 반올림안만 전 시나리오를 실행한다. 다른 기반 재탐색은 없다.

OFF는 원래4.1 또는 같은 유상 준비·차단을 적용한 불변4.2의 핵심 월행과 비교한다. 새 정산은4.2의 내부 함수 hook이 없어 개발 시점에 정적으로 복사해 확장했다. 실행 중 소스 치환/eval은 없다. 물 반응의 산소는 기존 제련 잔재에서 차감하고, 소유자별 H/물 양자 보존 및 자기 거래 매출 금지는 그대로다.

기존4.1 기준과 SCU 완전원가/회수 평가는 재사용한다. 새 무차단 생산 검사는 H-CUT 외42경로의 OFF 산업 생산이 있는 천체 및 유상 준비 무차단3천체에서 모두 수행한다. 총240개월과 모든229개 연속12개월 창을 **합금0.001U 정수 Q**로 비교한다. 무생산0/0 창은 두 생산량이 같지만 비율은 미정의로 남긴다. H-CUT는 OFF 창 생산이 양수일 때만95% 검사에 통과할 수 있다. 같은 기술 무차단 대비 비율을 별도로 보고한다. 이전 기준을 재판정하지 않는다.
