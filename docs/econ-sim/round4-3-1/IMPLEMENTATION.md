2026-11-07 Asia/Seoul. 오프라인 전용. PR #24가 미병합이어서 `5e31515f1eda9131438afb9b2c7fad4122b2e7c5`에서 `econ/round4-3-1-life-reserve`를 만들었다. 아카이브 `5bd1cec9a5216229d74e9af4d97e191d269227ec` 보충§28을 직접 읽었다. [4.3 식](../round4-3/IMPLEMENTATION.md)을 바꾸지 않고 새 정적 어댑터로 확장했다.

## 고정과 확정의 구분

4.3 반올림 얼음 산출750물U/월·건설0.79·유지0.66·0.0018GWh/물U·6개월, 임시 매장량 달100만/화성1,000만물U, 감면5년·유예12개월·산소 재활용50%를 고정했다. 4.2.2 y0.09/h0.96/현금6개월/물0.72·12개월/s0.13 및 R41-rounded·기존4.1 criteria는 재탐색하지 않았다. 국가 정부 C 계정은 여전히 하나이며 실물·민간C는 천체별이다.

**사용자 확정:** 인구비례 물·산소6개월 자동 비축, 생명유지 전용 산소 발생과 보호 전력, 미테라포밍 식민지의 낮은 세율, 극한 생명유지 정보화. **이번 임시 계수:** 산소 여유율1.2, 미테라포밍 기본세율의 절반0.5, 저장고 자본0.1배·100U 증설단위·1개월 공사. 기존4.3 반올림값은 이번에 고정하되 영구 게임 설계로 승격하지 않았다.

## 1. 실제 재고 안의 보호 비축

```text
월 물 수요Q = ceil(인구 ×0.5L ×30일 /4,500kg ×1,000)
월 산소 수요Q = ceil(인구 ×0.84kg ×(1−0.5) ×30일 /4,000kg ×1,000)
각 비축 목표Q = 각 월 순수요Q ×6
지구 수요·비축 =0
일반 사용 가능Q = 정부 실물 계정Q − 해당 자원 보호 비축Q
```

비축은 정부 물·산소 **실물 계정 안의 정수 부분집합**이다. 별도 source로 물을 만들거나 두 재고를 합산하지 않는다. H 회수 물의 출처도 비축 부분집합으로 함께 잠그고, 취수·거래·일반 전해·물 예측에서는 잠긴 수량을 제외한다. 월별 `채움−비상 인출−인구 감소에 따른 해제=현재 비축`을 감사한다.

정부는 현지 민간 물을 양의 기존 물 시세로 실제 매입한다. 일반 생명유지와 전용 산소 취수에 필요한 작업 재고를 먼저 남기고 초과분을 잠근다. 그달 제련 회수 물도 정산한 뒤 생활용 물을 사용하고, 실제 부족분만 비축에서 꺼낸다. **물 회수 이전에 비축을 인출하던 개발 중 오류는 수정 전 실패→수정 후 통과 재현 테스트로 남겼다.** 다음 순서로 전용 산소·비축 채움·일반 수소 취수를 처리한다. 월말 얼음 산출은 기존4.3처럼 다음 월부터 사용하며 다음 월 생명유지 작업 재고를 남긴 뒤 초과분을 비축한다. 닫힌 비축은 일반 판매 대상이 아니다.

산소는 당월 전용 발생기 산출→일반 전해 부산물/가용 재고→비축 순서로 소비한다. 남은 정부 산소는 비축 목표까지 잠근다. 산소 시장이나 매출은 없다. 인구가 늘면 수요·목표·필요 시설을 다시 계산하고, 줄면 초과 비축을 일반 재고로 해제한다. 해제는 소비나 비상 사용으로 세지 않는다.

## 2. 저장 시설 비용 [임시]

기존 물 탱크 기준 `e.waterTankU=200,000U`, 물·액체산소의 같은4SCU/U 포락을 사용한다. 연결된 현지 저장이므로 운송용 SCU 껍질·운송비를 만들지 않는다.

```text
각 자원 신규 탱크Q = max(0,ceil((목표Q−지불한 총 탱크Q)/100,000)×100,000)
저장 자본비율 = (신규 물U+신규 산소U)/기존 waterTankU ×0.1
건설C = 기존 전해1모듈C ×저장 자본비율 ×CPI
건설 합금U = ceil(기존 전해1모듈 합금U ×저장 자본비율 ×1,000)/1,000
완공 = 지불한 월+1개월
월 직접비 = 건설 기준C ×기존 directAnnual/12 ×CPI
월 보수 합금 = 기존 환경별 upkeep 식,0.001U 정수 정산
```

양의 C·합금을 원자적으로 지불하고 자본합금으로 묶어야 설치된다. 완공된 유상 용량까지만 비축할 수 있다. 저장고는 필수 정비 대상이다. 별도 탱크 파손·증발·열손실 모델은 추가하지 않았다. 산소 액화 전력은 기존4.3의 양의0.32kWh/kg를 생산 시 한 번 지불하며 비축으로 표시할 때 다시 부과하지 않는다. 작은 보수량이 기존0.001U 정산에서0이 될 수 있지만 비용을 임의로0으로 설정한 것은 아니다.

최초 충전 비용 JSON에는 충전까지의 저장고/전용 발생기 자본·유지·변동 현금과 합금, 전체 생명유지 물 매입액을 함께 남긴다. 별도로 독립 재현 경로에서 최초 충전까지 해당 천체의 실제 국가 원장 지출 총액(자원 조달·물류·다른 공유 시설 포함)을 추출한다. 시설별 C는 직접 현금 비용이며 합금 매입 현금은 소재 조달 원장에 있다. 공유 설비이므로 **순수 추가 비축비로 합산할 수 없다.** 비축 물 취득가는 당시 물 시세×물량의 재고 평가, 전력은 현지 요금 평가다. 이 평가를 실제 국가 원장 지출에 다시 더하지 않는다. 저장/발생기 비용은 식민지 전체 국가 지출에 이미 포함된다.

## 3. 생명유지 전용 산소 발생기

```text
주문 시점 용량Q = ceil(현재 인구를7개월 선행 예측한 산소 월 수요Q ×1.2)
신규 증설Q = max(0,주문 용량Q−이미 지불한 총 전용 용량Q)
건설C/합금 = 기존 일반 전해1모듈 비용 ×(신규 용량U/기존 모듈U)
공사 기간 = 기존 hydrogenLagMonths=6개월
당월 예정U = min(가용 용량×건강×실제 직접비 지급률,
                산소 생활 수요U+산소 비축 부족U,
                생활용 물을 제외한 일반 정부 물U)
```

기존 얼음 의사결정의6개월 공사+다음 운영 월 예측(7개월 선행)을 함께 사용한다. 인구 증가에 대한 작은 증설도 실제 지불·공사 완료 뒤 사용한다. 임의의 무상 소형 모듈이나 새 정격 발전소를 만들지 않는다. 전용 시설은 H 가격 수익성으로 중단하지 않는다. 기존 생명유지 정비 트리아지에 연결하며 자금·물·실제 전력 부족은 그대로 가동을 제약한다. 새 고장 모델은 없다. 기존 E6의 전체 정부시설 강제 중단은 정보용 실험에 남겼다.

물1U=4,500kg → 수소1U=500kg+산소1U=4,000kg, 정수Q의 같은 전해식이다. 기존 전해0.0255GWh/U, H 액화9.6kWh/kg, O 액화0.32kWh/kg로 **총0.03158GWh/산소U**를 요구한다. 실제 전력·직접비·합금 보수비를 지불하며 수소는 월말 현지 재고에 더해 같은 월 기동/제련에 재사용하지 않는다. 일반 H 전해 산출과 전용 산출을 별도로 기록하므로 H-CUT에서 일반 전해0을 검사하면서 전용 산소/수소 부산물을 잃지 않는다.

전력은 기존 기동 입력 후 얼음·전용 산소를 명시적으로 보호하고 도시 기본·나머지 부하를 처리한다. 선택적 수출 포장도 이를 침범하지 않는다. 소유자별 요금 배분에서 정부 얼음 부하를 민간 부하에 다시 넣던 중복도 새 어댑터에서 제거해 동일 전력을 이중 청구하지 않는다. 기존4.3 파일과 결과는 수정하지 않았다.

H 건설 물 예측은 잠긴 재고를 제외하고, 실제 알려진 얼음 공사·물 회수 이력·생활용 물·전용 산소 취수·아직 못 채운 비축을 우선 예약한다. 조건0.72/12는 그대로며 미래 H-CUT/충격을 읽지 않는다. 물리적 필요조건에 대한 보수적 견적이며 이후 모든 자금·전력을 보장하는 예보가 아니다.

## 4. 감면 후 세율

```text
설립 이후60개월 미만 식민지 →0%
그 외 → 명시적 행성 값 ?? 명시적 행정 섹터 값 ?? 파생 국가 기본
파생 국가 기본 = 국가0.25 × (미테라포밍 식민지 ? 비교계수 :1)
비교계수: 기본0.5(12.5%) / 비교0(0%) / 비교1(25%)
```

명시적인0%도 덮어쓰기이며 null만 상속한다. 지구는 감면·식민지 계수를 적용하지 않는다. 섹터나 행성의 명시값에 절반을 다시 곱하지 않는다. 테라포밍 상태는 자료 자리만 있고 전환·환경 모델은 없다. 기존0% 식민지 입력을 수정하지 않고 새 어댑터에서 파생 정책으로 적용한다. 실제 세수 원장과 연간 재정을 비교하며 인구 성장은 기존 외생식이므로 조세 이주 효과를 추론하지 않는다.

## 5. 판정과 실험 범위

고정 반올림안 하나·세율3안·자력/구호·42개 기존4.1 시나리오·유상 준비 대조·18종 H-CUT·H-OFF/ON·5시드·240개월을 실행한다. 재탐색은 없다. H-OFF도 동일한 새 국가/비축/전용 발생기 구조다. 전체431-OFF만 불변43에 위임해 회귀 대조한다.

기존4.1 criteria·분류와 국가 기준 budget17은 유지한다. 새 생명유지 필수는 E0·E2-S·E5-M(18격자 포함)·H-CUT에서 유예 뒤 모든 식민지/월99% 이상이다. E4·E5·E5-X·E6·E11 등 나머지 경로의 새 생명유지는 정보로 남긴다. 지구 H 마진≥0·신규 회수≤4년과 **최신431 기준표에 명시한 E0** 누적 ON/OFF>1을 검사한다. 이전43에서 필수였던 준비 대조 순증은 이번에는 정보로 구분한다. 무결성/국가 음수 검사는 모든 경로에 적용한다.

극한의 ‘버틴 월’은 충격 시작 뒤 물·산소를 모두99% 이상 충족한 연속 선두 기간이다. 충격 직전 비축 충전율·실제 비축 인출 월/양·최저 충족률을 함께 보고한다. 공급이 계속되는 경로에서 이 기간을 비축 단독 자립 기간으로 해석하지 않는다.

화성의 기존 민간 물200,000U와 기존 정성적 얼음 가정은 보존한다. 사망/행복·조세 이주·식량·산소 판로·빚/새 구제·예산 배정·실제 물류/얼음층·M2/M3·게임/UI는 연결하지 않았다.
