# 사용자 보강 조건

2026-11-01 대화에서 직접 받은 요청. 첨부 지시서와 충돌하면 이 보강 조건을 우선한다.

1. 합금은 철강·비철금속·특수합금 등을 합친 추상 산업 자원이다. 알루미늄만으로 전력 집약도를 대표하지 않고, 복수 산업 구성 가정을 비교한다.
2. 전력은 행성별 통합 전력망이다. 광산마다 발전소를 강제하지 않는다. 지구 기존 인프라, 신규 식민지, 산업 확장, 설비 고장을 구분한다. 부족을 만들려고 산업 전력을 부풀리지 않는다.
3. 발전소와 광업·제련의 투자 회수는 별도 평가한다. 전기 판매 현금 수익과 산업 가동 유지·정전 방지·예비력의 기반시설 가치를 구분한다.
4. 핵융합 정상 소비는 2.5U/월을 보존한다. 별도 실험에서만 0.5/1.0/2.5U/월을 비교해 수소 수급·생산 경제성·핵융합 운영비를 보고한다. 승인 없이 기본값에 적용하지 않는다.
5. 초기 식민지의 모듈 과잉 규모를 수치로 확인한다. 확정 정격을 변경하지 않고 설계 개선 제안을 분리한다.
