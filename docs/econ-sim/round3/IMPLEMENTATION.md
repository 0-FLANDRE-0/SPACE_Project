# ECON-SIM-3 구현과 재현

기준 HEAD `aff438089e1551e71309403f1f144ac7def99e0f`, `feat/econ-calibration-sim`, PR #10. 1·2차와 게임의 기존 소스를 보존하는 새 파일만 사용한다. DECISIONS에는 미결정 결과를 추가한다.

## 경로

- `dist/src/economy-energy-model.js`: DOM·시계·저장소가 없는 월별 통합 실험. OFF는 원본 `simulateEconomy`로 그대로 위임한다.
- `economy-energy-ledger.js`: 화폐·소유자·행성·물질별 정수 장부, 원자적 거래, 에너지 수지 검사.
- `economy-energy-facilities.js`: 고정 계약, 기동 적분, 전력 저장, 유지보수, 공사 할증, 기존 산업 처리량/램프업 재사용.
- `scripts/econ-round3-inputs.mjs`: 프리셋/원천/계약 해시 읽기. 광업 수소 상수가 바뀌면 어댑터를 검토하기 전까지 중단한다.
- `scripts/econ-round3-analysis.mjs`: 판정 범위와 산업/발전 재무 계산.
- `scripts/econ-round3-calibrate.mjs`, `.config.json`: 표본·병렬 계산·교차 검증·민감도·원시 결과. Node worker는 수치 계산만 수행하며 결과 순서는 입력 순서로 고정한다.
- `scripts/econ-round3-mutants.mjs`: 복제된 임시 트리에만 오류를 주입하는 검사. 실소스는 바꾸지 않는다.
- 보고용 HTML/SVG는 수치 결과로 생성한다. 게임 HTML은 건드리지 않는다.

## 장부와 단위

C와 물질 U는0.001 단위 정수다. 모든 현금 거래는 지급자 차감=수취자 증가다. 중앙은행 정상 발행/소각 및 전시 발행만 통화량을 바꾼다. 국채는 가계 기존 현금을 정부에 이전하며 발행 화폐와 다르다. `sum(C)=M`, `MV=PY`를 월마다 검사한다. 임금·관리·수리·핵연료 서비스는 가계/서비스 부문 수입으로 돌아간다. 채권이자도 소각하지 않는다.

광석은 유한한 실제 행성 부존 계정에서 꺼낸다. 제련 광석 정수량=합금+잔재의 정수량이다. 난도는 처리량, 품질은 수율을 결정한다. 여기서는 Round2와 비교하기 위해 품질 확률의 기대수율을 집계해서 사용한다. 기존 게임의 로트별 확률 생산을 바꾼 것이 아니다. 천체별 실제 매장량은 합산하지만 각 광맥의 탐사 해금/운송 최적화는 다루지 않는다.

제련 보조는 raw85U/월 상한과 실제 처리량 보정 소비를 구분한다. 처리 효율76%에서 최대 보조의 실제64.6U를85U 필요로 잘못 제한하지 않으며, H 예산을 만족하는 보조율을 두 구간 해석식으로 구한다. 구매는 재고에 의해 이미 감산된 소비가 아닌 희망 보조 주문에서 출발한다. 정부 필요분을 예약한 뒤 잉여만 민간에 실제 판매한다. 미충족 H는 개시 시점에 채워지지 않은 주문이며 소비량−기말재고가 아니다.

수소 부산물은 실제 H 원천의 타일에 광업을 배치했다고 선언한, 광석 생산 중인 시설에서만 최대100U/월이다. 지구2원천을 중복 배정하지 않으며 정부/민간이 같은 유한 잔량 계정을 사용한다. 첫 원천은 정부 광업이 가동하면 정부, 나머지는 민간에 배정한다. 신규/추가 광업 수가 증가해도 같은 원천을 무한 복제하지 않는다. 해당 부지의 허가/탐사가 완료되었다는2100년 실험 가정이며 공식 탐사 데이터 수정이 아니다.

수전해는 실제 수원 타일의 산업 호스트, 설비용량, 취수 한도, 물 탱크, 배정 전력으로 제한한다. 물9U→H1U+O₂8U를 기록한다. 산소는 부산물 장부일 뿐 새 경제 상품으로 판매하지 않는다. 취수는 이름 있는 외부 물질 입력이며 광석/수소 매장량 생성이 아니다. 월 중 만든 H는 **정산 마지막**에 들어와 그 월의 핵융합/제련에 사용하지 않는다. 기존 재고를 소비하는 순서만 허용한다.

기동 적분은 실제 전력 예산·진행 시간·사전 H 재고를 동시에 제한한다. 진행 H를0.001U 격자로 내림해 같은 미세 잔량을 반복 사용하는 것을 막는다. 성공한96h 기본 기동은75GWh 입력·180GWh 발전·5U이다. 정상 연료는 별도의 정상 운전 시간에만 청구하고, 최소 유지 출력으로 운전하며 남은 전력은 삭감할 수 있다. 자원이 최소 유지분보다 부족하면 냉간 정지한다. 재기동은 다시2,500C와 기동 자원이 든다. 계통 출력 감산만으로 재기동 비용을 부과하지 않는다.

에너지 블록별로 가용 공급+방전=사용+충전+삭감을 kWh 정수로 검증한다. 저장 SOC는 GWh 실수이며0~용량 범위,1e−8GWh 허용오차로 검사한다. 충·방전 효율은 각각 η로 왕복 효율은η²이다. 월 합계/그림은 실수 누적값이라 마지막 자릿수는 다를 수 있다. 미공급량은 상한 가격에서도 남는다. 발전 그래프의 가용량에는 삭감 가능한 발전 잠재량이 포함되며 실제 판매량과 같지 않다.

인구는 초기 공식 정수 인구에서 주어진 성장률의 연속 집계값으로 증가한다. 개별 인구 이동·사망 정책이나 셀 재분배를 새로 만들지 않는다. 초기 지구8,893POP/92셀은 공식 데이터를 읽어 검사한다. 본체 프리셋을 갱신하지 않는다.

## 기준 수요·기존 비용의 분해

지구 평균 기초 전력은8,120GW이다. 초기 기존 민간 광업/제련·수소 설비의 자세한 전기를 계산해 **같은 양을 도시/기존 산업 배경 부하에서 먼저 뺀다**. 초기 산업을8.12TW 위에 덧붙이지 않는다. 이후 GDP 수요 탄력성과 실제 설비 확장으로 증가한 소비만 추가한다. 지구 기존 설비는 여러 기술이 섞인 집계 유효 공급능력이며,9TW 전체를 핵융합이라고 가정하거나 H 연료를 소급 청구하지 않는다.

Round2의3.6% 민간 합금 수요에서 초기 상세 시설 보수·자본 대체에 배정한 부분을 빼고 일반 수요를 만든다. 실제 신설 투자/보수 U를 다시 별도 차감하므로 같은 초기 유지비를 두 번 더하지 않는다. GDP는 기초 잠재 성장에 실제 전력·재료 부족 손실을 반영한다. 내부 구매/건설 현금 이전만으로 GDP를 추가 생성하지 않는다.

이전 정부11.5%·민간10% 통합 운영 프록시는 ON 실행에서 읽어 청구하지 않는다. 새 직접 임금/관리 C, 실제 취득한 재료 C, 자기 보유 재료 U, 수소·전기, 수리비로 대체한다. 상각은 민간 투자 판단과 별도 재무 원가의 비현금 값이고 월 현금에서 다시 차감하지 않는다. 민간 신규 산업의 투자 판단도 실제 H 보조·전기·보수 U를 포함하며 직접 임금률은 합금 기회비용을 포함한 총투자액이 아닌 건설 C에만 적용한다. 구 프록시를0.9로 바꿔도 ON 경로가 동일한지 검사한다.

세금은 가계/민간→정부, 고정 민생 지출은 정부→가계 이전이다. 순전략 예산만 새 국고 가용액이다. 기존 전기요금·서비스 소비는 GDP의 내부 분해이며 추가 GDP나 화폐 발행이 아니다. 도시 전기요금은 가계→민간 배전 집계로 들어온 뒤 실제 정부 발전 공급분만 민간→정부로 정산한다. 자기 소유 발전/소비에는 매출이 없다. 지불 부족은 미정산 C로 따로 표시하고 매출로 꾸미지 않는다.

## 설비·소유·상태

국영 광업/제련은1세트의 고정 계약이다. 광업6개월, 제련8개월에 각각 준공한다. 민간만 국토 전체의 연속 용량 집계로 표현하며 시장 허가/확장 지연을 더한다. 램프업은 기존 `facilityCapacity`의10→100% 곡선 적분이다. 완공 전 공장 운영비/생산이 없다. 먼저 완공된 광산의 재고를 나중 제련소가 사용할 수 있다.

정부 발전은 기반1개와 모듈 개별 자산으로 저장한다. 정부 구획은 단지당1개이며 증설 중 기존 모듈은 계속 발전한다. 기반 준공 후에만 모듈 공사를 시작한다. 동일 행성 **정부** 공사를 모든 단지에 걸쳐 집계해 C에만 할증을 적용한다. 학습이 C 할증을 낮추며 절대 동시공사 제한은 없다. 기존 지구 민간 전력의 신설은 최대35기 핵분열 단지 상당의 집계 투자다. 실제 C/U를 선불 지불하고5개월 이상 지연 후 가동한다. 수익성이 모자라면 투자하지 않으며, 부족분을 무료 발전으로 메우지 않는다.

완공된 산업·전력 기반/모듈·수소·저장·기존 전력 자산 모두 양의 합금 보존 기반을 가진다. 직접 C는 고정60%+직전 가동률 비례40%, 합금은 고정85%+가동률 비례15%로 분해한다. 중단 상태의 C 잔존율5–30%, 합금80–100%를 탐색한다. 이 비율·보존 기반·실험 계수는 모두 미확정이다. `construction/starting/active/curtailed/paused/coldStopped` 상태를 별도로 취급한다.

유지보수 부족은 미납 U와 건강 저하를 남긴다. 보수를 재개하면 실제 추가 합금과 수리 C를 지불해야 회복한다. 장기간 광업/제련/전력의 동반 붕괴에서 현지에 재료를 만들 수 없으면 외부 유상 구호 없이는 회복하지 못할 수 있다. 자동 무료 수리나 파괴로 결손을 없애지 않는다.

달/화성의 기초 시험 정착지는 지구의 고정10,000U에서 각각250/80U를 떼어 운임을 지불한 **일회성** 유지 재료를 받는다. E2/E4/E8/S4의 추가 개척 지원도 지구 C/U/H를 차감한다. 이후 지원 C와 명시적 추가 운송 이외에는 행성 간 재고 공유·송전이 없다. 초기 민간 재고·기존 발전·물 탱크는 역사적 초기 조건으로 분리하여 기록한다. 개별 회사·세부 물류망 구현이라고 주장하지 않는다.

## 시간·정책·시나리오

경제 월12회/년, 전력730h/월이다. 산업 계약의 월 처리량/기간을 그대로 사용한 독립 집계 시간축으로, 본체의30일 달력을 수정하지 않았다. 핵융합 기동은24h 이하 사건 적분만 수행한다. 평상시20년을 시간별 반복하지 않는다.

달은 대표 월의 긴 명암 블록을, 화성 저장은 약12.33h 명암 사건과 마지막 부분 구간을 사용한다. 화성의 밤을 반달로 취급하지 않는다. 기후/발전계수는 월 평균 가정이고 위도·계절별 궤도 일사 모형은 아니다. E3는12개월 동안 하루6시간10.75TW급 피크와 기존 공급10% 고장을 겹친 강한 스트레스다. 피크를24시간 내내 적용하지 않는다.

S0/S1/S2/S3-debt/S3-money/S4/S1-sell은 선행 정책 대조다. 새 물리/현금 모형에서 동일 월별 결과가 나와야 한다는 뜻이 아니다. E0 정상 지구, E1 정부 전력 확대, E2 식민지 단계 건설, E3 피크/고장, E4 H 공급 중단/겹친 기동/달 자체시동 불가, E5 실제 합금 징발+광업 중단, E6 일시 중단/냉간 재기동, E7 과도한 공사+학습, E8 수원 제약/낮은 일사량이다. 상세 사건은 `scenarioEvents`, `monthlyPower`에 결정적으로 정의했다.

E4의 H 생산 중단은48~84개월, E5는60개월 재고99% 실물 징발과60~84개월 광업 중단, E6는48~60개월 정부 시설 중단이다. E5 징발은 실물 소모이며 가짜 판매 수입이 없다. E8의 낮은 일사는36~108개월 원래 발전계수의25%다. 목적은 위기 진단이며 평시 합격률을 높이려 위기를 없애지 않는다.

## 탐색과 판정

범위·초기값·출처는 `scripts/econ-round3.config.json`에 있다. LHS512개×5시드, E0/E2/E3를 넓게 계산한다. 각 축 양끝 OAT 후 측정 영향 상위8축을 좁혀128개×9E시나리오×5시드를 계산한다. 넓은 탐색 상위8개도9시나리오로 다시 평가한 뒤 동등한 범위에서 최종3개를 고른다. 반올림은 탐색한 키만 바꾸며 정격·월수소·기초 수요·원자력 연료 서비스 같은 고정/별도 값을0으로 만들지 않는다.

최종3개+반올림1개를16시나리오×5시드씩 별도 실행한다. 선행 rounded-4+3후보는7시나리오×5시드에서 OFF/ON 대조한다. OFF는 원본 직접 호출과 해시 비교한다. 동일 시드/동일 입력 재현은 내용 해시로, 성능 시간/측정 환경은 비교 대상에서 제외한다.

확정 무결성, 지정된 평시 가격/물가/예산 기준, 전시 기준, 추가 공급 안정성 제안을 구분한다. 실비 포함 산업 회수를1.5~3년에 강제하지 않는다. 전력 미공급0.5% 이하/유지보수99% 이상은 **보고용 추가 제안**이다. 결과 JSON은 macroPassed/proposedReliabilityPassed를 따로 낸다. 전력·수소·손익·정부 비중은 지시서가 정한 정보 지표를 탈락 기준으로 몰래 바꾸지 않는다. 스트레스 E3~E8에 평시 기준을 적용하지 않는다.

발전 재무는1기 단독/최대 모듈 기반 공유를 별도로 계산하고, 실제 외부 판매·자기 소비를 구분한다. 독립 회수 계산은 단지 완공·첫 기동비를 포함하되 송전망·금융비용·해체·부지비를 완전 모델링하지 않는다. 따라서 실제 LCOE라고 주장하지 않는다. E1/E3의 동일 설정 무신설 반사실은 미공급 회피·산업 가동·GDP·국고 차이를 구한다. GDP/산업 손실 회피는 현금 매출로 더하지 않는다.

수소0.5/1/2.5는 별도 paired 실험이며 정상2.5 기본값은 그대로다. 산업 구성3종도 같은 후보/시드/사건에서 한 가정만 바꾼다. 발전비0.75/1/1.25와 기반기간1/2/3/4개월은 금융 하위모형 민감도다. 이를 전체 거시 경로를 재실행했다고 표시하지 않는다.
