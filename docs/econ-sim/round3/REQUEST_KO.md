## 1. 이번 검증에서 답할 질문

1. 지구의 기존 산업·도시가 전력을 소비하는 상태에서, 추가 국영/민간 발전소와 광업·제련시설을 증설했을 때 **20년간 전력 공급·산업 가동률·GDP·합금 가격·국고·민간 성장**이 어떻게 달라지는가?
2. **광업단지와 제련단지의 전력 사용량, 인건비, 관리/수리비, 월 합금 유지보수량**은 어느 정도가 경제적으로 지속 가능한가? 처리량·채굴/가공 난도·가동률을 반영한 단위 생산원가는 얼마인가?
3. 핵융합·핵분열·태양광의 **발전량, 운영비(C), 합금 유지보수(U), 연료 비용, 초기 건설 투자와 회수기간**이 서로 납득할 만한가? 발전 방식별로 사용 목적과 장단점이 실제로 나타나는가?
4. **수소 기준가 0.4C/U**가 민간/국영의 수소 공급·사용과 전기분해 생산원가를 고려했을 때 지속 가능한가? 수소 부족이 핵융합 감산·냉간 정지·재기동 비용을 실제로 유발하는가?
5. **가동 중단 시 C 지출은 크게 줄지만 합금 유지보수 U는 조금만 감소**한다는 규칙이 재정난·합금 부족·시설 보존 선택에 어떤 영향을 주는가?
6. 전력 생산·소비·수소 생산·합금 유지보수를 추가해도 ECON-SIM-2의 거시 경제 기준값이 설명 가능한 범위에서 유지되는가? **정부의 판매 수익이 민간을 과도하게 구축하지는 않는가?**
7. 어떤 수치가 가장 민감한가? 어느 구간부터 발전소가 경제적으로 무가치해지거나, 합금/수소 공급 부족이 연쇄적인 생산 붕괴를 일으키는가?

## 2. 선행 경제 기준값 — 비교 대상이지 사용자 확정값 아님

2차 보고서의 반올림 후보 `rounded-4`는 512조합 × 7시나리오 × 5시드 검증에서 통과했으며, 전체 합격 조합은 6개였다. **사용자가 최종 채택한 값이 아니다.** 3차의 시작 비교점으로 사용한다.

| 2차 반올림 비교 기준 | 값 |
|---|---:|
| 연간 노동생산성 성장률 | 1.1% |
| 목표 물가상승률 | 1.3% |
| 연간 GDP 대비 민간 합금시장 비중 | 3.6% |
| 세수 중 우주·전략 예산 비율 | 2.1% |
| 지구 세율 | 25% |
| 유통속도 `V` | 1.3333 (M₀≈1,500만C는 `Y₀/V`의 결과) |
| 시작 합금 기준가 | 2.3C/U |
| 2차의 국영 통합 운영비율 | 연 11.5% — **3차에서 실비로 대체/분리할 임시 프록시** |
| 2차의 민간 통합 운영비율 | 연 10% — **3차에서 실비로 대체/분리할 임시 프록시** |

- 지구 시작 인구 8,893 POP, 1 POP = 100만 명, 1U = 10톤.
- 국영 광업단지: 기존 계약상 14,500C + 합금 1,200U, 6개월, 이상적 광석 5,000U/월. 실제 산출량은 난도와 램프업에 따름.
- 국영 제련단지: 기존 계약상 24,500C + 합금 3,150U + 수소 120U, 8개월. 처리량과 수소 보조, 광석 품질 수율은 기존 코드 기준.
- 기존 민간 모델은 **개별 회사가 아닌 행성별 집계 민간 부문**이고, 2차 생산비 일부는 실제 현금 장부가 아닌 그림자 비용이었다. 3차에서 이를 실제 비용으로 대체할 때 회계 일치 여부를 검증한다.
- 2차의 `S1-sell`은 국영 합금 판매가 민간 증설을 강하게 위축할 수 있음을 보여줬다(반올림 후보에서 민간 설비 약 **43.95% 감소**). 3차에서 이 구축 효과를 숨기지 말고 재측정한다.
- 2차의 물가·합금가격·재정/전시 기준 및 S0, S1, S2, S3-debt, S3-money, S4, S1-sell 시나리오는 **변경 전/변경 후 대조 기준**으로 보존한다.

**회귀 대조:** 신규 전력·실비 모델을 완전히 끈 *legacy 모드*는 동일한 입력/시드로 2차 결과 또는 해시를 재현해야 한다. 3차 모델을 켠 결과와 혼합하여 하나의 합격 수치로 보고하지 않는다.

## 3. 게임 설계 입력 — 규칙을 보존할 것

### 3.1 발전 모듈의 기본 구조

| 발전 방식 | 모듈당 정격출력 | 단지당 최대 모듈 | 단지 최대 정격출력 | 모듈 1기 건설기간 |
|---|---:|---:|---:|---:|
| 핵융합 | **5GW** | **50기** | 250GW | **4개월** |
| 핵분열 | **2.5GW** | **35기** | 87.5GW | **3개월** |
| 태양광 | **최대 1.5GW** | **80기** | 120GW | **1개월** |

- 정격출력 MW/GW와 실제 생산 전력량 MWh/GWh/TWh를 구별한다. 태양광 1.5GW는 최대 정격이며 실제 발전은 일사량·낮/밤·항성 거리·가동률에 좌우된다.
- 국영 발전단지는 모듈 수와 무관하게 **단지당 정부 건설구획 1칸**을 차지한다. 민간 발전은 집계 민간 산업으로 표현하며 정부 건설구획을 점유하지 않는다.
- 기존 단지의 증설 중에는 기존 모듈이 계속 운전한다. 한 번 지은 단지 기반 공사비를 모듈 증설 시 다시 부과하지 않는다.
- 단지 기반 공사는 **약 2개월**을 현 협의의 잠정 출발점으로 둔다. *기반 공사 완료 → 해당 모듈 공사 → 기동/가동* 흐름을 검증하며, 기간 자체의 민감도도 보고한다.
- 동일 행성의 정부 병렬 건설에는 **절대적인 하드 상한을 두지 않는 방향**을 적용한다. 효율적 동시 시공량을 넘을 때 추가 **C** 할증이 발생하고 기술/건설 경험으로 효율 시공량 증가 및 할증 감소가 가능하다. 구체적 병렬 허용량·할증률·학습 효과는 미확정이므로 탐색한다. 타 단지로 공사를 분할해 할증을 회피하지 못하도록 행성 전체 정부 동시 공사를 집계한다. 합금·수소 요구량 자체는 할증 C로 대체하지 않는다.

### 3.2 핵융합 모듈 — 건설/기동/정상 운전의 자원 구분

- **건설 시** 모듈당 수소 **5U 1회 소비**. 이 수소는 아래 기동 수소와 **별개**다.
- **최초 기동** 모듈당 **2,500C**, **기동 수소 총 5U**, **외부 기동 전력 최대 1,250MW**.
- **기동 시간 4일(96시간)**: 최초 24시간은 외부 1,250MW를 소비하면서 발전량 0. 그 이후 72시간 동안 외부 기동 전력은 연속적으로 감소, 발전 출력은 연속적으로 증가해 **96시간 종료 시 기동 전력 0MW·발전 5GW** 도달.
- 기동 수소 5U는 96시간에 걸쳐 서서히 소비한다(잠정 기본 프로파일: 진행 시간에 균등 배분). 2,500C는 기동 개시 시 1회 지출하는 것으로 모델링한다.
- 전체 구간에 안정적인 외부 전력/수소를 확보한 기본 곡선의 검산값: 외부 입력 에너지 **75GWh**, 기동 중 총 발전 에너지 **180GWh**, 순생산 **105GWh**. 모듈당 1,250**MW**를 4일 내내 소비했다고 오해하지 말 것.
- 정상운전 시 모듈당 정격 출력에서 **수소 2.5U/월**, 실제 출력·시간에 따른 비례/최소 유지분은 명시된 규칙으로 처리. **기동용 수소 5U와 정상용 수소 2.5U/월을 같은 시간에 중복 청구하지 않는다.**
- 수소 부족 시 모듈별로 자동 감산하며 가능한 한 유지. 최소 유지 출력도 못 감당하면 **냉간 정지**, 이후 재기동에 비용·외부 전력·수소 필요. 최소 유지 출력, 부족 판단, 냉간 재기동 비용의 추가/할인 규칙은 탐색 대상이다. 단순 출력 제한 또는 일시적인 계통 출력 조절은 재기동비를 발생시키지 않는다.
- 여러 모듈은 독립적인 공사·기동·운전·정지 상태를 가진다. 미완공 모듈은 발전하지 않는다.

**시간 해상도:** 경제는 월 단위로 계산하되 4일 기동처럼 일별/시간별 상태가 의미 있는 사건은 **결정적 하위 스텝 또는 수학적 적분**으로 정확히 합산한다. 20년 전체를 무조건 시간별로 반복할 필요는 없다. 외부 전력이 부족하면 실제 공급된 전력·소비된 수소와 기동 진행을 일관되게 조정하며, 무조건 96시간 뒤 완공/가동 처리하지 않는다. 같은 월에 발전한 에너지와 기동에 사용한 에너지를 모두 장부에 반영한다.

### 3.3 전력망 및 소유 구조

- **천체/행성마다 하나의 통합 전력 풀**을 잠정 사용한다. 섹터별 선로 손실·지역 송전망·섹터 간 물류 및 행성 간 송전은 **후속 범위**다. 시설의 섹터 위치는 미래 확장을 위해 유지한다.
- **국영과 민간은 발전·수요·재고·현금 소유가 별개**다. 생산된 전기는 행성 전력망에서 합산해 배전하지만, 전기 판매/구매 대금은 소유 주체 간 실제 C 이전으로만 기록한다.
- 국영 발전소가 국영 광산에 공급한 전력을 국고 매출로 계상하지 않는다. 민간에 **실제로 판매·정산된 에너지**만 국영 현금 수익이다. 민간이 국영에 판매한 전기는 국영 비용·민간 수입이다.
- 전력 부족 시 필수 생명유지/기초 도시 수요 보호, 산업 가동률 감소 등의 우선순위는 탐색 가능한 정책으로 둔다. 정책 간 분배 공정성 및 국영/민간 구축 효과를 비교한다.
- 축전/비상 예비전력은 **에너지 저장과 방전만 수행**한다. 저장 시설은 전기를 무에서 생산하지 않으며 충전·방전 손실과 재고/잔량을 계산한다. 축전 세부 비용이 확정되지 않았다면 이 단계에서 작은 추상 저장 모델로 검증하되, 수치와 가정은 명시한다.

### 3.4 수소

- **잠정 시장 기준가 1U = 0.4C**. 고정 관제가격이 아니라 행성별 수급에 따라 변동하는 시장 기준이다. 시작 합금 기준가는 **2.3C/U**를 유지한다. 두 상품 모두 명목/실질 가격 및 물가지수 변화를 분리한다.
- 광업의 수소 부산물은 **기존 실제 수소 원천이 있는 섹터에서만**, 활동 중인 해당 생산시설의 조건을 충족하면 최대 **100U/월**이다. 국영뿐 아니라 민간 광업에서도 수소를 생산할 수 있다. **존재하지 않는 광맥/수원을 생성해서 수소를 공급하지 않는다.**
- 해양 섹터 또는 해양 인접 섹터의 산업단지에는, 해당 조건이 만족될 때 **추가 정부 건설구획 없이 수소 생산 모듈**을 부착할 수 있다는 설계 방향을 사용한다. 민간 부문도 모듈/설비 능력에 상응하는 추상 생산을 할 수 있다. 모듈 건설비·생산량·전력 투입·C 운영비·합금 유지보수량은 탐색 대상이다.
- 수전해 등 전력 기반 수소 생산에는 **실제 전력량과 운영비**가 필요하다. 생산량은 설비 용량·접근 가능한 수원·사용 가능한 전력에 제한된다. 해당 행성의 물/얼음/수소원 조건 없이 무제한 수소 생성 금지.
- 수소를 만든 같은 정산 구간에서 핵융합이 그 수소를 소비하는 순환을 무제한 허용하여 자기 시동/무한 생산이 생기지 않도록 **사전 재고·생산 순서·에너지 배분 규칙**을 명시한다. 물→수소 생산 전력과 핵융합의 핵에너지 출력을 물리적으로 동일 에너지원으로 간주해 억지로 1:1로 묶지는 않는다.
- 국영·민간의 수소 재고를 따로 유지한다. **행성 간 자동 재고 공유·무비용 수송은 없다.** 물류망 완성 전 행성 내부 통합시장/정산을 근사할 수 있으나 이를 실제 섹터 간 운송 시스템으로 주장하지 않는다.

### 3.5 **모든 건설 시설의 합금 유지보수 — 이번 핵심 신규 규칙**

- 모든 건설 시설은 소유 주체(국영/민간) 및 운전 방식과 관계없이 **유지보수용 합금을 반드시 지속 소비**한다. 특정 시설만 합금을 소비하는 기존 예외 구조는 폐기 대상인 **시뮬레이션 설계 규칙**이다.
- 소비량은 **시설 종류, 단지 기반 규모, 설치 모듈 수, 가동 수준** 등에 따라 달라진다. 광업·제련·핵융합·핵분열·태양광·수소 생산 설비 및 이 단계에서 모델링하는 축전시설 모두 포함. 향후 다른 건설 시설에도 같은 계약을 적용할 수 있어야 한다.
- **일시 운용 중단 시** 인건/관리 등 **C 운영비는 상당히 감소**한다. 그러나 구조물 보존·부식/교체를 위한 **합금 유지보수 U는 정상의 대부분이 계속 소모**되고 *조금만 감소*한다. 전력은 최소 보존 수요만, 생산용 연료/원료는 가동을 멈춘 만큼 줄인다.
- 시설과 모듈이 **완공되기 전에는 가동시설 유지보수비를 청구하지 않는다.** 완공 후 가동/대기/중단에 따라 비용을 발생시키되, 기반 구조물과 개별 모듈의 비용을 중복 계산하지 않는다.
- 합금 유지보수는 **실제 U 재고 차감**이며, 자체 보유 합금을 쓰는 것은 금전적 지출이 아니다. 시장에서 부족분을 사는 경우에만 실제 C 구매비가 발생한다.
- 합금이 부족하면 필요한 유지보수를 전부 수행한 것처럼 처리하지 않는다. 공급 제한, 설비 상태/효율 악화, 복구비 등 검증 가능한 결과가 있어야 한다. 즉시 자산 소멸만 발생하는 과격한 규칙은 피하고, 부족 지속기간에 따른 효과를 탐색한다.

## 4. 발전소 건설비의 잠정 출발값 — **아직 사용자 확정 수치 아님**

아래는 앞선 설계 대화에서 제안된 가격표다. **3차 탐색의 시작점/민감도 비교용**으로만 사용하고, 사용자 확정값처럼 소스 상수로 박아두지 않는다. 채굴/제련의 이미 구현된 건설비는 해당 표로 덮어쓰지 않는다.

| 항목 | 핵융합 | 핵분열 | 태양광 |
|---|---:|---:|---:|
| 단지 기반 건설 C | 15,000C | 8,000C | 5,000C |
| 단지 기반 건설 합금 | 1,200U | 650U | 400U |
| 모듈 1기 건설 C | 6,000C | 3,000C | 2,000C |
| 모듈 1기 건설 합금 | 450U | 250U | 100U |
| 모듈 1기 **건설 전용** 수소 | **5U** | 0 | 0 |

- **태양광 건설에도 합금이 필수**다. 위 400U/100U는 제안 예시이며 정확한 양은 탐색한다.
- 핵융합의 건설 수소 5U는 사용자 제시 규칙. 위 표에 **기동 수소 5U**와 **정상 운전 2.5U/월**은 포함돼 있지 않다.
- 건설 C·합금 요구량, 모듈당 출력 및 수명, 월 운영비, 전기요금, 실현 가동률을 함께 보고 **발전기 투자 회수기간**을 계산한다. 공사 C 비용을 낮추는 것만으로 합격시키지 않는다.
- 핵분열에는 지속적인 C·합금 유지보수, 태양광에는 저연료/저기동 부담과 조건에 따른 낮은 평균 출력, 핵융합에는 지속 수소·비싼 기동·높은 연속 출력이라는 차이를 유지한다. 핵분열 합금은 핵연료 자체의 대체재가 아니라 **유지보수 자재**로 취급한다.

## 5. 시뮬레이터 모델 요구사항

### 5.1 경제·전력·자원은 하나의 월간 장부에서 정산

- 선행 경제 모델의 인구·생산성·GDP·물가·통화·세수·정부 행동·민간 합금 공급/수요를 보존하고 **전력/수소/시설 비용과 실질적인 상호 제약**을 추가한다.
- 월간 정산 순서는 문서화한다. 권장: **이월 재고·현금/시설 상태 확인 → 건설·기동 일정 → 전력 생산가능량/수요 계산 → 필수 수요 배정 → 산업 가동률 결정 → 광석·합금·수소 생산/실제 투입 → 유지보수/구매·판매·세금·예산 결제 → 시장가격/다음 달 투자 의사결정**. 서로 의존적인 양은 필요하면 부분 틱/명시적 조정 단계를 사용하여 순서에 따라 자원이 창조되지 않게 한다.
- 전력은 MW/GW의 **용량**과 MWh/GWh/TWh의 **월간 에너지**를 모두 계산하고, 실제 가동시간·가동률·기동 중 발전·기동 전력 소비·축전 손실을 반영한다.
- 광업/제련의 전력 소비는 **설비 규모, 실제 처리량/가동률, 난도/품질 및 고정 부하**에 근거해야 한다. 단순히 생산량을 아무렇게나 0.001MW로 만드는 식의 수치 조정 금지. 에너지 집약도(예: MWh/U 또는 MWh/톤)와 그 근거/탐색 범위를 명시한다.
- 전력 부족은 산업 가동률/실제 생산량을 감소시켜야 하고, 감소한 생산량은 합금·수소 공급, 가격, GDP, 재정에 영향을 줘야 한다. 전력 생산시설 자신도 유지보수/연료 부족의 영향을 받는다.
- 정부가 재고로 보유한 합금/수소와 민간 시장 재고를 분리하며, 광석 원료와 완제품 합금도 구분한다. 유지보수·건설에 들어간 합금은 실물 U 재고를 줄인다. 월말 마이너스 재고, 무원인 생성·삭제 금지.

### 5.2 **기존 지구 기초 전력 인프라의 이중 계산 방지**

- 지구 2100년의 전력 수요 출발점은 **평균 약 8.12TW, 연 약 71,144TWh**라는 잠정 추정치로 둔다. 피크 수요 약 10~11TW 또한 잠정 스트레스 조건이다. 이는 **기존 도시·민간 산업·인프라가 사용하던 전력까지 포함**한 기초 수요다.
- 지구는 시작 시점부터 이에 대응하는 **기존 발전 기반시설**을 가진다. 게임 시작 순간 전체 정전이 일어나지 않도록, 초기 기준 공급/예비율을 함께 보정한다.
- 이 기초 수요에 이미 포함된 기존 산업 전력량을 신규 정부 광업/제련·기존 민간 산업 수요로 다시 더하지 않는다. 신규 증설 또는 명시적으로 추상 기반시설에서 분리한 증분만 **추가 전력 수요**로 기록한다.
- 마찬가지로 기존 GDP에 내포된 전기요금·산업 운영비를 새 모델에서 **추가 GDP 창출 또는 새로운 국민 총지출**인 것처럼 이중 계산하지 않는다. 기초 민간 발전/소비는 추상 회계상 내부 정산으로 남길 수 있으나, 국가 GDP와 통화량에 추가 합산해서는 안 된다.
- 달/화성의 초기 전력망/수요는 별도 소규모 잠정값으로 탐색한다. 지구 전력을 송전하거나 별도 비용 없이 합금·수소를 옮겨 식민지 경제를 안정화시키지 않는다. 초기 식민지 건설에 필요한 자원이 현지 재고에 없다면 공사를 진행시키지 말고, 별도의 **유한한 초기 현지 비축/명시적인 외부 지원 이벤트**를 시험 설정에 넣어 그 출처·비용·수량을 기록한다. 이 이벤트를 실시간 물류망 구현으로 표시하지 않는다.

### 5.3 크레딧(C) 실제 흐름 — 무료 수익과 이중 운영비 금지

- 정부 ↔ 민간 전력·합금·수소 **거래**는 반드시 지급자에서 C 차감, 수취자에 같은 C 증가. 자체 생산물/자체 소비는 비용의 경제적 기회가치로 평가할 수 있지만 **외부 현금 지출/실제 매출로 계상하지 않는다**.
- 기존 민간 생산 비용은 일부 현금 계정 없이 투자 문턱 계산에 쓰이는 **그림자 비용**이었다. 3차에서는 필요한 최소한의 **집계 민간 현금/투자 장부**를 도입해 전력·수소·합금 결제를 추적한다. 개별 기업·회사 생성은 하지 않는다. 기존 통화 공급량 `M=Y/V` 및 발행·회수와 민간/정부 보유액의 관계를 명확히 보고한다. 정부 국고 외에 집계 민간 산업 및 가계/노동·서비스 공급자를 대표하는 집계 현금 계정을 두거나 동등한 이중기입 방식으로 정산해, 국영 급여·관리비가 이유 없이 통화량에서 사라지지 않게 한다. 명시적 발행·소각·외부 유출입을 제외한 현금 계정 합계는 통화 공급량과 대사해야 한다.
- 화폐 발행·소각·차입, 세금, 정부 예산 등 통화 변화는 선행 규칙을 따르고 별도 장부로 추적한다. **합금 생산/민간 설비 신설/전력 생산이 직접 C를 창조하지 않는다.** 민간의 구매력이 부족하면 거래량과 투자/가동이 제한되어야 한다.
- **핵심: ECON-SIM-2의 `governmentOperatingRate=0.115`, `privateOperatingRate=0.10`을 실제 급여·관리비·합금/수소/전기 구매비 위에 그대로 더하지 말 것.** 3차에서는 각 항목을 명시적 실비로 **대체**, 또는 이미 모델링되지 않은 잔여 비용만을 설명 가능한 **residual**로 분리하고 차감 근거를 보고한다.
- 유지보수 합금(U)과 그 **구매대금(C)**은 서로 다른 장부 항목이다. C 운영비 내 `alloyPurchaseC`가 이미 포함돼 있다면 총지출 계산에서 중복 추가하지 않는다. 민간 생산원가와 기존 3.6% 합금 시장 수요 안에 신규 유지보수 수요를 중복 더하지 않도록 **기초 일반 수요/새로운 유지보수 수요를 분해**한다.
- 시설 C 비용은 공사비·운영 급여/관리·전기 구입·수소 구입·합금 구입·차입 이자·기동/재기동으로 구분하여 보고한다. 합금(U)·수소(U)·전기(GWh)는 별도 수량 장부로 남긴다.

### 5.4 가동·중단·유지보수 계약

각 시설/모듈에 최소한 `construction`, `starting`(해당 시), `active`, `curtailed`, `paused`, `coldStopped`(해당 시) 상태를 정의한다. 시설 종류별 적용 가능한 상태를 구분한다.

**정상 가동 예시 식(형식 예시, 계수 미정):**

```text
월간 직접 C 운영비 = 단지 고정 인건/관리 C
                 + 설치 모듈별 고정 인건/관리 C
                 + 실제 가동률에 비례한 변동 인건/정비 C
                 + 실제 외부 전기/합금/수소 구매 C

월간 합금 유지보수 U = 단지 기본 보존 U
                   + 설치 모듈별 보존 U
                   + 가동량에 비례한 마모 보수 U

운용 중단 C 비용 = 정상 C 급여/관리의 낮은 잔존분
                  + 실제 최소 보존 전력 및 필요한 구매비
운용 중단 합금 U = 정상 합금 유지보수의 높은 잔존분
```

- **C 잔존율은 크게 감소, 합금 잔존율은 소폭 감소**해야 한다. 처음 탐색 범위를 정할 때 예시로 C 5~30%, 합금 U 80~100%를 사용할 수 있으나 이는 **검증용 범위 제안**일 뿐 사용자 확정값이 아니다. 시설별로 다른 값을 허용한다.
- `paused` 중 생산용 원료는 사실상 멈추되, 유지보수 합금은 계속 차감한다. 유휴 설비에 대해 이미 설치된 모듈의 유지보수 부담을 0으로 없애지 않는다.
- 정상→중단→복귀 전후 합금/수소/전력/C 장부가 보존되어야 한다. 핵융합이 완전 냉간 정지라면 재기동 절차와 비용을 다시 적용하고, 단순 출력 감산에는 적용하지 않는다.
- 합금 부족으로 유지보수가 미달되면 **유지보수 결손/시설 건전도**를 기록한다. 장기간 결손 시 출력/처리량 감소, 재가동 복구비 상승 등을 시뮬레이터 수준에서 탐색한다. 회복 시 사용한 합금·C 없이 건전도가 즉시 최대치로 복구되면 안 된다.

### 5.5 수요·공급 균형과 시장

- 합금 시장: 광업→광석→제련→합금, 민간 및 국영 보유량, 건설투입/산업수요/합금 유지보수 소비를 반영한다. 합금 **실질 기준가 2.3C/U**와 2차의 가격/투자 지연 모델을 비교하여 모형 충돌을 분석한다.
- 수소 시장: 광업 부산물·수원 접근 생산설비·민간 생산과 발전/제련/건설/기동/함선 관련 가능 수요를 구분한다. 함선 연료 소비량 자체가 미정이면 임의의 확정값을 발명하지 말고 **별도 민감도 시나리오**로 두고 실제 설계와 분리 표기한다.
- 전력 시장: 기존 기초 발전량, 발전 방식별 가동률, 실제 계통에 공급 가능한 에너지, 기동 입력·수전해·산업·도시 수요를 차감한다. 잔여 공급과 사용되지 못한 발전량을 기록한다.
- 수소·합금·전력 가격이 서로 영향을 주더라도 일방적인 `최저가·무제한 공급` 가정으로 균형을 강제하지 않는다. 시장 가격 급등을 미리 정해둔 상한 하나로 감춰서는 안 된다. 가격 상한을 둔다면 상한에서 **미충족 주문/정전**으로 부족 상황을 남긴다.
- 태양광 평균 출력/발전소 초기 연료, 수전해 소모 전력, 광업/제련 소모 전력은 현실적 산업·물리 규모와 기존 게임 단위에 맞도록 **근거 있는 탐색 구간**을 마련한다. 실제 근거가 부족하면 가정을 노출하고 결과를 민감도로 분리한다.

## 6. 탐색 매개변수 — Codex가 찾을 것

필수적으로 탐색할 항목은 다음과 같다. **아래에 정답 숫자를 미리 채워 넣지 않는다.** 먼저 단위·투자 규모·실제 물리량과 2차 경제 구조를 기준으로 타당한 범위를 제안하고, 설정 JSON에 출처·기본값·상하한·의미를 기록한다. 지나치게 넓으면 1차 탐색→민감도 분석→2차 좁힘으로 진행한다.

| 묶음 | 탐색 매개변수 |
|---|---|
| 광업단지 | 정격/처리량당 전력 수요(MW, MWh/U), 고정/변동 인건비 C, 관리비 C, **합금 유지보수 U/월**, 운영 중단 잔존율, 유지보수 결손 영향 |
| 제련단지 | 정격/처리량당 전력 수요, 고정/변동 인건·관리비 C, **합금 유지보수 U/월**, 수소 보조 사용과 추가 생산 경제성, 중단 잔존율 |
| 핵융합 | 고정/변동 운영비 C, **합금 유지보수 U/월(단지+모듈)**, 최소 유지 출력, 냉간 정지 조건, 재기동 추가/할인 비용, 기동 전력 부족 대처 |
| 핵분열 | 고정/변동 운영비 C, **합금 유지보수 U/월**, 출력 제한·기동/중단 특성(확정되지 않은 부분), 공급 원가 |
| 태양광 | 행성별 평균 발전계수, 고정/변동 운영비 C, **합금 유지보수 U/월**, 일사량 불리한 시나리오, 실제 전력 공급 원가 |
| 수소 생산 모듈 | 모듈 건설 C/U, 생산 U/월, 전력 소모 MWh/U, 운영비 C, **합금 유지보수 U/월**, 국영/민간 공급 탄력성 |
| 축전·비상 | 탐색용 필요 용량/초기 비용/운영 C·합금 U, 충·방전 효율, 비상 가동 정책(이번 단계에는 간략 모델 허용) |
| 전력 시장 | 초기 민간 기초 공급능력·예비율, 전력 가격 C/GWh, 수요 탄력성, 국영/민간 배전 우선순위, 부족으로 인한 GDP/생산 손실 |
| 수소 시장 | 기준가 0.4C/U 주위 공급/수요 민감도, 재고 목표·가격 조정, 민간 공급 확장 지연 |
| 공사·투자 | **잠정** 발전소 C/U 건설비의 ±범위 재검증, 경제적 병렬 시공량/할증률, 기술/경험 효과를 켰을 때의 비교, 발전 투자 회수기간 |
| 시설 공통 | **가동 중단 C 잔존율(낮음)/합금 U 잔존율(높음)**, 자원 공급 중단 시 상태 악화 및 복구 속도 |

설계상 고정된 **모듈 용량·최대 모듈 수·모듈 공사 기간·핵융합 기동 4일·정상 수소 2.5U/월·건설/기동 수소 각각 5U**는 탐색으로 바꾸지 않는다. 사용자가 잠정으로 둔 가격/건설 C/U 및 기초 전력 수요는 원안+민감도 비교로 두고 확정처럼 취급하지 않는다.

**전기요금의 탐색법:** 전기요금을 임의의 큰 C/GWh에서 시작하지 말고, *기초 전력 지출이 GDP에서 차지할 수 있는 합리적인 비중*과 지구 평균 사용량(연 71,144TWh)을 이용해 환산한 가격 범위를 먼저 도출한다. 예를 들어 지구 연간 GDP 2,000만C 중 전력 사용료가 **5%라고 가정할 때 약 0.014C/GWh**라는 계산이 가능하다. **5%도 0.014도 확정값이 아닌 단위/규모 검산 예시**다. 이후 생산자 원가·민간 구매력·건설비 회수와 맞춰 탐색한다.

**가능한 보정 방식:** LHS/격자/적응형 탐색을 사용할 수 있다. 수십 개 매개변수를 무작정 완전조합하지 말고, 모듈별 단위 규모를 먼저 보정하고 중요 민감도에 표본을 집중한다. 실제 실행한 조합 수×시나리오×시드, 표본 거절 수, 탐색 공간 축소 근거를 기록한다. 동일 설정/시드 재실행은 동일 결과/해시가 나와야 한다.

## 7. 시나리오 설계

### 7.1 2차와 직접 비교할 대조 시나리오

**S0, S1, S2, S3-debt, S3-money, S4, S1-sell**을 가능한 한 그대로 유지한다. 신규 전력·운영비 모델을 **OFF/ON**으로 구분한 결과를 나란히 제출한다. 2차에 없던 전력 설비나 자원 거래가 없는 상태를 2차와 동일하다고 속여서는 안 된다.

### 7.2 3차 신규 시나리오 (ID 예시)

| ID | 내용 | 주요 검증 |
|---|---|---|
| E0 | 지구 기존 전력망·민간 산업의 평시 성장 | 시작 정전 없음, 이중 수요/비용 없음, 20년 재정·물가·합금가격 안정 |
| E1 | 지구 국영 발전단지 건설/증설, 민간에 일부 전기 판매 | C 회계 보존, 정부 투자회수, 민간 구축, 기존 국영 시설 자체소비 매출 0 |
| E2 | 신규 달/화성 식민지에 소규모 핵분열·태양광/축전 설비 단계 건설 | 초기 기초 전력 확보, 기동/정전, 행성 간 무상 수송·송전 0 |
| E3 | 전력 피크 급증 또는 공급능력 급감 | 필수 수요 보호, 산업 감산, GDP/합금 생산 피드백, 정전 복구 |
| E4 | 수소 공급 부족 + 핵융합 가동/기동 겹침 | 출력 자동 감소, 냉간 정지·4일 재기동, 수소 가격/잔량, 부팅 불능 식민지 |
| E5 | 합금 공급 부족/국영 판매 급증 + 전 시설 유지보수 | 유지보수 부족·건전도 악화, 광업/제련 연쇄 영향, 민간 투자 위축 |
| E6 | 발전소·광업·제련의 장·단기 일시 운용 중단과 복구 | C 크게 절감, 합금 U 거의 유지, 냉간 기동과 비용 회수, 중단 꼼수 방지 |
| E7 | 동일 행성에서 과도한 동시 모듈 착공 | 병렬 C 할증, 기술/학습 보정, 과도한 조기 발전 확장 손익 |
| E8 | 수원 조건 유무 및 태양광 불리 조건 비교 | 전력 없는 전기분해 금지, 수소 공급원 제약, 현실적인 평균출력 |

- **E0~E2는 평시 적합성**, E3~E8은 **스트레스 내성 및 정보 지표**로 구분한다. 의도적으로 위기를 만든 E4/E5에 평시 가격·예산 기준을 무조건 강제하지 않는다.
- 하드 불변조건/장부 무결성은 **모든 시나리오**에서 예외 없이 적용한다.
- 성능/시간 부담이 크다면 예비 탐색에서는 핵심 평시+대표 스트레스만, 상위 후보의 최종 재검증에서는 **전체 시나리오 × 최소 5시드**를 수행한다. 생략한 항목이 있으면 이유와 건수를 명시한다.

## 8. 합격 기준 — 통과 여부와 정보 지표를 구분

### 8.1 변경 불가능한 무결성 기준 (전 시나리오)

- 합금·광석·수소·축전 에너지·현금·인구에 원인 없는 생성/소멸 없음. 비음수 재고, NaN/Infinity 없음. 수량·화폐의 반올림 오차와 허용 오차는 문서화.
- 정격/최대 모듈 수·완공 일정 준수. **건설 미완료 모듈에서 전력 생산 0**. 단지 건설비 중복 징수 0.
- 핵융합 96시간 기동 곡선, **건설 수소 5U + 별도의 기동 수소 5U**, 2,500C 기동비, 정상 수소 2.5U/월 준수. 외부 기동 전력은 실제 배정·소비돼야 함. 기동 자원이 없는데 기동 진행만 완료되는 오류 0.
- 정상 가동/중단 여부와 관계없이 모든 **완공된 건설 시설의 합금 유지보수 소비량 > 0**(시설 종류·모듈 수에 맞는 양). 중단 시 C 감소폭이 합금 감소폭보다 **충분히 큼**(명시한 상대·절대 지표로 검증), 중단 시설에 무료 보존 없음.
- 국영 자체 발전/자체 소비의 국고 매출 0; 정부/민간 실거래 C 이전은 **지급액 = 수취액**. 국영·민간 수소/합금 재고 독립. 행성 간 자동 물류/송전 0.
- 수원 없는 곳의 수전해 설비 생산 0, H 없는 광산의 H 부산물 0, 전력 배정 없는 전기분해 생산 0. 전력 공급량 및 저장 방전량 이상으로 수요가 충족되지 않음.
- 신규 전력·실비 모델 OFF에서 2차의 합의된 비교 결과/결정적 실행이 동일하게 재현됨. 추가 운영비를 구형 프록시와 이중 부과하는 경로 0.

### 8.2 평시 거시 지표 (S0~S2, E0~E2에서 가능 범위)

- 2차 평시 실질 합금가격 **기준가 ±15%**, 20년 평균 **±8%**, 물가 상승률 연 **1~3%**, 17년차 재량 예산 증가율 명목 **1.1~1.6배**를 **선행 대조 기준**으로 계속 측정한다. 새로운 원가가 이 기준을 깨면 **무엇 때문에 깨는지 분석**한다. 필요하면 후보를 *기준 만족/부분 충족/근접*으로 분류하되, 테스트를 바꾸지 않고 통과로 위장하지 않는다.
- 지구 시작 시점에는 기존 기초 전력 수요에 대응하는 공급이 있어야 하며 정상 경로에서 기초 수요 전부를 구조적으로 끊는 시작 정전은 실패. 이후 통상 성장·투자 시나리오에서는 미충족 전력 비중, 공급 안정성, 예비력 추이를 보고한다.
- 광업/제련/발전시설의 **실제 전력·합금·수소·C를 고려한 원가/손익** 및 투자 회수 가능성을 보고한다. 2차의 ‘운영비 0 회수 1.5~3년’을 **실제 운영비 포함 후에도 무조건 같은 합격 범위로 강제하지 않는다.** 운영비 0 대조와 실비 포함 회수기간을 따로 계산하고 새로운 목표 범위를 근거와 함께 제안한다.
- 국영/민간 발전 전기요금이 민간 구매력·GDP와 비교해 터무니없지 않아야 한다. 전력 가격의 GDP 대비 비용 비중, 발전 원가/판매가, 과도한 국고 이윤, 민간 설비 위축을 서로 함께 검증한다.
- 수소는 평시 수급/가격이 0.4C/U 근방에서 유지될 수 있는 후보와, 0.4가 불가능한 후보를 **모두** 보고한다. 수전해 원가 > 시장가라면 수전해가 시장에서 자생 불가능한 이유를 숨기거나 억지 수익 보조금을 넣지 않는다.

### 8.3 스트레스 지표는 진단 목적

- E3~E8의 전력·수소·합금 부족 시 감산, 정지, 긴급 지출/복구 시간, 산업 손실, 가격 변동을 그래프와 표로 보고한다.
- 전시 충격/4년 이내 회복·식민지 일반 지원 부담 등 2차 기준은 **해당 기존 시나리오에만** 적용한다. 국영 생산 점유율과 의도적 국영 판매/식민지 집중 시나리오의 과도한 부담은 강제 탈락 조건이 아니라 **정보 지표**로 유지한다.
- 각 후보의 장점뿐 아니라 실패 시나리오·장기 리스크를 반드시 기록한다.

**판정 방식:** *무결성 전체 통과* + *지정된 평시 기준의 모든 시드 동시 통과*를 별도 나타낸다. 스트레스 점수, 손익, 정책 판단은 추가 정보로 분리한다. 합격 0개면 실패 원인을 기준별/시나리오별 분해하고 가장 가까운 후보를 보고한다. 수치 기반 기준이 부족하다면 합리적 추가 기준을 **보고서상 제안**하되 사용자 승인 없이 ‘이미 확정된 기준’으로 바꾸지 않는다.

## 9. 탐색 절차·모델 검증

1. **감사/회귀:** 2차 모델 재현, 함수·장부·프록시/민간 집계의 연결 지점 확인. 현행 2차 `rounded-4`와 후보 3개를 **동일 설정에서 3차 OFF/ON 대조**.
2. **단위·하위 모델 검사:** 5GW/2.5GW/1.5GW 출력, 4일 기동 에너지 75/180GWh, 현행 국영 광업·제련 계약, 자원/수원/일사량 제약, 합금 유지보수 ON/PAUSED 검산.
3. **독립 산업/발전 수치 예비 탐색:** 광업·제련 전력 집약도 및 실비, 3개 발전 방식 운영비, 수소 생산 원가, 전력요금의 타당한 범위 설정. 건설비·가격을 함부로 낮추지 말고 근거를 기록.
4. **거시 통합 넓은 탐색:** 2차의 반올림 경제값을 기본 대조로 두고 전력·운영비 묶음 후보를 LHS/계층적 샘플링으로 탐색. 표본 규모는 성능 측정 후 정하되, 가능하면 **512개 이상의 조합 × 최소 5시드**를 확보하고 실제 건수를 명시. 기초 평시/대표 위기를 병행.
5. **민감도/OAT·부분 탐색:** 가동률, 합금 유지보수, 전기요금, 시설의 C 비용, 수소 생산 효율, 민간 전력 확장 지연, 시작 예비전력 등의 영향 순위를 도출. 민감 변수를 중심으로 좁힌 2차 탐색.
6. **상위 후보 교차 검증:** 견고성 높은 후보 3개 이상을 **전체 시나리오 × 5시드 이상**으로 재실행. 2차 `rounded-4`와 비교해 월별 경제 성과가 어디서 달라졌는지 설명.
7. **사람이 쓰기 쉬운 반올림 후보:** 상위 후보 근방에서 제안값 한 세트를 반올림하고, 임의 보정 없이 **별도 5시드 전체 재실행** 후 실제 통과 여부를 기록. 실패하면 실패 그대로 표기하고 다음 근접안을 보고.
8. **반례/돌연변이 검사:** 전력 0인데 수전해 생산, H 0인데 핵융합 최대출력, 중단 시설 합금 0, 기동 전력 없는 96시간 자동 가동, 국영 자체발전 허위 판매, 2차 운영비 재청구, 다른 행성의 재고 빌려쓰기 등 오류를 주입해 테스트가 탐지하는지 확인.

**성능:** 기존 2차의 단일 20년 실행 p50 약 2.77ms/p95 약 4.21ms, 전체 2차 탐색 약 62초를 비교 기준으로 기록하고, 3차의 실제 측정값을 공개한다. 새 하위 모델의 비용을 이유 없이 폭증시키지 말 것. 총 탐색에 사용한 실행 시간과 하드웨어/런타임 환경을 보고한다.

## 10. 반드시 포함할 자동 테스트

새 `tests/economy-energy-model.test.js` 등으로 구현한다. 기존 경제 모델 테스트를 훼손하지 말고 **전체 기존 테스트+신규 테스트를 함께 통과**시킨다.

1. **결정성/회귀:** 동일 시드·설정 결과 해시 동일; 신규 모델 OFF 시 2차 회귀와 주요 출력 일치.
2. **시설 범위:** 각 발전소별 모듈당 출력·최대 개수·공사시간·공사 완료 조건·기존 단지 증설에서 기반 공사 재부과 금지.
3. **핵융합 건설:** 모듈당 건설용 H 5U, 기동용 H 5U 별개. C 건설비/기동비 별개.
4. **기동 96h:** 0~24h 발전 0, 입력 1,250MW; 24~96h 출력 연속 상승/입력 연속 감소; 종료시 5GW/0MW. 통합 외부 에너지 75GWh·발전 180GWh·수소 5U(수치 허용오차 내).
5. **기동 실패:** 외부 전력/수소 부족 시 진행 상태와 실제 소비량 일치; 자원 없이 즉시 완성 금지; 여러 모듈 기동 시 전력 상한 준수.
6. **정상·정지:** 5GW 정상 수소 2.5U/월, 감산 비례 소모, 냉간 정지 후 재기동 비용, 단순 감산 시 재기동 비용 없음.
7. **전력:** MW와 MWh 단위 구분, 수요·공급·초기 전력·축전 장부 보존. 태양광 정격 ≠ 평균 출력, 음수 에너지 금지.
8. **수소:** 원천/수원 없는 시설 생산 0, 전력 없이 수전해 0, H 잔량 비음수, 정부↔민간 거래 보존, 행성 간 무상이동 0.
9. **합금:** 모든 완공 시설 운영/중단 상태의 **필요 합금 유지보수량 >0**, 시설별 상이한 소요량, 모듈 수 증가에 따른 소요량 증가, 실제 소비량의 재고 상한 및 U 장부 보존, 부족 시 미이행분/결손 누적.
10. **일시 중단:** C 운영비 대폭 감소, 합금 유지보수 U는 조금만 감소, 정상 복귀 시 허위 수익/무료 복구 없음.
11. **광업/제련:** 전력 부족 시 실산출 감소, 채굴 난도·품질 수율·수소 부스트가 기존 모델과 일관, 광석과 합금 재고 분리.
12. **현금 회계:** 국영 자체 사용 매출 0, 모든 거래에서 정부·민간 C 이전 합계 0(발행/소각·외부 요인은 별도), 공급자 수취액=구매자 지출액. 프록시 운영비와 실제 비용 중복 청구 0.
13. **민간 집계:** 민간 발전/수소 생산에 회사 객체 생성 불필요, 투자·공급능력·현금 잔고가 보존되고 C 없는 구매 불가.
14. **거시:** 시작 `M₀=Y₀/V`, 정상 물가지수/시설 C 물가 연동, 기존 2차 전시·예산 시나리오 대조 결과 유지(OFF 기준).
15. **견고성:** 양수/0/상한 경계, 극단적 합금·수소·전력 부족, 모든 시나리오에서 NaN/무한대/음수 재고 없음.
