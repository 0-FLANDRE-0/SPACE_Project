## 부족 모드와 유예의 정확한 시각

매월 충격·완공·기존 정지 결정 이후, 유지보수 이전에 각 천체의 정부+민간 **자유 합금**과 실제 전 시설 월 보수 필요량을 관측한다. 건설 자본/SCU 묶임은 자유 재고가 아니다. 진입은 `free < N×need`, 해제는 `free >= exitMultiple×N×need`다. 보수 필요량은 R4 실제 가동·정지·부분 공사의 bill로 계산하며, 미납 부채는 이 진입 정의에 숨겨 더하지 않는다. 관측/진입·해제 기록은 매달 한 번이다.

모드 적용 시 산업→발전→필수망→기타, 평상시는 기존 필수망→발전→산업→기타다. **생명유지의 집계 대리변수는 R4에서 이미 우선순위0으로 분류한 legacyGrid/essential 자산**이다. 특히 legacyGrid는 필수 생명유지만 분리한 시설이 아니라 기존 전력망 집계이므로, 유예가 전체 망을 보호하는 효과는 추후 필수/일반 부하 분리가 필요한 모형 한계다. 새로운 생명유지 시설이나 인구 사망 모형은 발명하지 않는다.

첫 미납 월을1개월차로 세어 G개월 동안 해당 자산의 소재 미납에 의한 건전도 하락을 유예한다. 직접 C 비용과 실제 다른 전력/연료 제약은 계속 적용한다. `lifeAccruedQ = lifeDeferredQ + lifeRepaidQ`를 정수0.001U 단위로 감사하고 기존 전체 `backlogU`에도 포함한다. **마지막 유예 월이 시작되기 전에**, 남은 미납이 있는 자산은 최우선으로 복귀한다. 다음(G+1)개월 미납부터 기존 손상률×탐색 배율로 하락한다. 모드 해제/재진입으로 유예 시계를 초기화하지 않으며, 현재 보수 한 번을 낸 것만으로 과거 부채를 지우지 않는다. 실제 합금 수리와 C 노동비를 내고 미납을 상환한 뒤에야 시계를 재설정한다.

최우선 복귀는 자원을 무상 생성하지 않는다. 모든 재고가 바닥나 유예가 끝나면 실제 건전도/출력이 떨어지는 사례를 정보로 기록한다. `lifeDamageAssetMonths`는 자산·월 단위 손상이며 인명 피해 숫자가 아니다. 각 경로에서 손상이 한 번이라도 있었는지의 사례 수도 따로 집계한다.

## 긴급 매입과 수입

정부 조달 목표는 **행성 전체 월 보수×N+전 시설 미납량**이다. 정부 자신의 소수 시설만으로 한정하면 민간 산업의 복구 필요량이 빠지므로 전체를 대상으로 한다. 이 목표/공급자 순서는 명시적 추가 운전 가정이며 사용자 확정 수치가 아니다. 매입/수입은 정부 재고에 들어오며, 민간 운영자에게 도달하는 과정은 기존 R4의 현지 유상 거래/보유분 규칙을 유지한다. 소유권 이동은 행성 총 합금을 늘리지 않는다.

시장 매입은 부족 관측이 활성일 때만, 정부 목표 부족량·현재 민간 재고의탐색 한도·정부 C 중 최소만 거래한다. 가격은 해당 천체 실질 시가×프리미엄×CPI를 한 번 적용한다. 매입 지급=민간 수취, 내용물은 민간에서 정부로 실제 이전한다. 그 뒤 재고 부족의 내생 가격 반응을 별도 관측하며 가격을 고정하지 않는다.

수입은 지구가 부족할 때 기존 달→화성 순서, 각 정부→민간 순서로만 제안한다. 공급자의 자기 소유 시설 월 보수뿐 아니라 **천체 전체 월 보수×`max(N,donorReserveMonths)`**도 보존하며 **내용물+선택된 실제 SCU 소재** 모두 이 하한 밖에서 마련한다. 각 출발지의 자기 보수 후 출하 직전에 상한을 다시 계산한다. 다른 소유자의 자유 재고를 고려한 천체 전체 하한과 출하 소유자 하한을 동시에 적용한다. 정부 소유 시설이 없어도 그 천체의 민간 필수망 비축이0이 되도록 팔 수 없다. 같은 정부의 내부 이전에는 상품 대금0, 민간→지구 정부에는 실제 상품 대금이 있으며, 양쪽 모두 소재·직접 포장 C/전력·운임은 양수로 부담한다. 포장 kWh는 기존 `transferRound4`를 그대로 써 실제 출발 망에서 차감한다. 실패한 제안은 다음 달의 부족/재고 기준으로 다시 만들고, 위기가 끝난 뒤 오래된 제안이 출하되지 않게 취소한다.

즉시 수입이 있는 월은 실제 출발 망을 먼저 정산한 뒤 지구 보수를 정산해 같은 월에 수입품을 사용할 수 있게 한다. 출발지 보수/전력/연료 예약을 먼저 지불하고 부족한 만큼은 출하하지 않는다. 이는 명시적 월내 정산 순서이며 실제 화물선·항로·선적 시간·호위·금융 구제 엔진이 아니다. 보호 하한은 **출하 직후**의 보수 비축이며 이후 별도 일반 소비/정책까지 영구 동결하는 규칙은 아니다.

## 탐색과 자료

원래37축을 고정한 네 기반에 동일한7축 LHS64개를 사용해 기반 간 차이를 비교한다. 대표와 가장 강한 격자(70%/12개월/2배)를 자력/구호×5시드로 예비 비교하되, 격자는 정보로만 순위 보조에 쓴다. 각 기반의 근접안1개를 전체42경로×5시드×2lane로 재실행하고, R4-rounded의37축을 그대로 둔7축 반올림안도 별도 전체 실행한다. 중간 표본의 통과가 평시 전체 검증까지 완료됐다는 뜻은 아니다.

모든 표본·seed·scope를 원시 CSV에 기록한다. 전체 최종 행,18격자,생명유지 부채/손상·구호 비용 및 실제 시장/기준가 마진을 별도 JSON으로 공개한다. 월 시계열은 열 schema와 수치 배열로 보존하며 HTML에서만 표시용 정밀도를 줄인다. 실패한 후보도 삭제하거나 범위를 줄여 숨기지 않는다.
