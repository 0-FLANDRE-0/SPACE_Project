## 수율과 실제 광석 조건의 경제성

`z`는 기존 `yieldFraction`, `y`는 새 수율 증가율이다. `P`는 기존 무보조 처리능력, `P_fast`는 기존 제련 램프 기간만 13% 단축한 처리능력, `k`는 기존 보조 계수다.

```text
A = P × (1+k)
R = P_fast × (1+k)                 # (1+b) 삭제; 성숙 시 R=A
A_actual = min(실제 광석, A)
R_actual = min(실제 광석, R)
Y_A = A_actual × z
Y_R = R_actual × z × (1+y)
H_A = 기존 assistedSmelting이 같은 광석에서 실제로 쓰는 보조H
H_R = Y_R × h를 0.005U 반응 묶음으로 올림
ΔY = Y_R − Y_A
ΔH = H_R − H_A
ΔC = max(0,R_actual−A_actual) × 기존 광석당 전력 × 현지 전력가
     + max(0,R/A−1) × (R_actual/R) × 기존 직접C·보수의 시세 가치
환원 경제성: ΔY × 합금가 > ΔH × 수소가 + ΔC
p* = max(0,(ΔY × 합금가 − ΔC)/ΔH)    # ΔH>0
```

`y` 자체는 처리능력·전력·유지비를 늘리지 않는다. 빠른 램프로 실제 처리 광석이 늘 때의 기존 비용만 반영한다. 실제 계획·정산의 합금 공정 전력도 **기본 수율 산출**에 대응하는 기존 비용을 사용하고, 보너스 합금에 추가 청구하지 않는다. 채광·고정 비용은 기존 원장에 계속 정산한다. 임계값과 같으면 환원을 배정하지 않는다. p*는 가격 통제가 아닌 월별 대안 비교다.

지시서의 성숙 정부 1세트 예시(광석 3,200U, 기본 합금 약812U, 합금가2.3C, h=1)를 적용하면 y=10/15/20%의 p*는 약 **0.2091 / 0.3000 / 0.3833C/U**다. Claude 근사 0.23/0.33/0.42와의 차이는 기존 보조H 85U를 일률 공제하지 않기 때문이다. 이 광석량은 무보조 처리능력보다 적어 실제 기존 소비가 0이다. 광석이 충분한 경우에는 기존 함수가 실제로 계산한 보조H를 공제한다. 참고 근사를 맞추기 위해 가짜 소비를 만들지 않았다.

## 월 작업시간과 정수 질량

4.2.1처럼 남은 시간의 기존 보조H를 먼저 남긴다. `f=clamp((H_available−H_A)/(H_R−H_A),0,1)`에서 시작하되 경제성·실제 재고를 확인한다. 환원 합금Q를 정한 뒤 환원 광석은 `합금Q/(1000×z×(1+y))`, 실제 시간은 `환원 광석/R`이다. 0.005U H 올림 때문에 남은 보조H가 침해되면 환원Q를 줄인다. 남은 시간은 기존 공정, H=0이면 기존 무보조다. 정식 전환 상태·전환비·진입/해제 히스테리시스는 없다.

실제 전력·상태 비율을 적용한 뒤 0.001U 정수 Q로 정산한다.

```text
baseQ = floor(전체 실제 처리 광석Q × z)
hrBaseQ = floor(실제 환원 광석Q × z)
hrGrossQ = floor(실제 환원 광석Q × z × (1+y))
yieldBonusQ = hrGrossQ − hrBaseQ
alloyQ = baseQ + yieldBonusQ
grossResidueQ = processedOreQ − alloyQ
```

기존 합계 반올림을 유지하면서 보너스는 원래 잔재에서 합금으로 옮긴다. 광석 source는 늘리지 않는다. 실제 `hrGrossQ×h`만 H로 지불하고 기존 반응 양자·물·잔재 산소 회계를 재사용한다. 광석=합금+총잔재, 기본 합금+수율 보너스=실제 합금, 소유자별 H/물 provenance 및 C/U 원장 감사를 모두 수행한다.

## 새 수전해의 물 확보 조건

정부·민간의 모든 신규 수전해(재순환 전용 포함)에 `forecastWater422()`를 **비용 지출 전** 적용한다. 기존 설비는 소급 중단하거나 철거하지 않는다. 같은 소유자의 실제 재고·현재까지의 관측·기존 취수원만 읽는 별도 계획 견적이며 원장에 물·수소·현금을 생성하지 않는다.

**[임시 구현 해석]** 건설 지연을 거친 **완공 시점부터 N개 운영 월**을 검사한다. 그 전 준비 기간도 재고 소진을 예측한다. 각 월 `신규 설비 가용 취수Q ≥ ceil(설계 취수Q×waterGateFraction)`이어야 한다. 당시 이미 생산이 끝났으면 다음 tick부터 시작한다.

- 예상 부산물 물은 최근 최대 N개월의 실측 최솟값, 관측이 없으면 0이다. 보수적 견적이지 미래 생산 보장이 아니다.
- 현재 보유 H에서 기존 핵융합·보조 사용과 증발을 먼저 예약한다. 미래 부산물H는 관측 최솟값·기존 광산 능력·유한 잔량으로 제한한다. 신규 주문 설비가 만들 H로 자기 물 조건을 승인하는 순환 예측은 금지한다.
- 기존 전해의 미래H도 실제 물 배분 및 마지막 실측 이용률로 제한한다. 당월 말 산출H로 당월 초 환원을 돌리지 않는다.
- 기존 규칙처럼 부산물 물에서 생명유지를 정부→민간 순으로 먼저 배분한다. 재고의 비부산물 물·기존 취수원이 자동으로 생명유지의 새 공급원이 되지 않는다.
- 기존/건설 중 설비의 설계 취수를 먼저 예약한다. 공유 취수원은 전체 소유자·설비 설계 수요로 나눠 한 번만 계산하며, 필요량만 취수한다. 새 취수원·물 수입·무료 재고 축적은 없다.
- 새 환원 부산물 물은 생명유지 후 남아야 미래 취수에 쓸 수 있다. 후보 설비는 필요한 분율만 예약하는 대신 가능한 설계 전량을 매월 소비하는 보수적 예측을 쓴다.
- 미래 H-CUT 일정·재고 파괴를 읽지 않는다. 차단 전 같은 준비 대조와 경로가 같아야 한다.

통과한 새 자산에는 시작/완공 tick, N, 분율, 최소 충족률, 검사 월수, 설계 취수Q를 남겨 다시 감사한다. 물 부족이면 거래 없이 보류하고 다음 투자 판단에서 재평가한다. 재순환 후보는 기존 제련 기반이 있어야 제안 가능하지만 현재 부산물 재고가 0이어도 물 견적을 거치므로, 물 없는 주문을 숨기지 않고 보류로 기록한다.

## 보류·증산·광석 지표의 의미

같은 소유자의 미완료 물 부족 제안은 하나의 ID로 묶는다. 반복 판단은 소유자·월당 한 번만 시도 횟수를 늘린다. 나중에 건설되면 `builtAfterDelay`로 닫고 다음 제안을 새 ID로 시작한다. 첫 견적C는 제안당 한 번, 미완료C는 마지막 견적을 합산한다. **이 금액은 보류된 주문의 견적이며 실제 절약C가 아니다.** 마지막 모듈 수는 재검토 때 달라질 수 있다. 원장 현금 추적을 별도로 제공한다.

직접 수율 증가Q, OFF 대비 총 합금 순증, OFF 대비 240개월 평균 실질 합금가 변화는 따로 계산한다. 직접 증가분은 투자·전력·현금 경로의 간접 증감을 포함하지 않는다. 광석 제약 월은 실제 생산 단계에서 적어도 한 자산의 가용 광석이 전력·상태 적용 제련능력보다 먼저 바닥난 월이다. 분모는 제련 가능 월과 전체240개월을 둘 다 제공하며 자산월과 구분한다.
