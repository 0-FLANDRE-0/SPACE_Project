6. `docs/DECISIONS.md`에 이번 결과를 **확정값으로 기록하지 않는다.** "ECON-SIM-1 탐색 결과, 사용자 미결정"으로만 남긴다.

## 1. 목적

다음 질문에 숫자로 답할 수 있는 근거를 만든다.

- 인구·생산성이 성장할 때 10년·17년·20년 뒤 지구 GDP, 정부 재량 예산, 물가, 합금 가격은 어떻게 되는가?
- 정부가 "조연"으로 남는가? (정부 생산이 민간 대비 얼마나 되는가)
- 국영 광업단지+제련단지 한 세트의 투자 회수 기간은 현실적인가?
- 전시 동원(대량 매입·지출 확대)이 가격과 경제에 어떤 충격을 주고, 얼마 만에 회복하는가?
- 어떤 매개변수가 결과를 가장 크게 흔드는가?
- 시작 시중 통화량(예전 논의의 800만C vs 1,500만C)은 **시뮬레이션으로 고를 값이 아니라, 시작 합금 가격 2.3C/U가 성립하도록 보정되는 값**임을 확인하고, 선택한 유통속도 가정별로 도출되는 값을 보고한다.

## 4. 모델 — 최소 성장 시스템

**월 단위 고정 틱**으로 정산한다. 실수 누적 오차를 줄이기 위해 인구는 정수 명, 자원은 0.001U 정수, 크레딧은 정수 또는 0.001C 정수로 저장한다. `Math.random()`·시각 기반 난수 금지. 기존 `keyedRandom` 같은 결정적 난수를 시드와 함께 사용한다.

### 4.1 인구

- 천체별 연간 자연 증감률 `r_pop`을 월 복리로 적용. 증가·정체·감소 모두 지원.
- 이주는 이번에 시뮬레이션하지 않지만, 구조상 **출발지에서 빼고 도착지에 더하는** 함수 자리를 두고 질량(인구) 보존 테스트를 만든다.

### 4.2 생산성과 실질 GDP

- `실질GDP_천체 = 인구(POP) × POP당 생산성 × 공급 제약 계수`
- POP당 생산성은 연 성장률 `g`로 증가. 시드 기반의 작은 무작위 충격(표준편차 `σ_shock`)을 선택적으로 넣어 **성장이 항상 일어나지는 않음**을 시험한다.
- 공급 제약 계수: 합금이 부족하면(아래 시장 재고가 목표보다 낮으면) 실질 GDP를 소폭 깎는다. 계수와 강도는 매개변수.

### 4.3 통화와 물가 — **중요**

- 교환방정식 `M × V = P × Y`를 사용한다. `M` 시중 통화, `V` 유통속도(매개변수), `P` 물가지수, `Y` 실질 GDP.
- **시작 보정:** `P₀ = 1`이 되도록 `M₀ = Y₀ / V`로 정한다. 따라서 시작 합금 가격 2.3C/U가 성립한다. `V`별로 도출된 `M₀`를 보고서에 표로 남긴다.
- **통화 증가 규칙 (기본):** 매월 `M`을 실질 GDP 성장률 + 목표 물가상승률 `π*`(매개변수 0~3%/년)만큼 늘린다. **GDP가 컸다고 크레딧을 임의로 뿌리지 않는다.** 통화 발행은 이 규칙과 시나리오의 명시적 정책으로만 바뀐다.
- **대조 실험:** 통화량 고정 규칙도 함께 돌려, 고정 시 디플레이션이 생기고 광산 수익·함선 상대가격이 어떻게 왜곡되는지 보고한다.
- **재정 화폐화:** 전시 시나리오에서 정부가 통화를 찍어 지출을 메우는 옵션. 인플레이션으로 이어져야 한다.

### 4.4 명목 가격 지수 연동

- 함선·시설의 크레딧 가격은 `기준가 × P`로 움직인다(합금 요구량 U는 그대로).
- **대조 실험:** 지수 연동 없음(C 가격 고정)과 비교해, 인플레이션 시 함선·시설이 실질적으로 싸지는 문제를 보고한다.

### 4.5 합금 시장 (지구)

- **민간 합금 수요(U/월)** = 실질 GDP × 합금 사용 강도 × (실질 합금 가격 / 정상가)^(−ε) + 정부 매입.
 합금 사용 강도는 "시작 시점 민간 합금 시장 규모 = GDP의 `a`%"(매개변수 1.5~4%)가 되도록 보정한다.
- **공급** = 민간 생산능력 + 정부가 판매하는 국영 생산분.
- **가격:** 시장 재고(재고 일수)가 목표보다 적으면 오르고 많으면 내리는 완만한 조정 방식을 권장한다. 정상가 대비 상하한(예: 0.5배~2.5배)을 둔다. **진동·발산 없이 안정적**이어야 한다. 구현자가 다른 안정적 방식을 택해도 되지만 식과 이유를 문서화한다.
- 명목 합금 가격 = 실질 가격 × `P`.

### 4.6 민간 산업 확장

- 민간 단위 생산비는 국영 광업+제련 한 세트의 투자비 상각 + 운영비 매개변수로 유도한다(국영과 같은 기술 수준 가정, 별도 규모의 경제 계수 선택).
- 실질 가격이 단위 생산비 × (1 + 요구 마진)보다 높으면 지연 `L`개월(6~24) 뒤 생산능력이 증가율 `β`로 늘고, 낮으면 감가율 `δ`(연 2~5%)로 서서히 줄어든다.
- 지구 매장량은 이 기간 고갈되지 않으므로 고갈 계산은 생략하되, 누적 채굴량은 기록한다.

### 4.7 정부 재정

- 세수 = Σ(천체별 명목 GDP × 천체별 세율 × 징수 효율). 징수 효율은 이번엔 1, 자리만 둔다.
- 재량 예산 = 세수 × 우주·전략 예산 비율. 나머지는 추상 고정 지출로 처리한다.
- 지출: 함선 유지비, 시설 운영비, 식민지 지원비(매개변수, C/년), 시나리오별 건설·건조·매입.
- 국고가 음수가 되면 국채(이자율 매개변수) 또는 지출 보류. 시나리오별로 명시한다.
- 국영 생산 합금은 정부 재고로 들어가고, 시나리오에 따라 시장 판매 가능.

### 4.8 국영 시설 생산

- 실제 캠페인 런타임(`advanceIndustry`)을 돌리지 말고, `industry-policy.js` 함수로 **세트 단위 기대값 모델**을 만든다: 건설 기간 → 램프업 → 채굴 효율 반영 광석 생산 → 제련 처리량 한도 → 기대 품질 기반 합금 수율.
- 선택 항목: 검증용으로 `advanceIndustry`를 1회 짧게 돌려 기대값 모델과 오차를 비교하면 좋다(필수 아님).

### 4.9 식민지

- 달·화성은 면세, 작은 GDP, 지원비 지출. 이번엔 시장·물류를 시뮬레이션하지 않는다. 식민지가 지구 재정에 주는 부담 비율만 본다.

## 5. 탐색 매개변수와 범위

| 매개변수 | 범위 |
|---|---|
| 생산성 성장률 `g` | 연 0.5% ~ 2.5% |
| 지구 인구 증감률 | 연 −0.2% ~ +0.3% |
| 식민지 인구 증감률 | 연 0% ~ +2% |
| 지구 세율 | 20% ~ 30% |
| 우주·전략 예산 비율 | 세수의 1% ~ 4% |
| 유통속도 `V` | 1.0 ~ 2.0 |
| 목표 물가상승률 `π*` | 연 0% ~ 3% |
| 민간 합금 시장 비중 `a` | GDP의 1.5% ~ 4% |
| 수요 가격탄력성 `ε` | 0.2 ~ 0.8 |
| 가격 조정 강도·상하한 | 구현자 제안 범위 |
| 민간 증설 지연 `L` / 증가율 `β` / 감가 `δ` | 6~24개월 / 구현자 제안 / 연 2~5% |
| 함선 유지비 | 가격의 연 5% ~ 10% |
| 국영 시설 운영비 | 0 ~ 세트 투자비의 연 15% |
| 식민지 지원비 | 연 0 ~ 10,000C |
| 생산성 충격 `σ_shock` | 0 ~ 구현자 제안 |

탐색 방식은 라틴 하이퍼큐브 샘플링이나 격자 중 택일. 조합 수 × 시나리오 × 시드(최소 3개)를 보고한다.

## 7. 합격 기준 (잠정 — 조정 가능)

| 지표 | 기준 |
|---|---|
| 평시 합금 가격 | 물가지수 반영 정상가의 ±15% 이내 (S0~S2) |
| 물가상승률 | 연 1~3% (S0~S2) |
| 정부 재량 예산 | 17년 차에 시작 대비 1.1~1.6배 (폭증 금지) |
| 정부 조연 유지 | S1 17년 차에 국영 합금 생산 ≤ 지구 민간 합금 공급의 25% |
| 세트 투자 회수 | 운영비 0 가정 1.5~3년 / 운영비 포함 시나리오는 별도 보고 |
| 전시 충격 | S3 합금 가격 고점 +20~60%, 종료 후 2~4년 내 ±10% 회복 |
| 식민지 부담 | 초반 5년 식민지 지원비 ≤ 재량 예산의 15% |
| 무결성 | 음수 재고·인구, NaN/Infinity, 가격 발산 없음 |

기준을 하나도 만족하지 못하면 가장 근접한 조합과 어떤 기준이 왜 깨지는지를 보고한다.

## 8. 산출물

1. **순수 모듈:** `dist/src/economy-model.js` (DOM·Three·실제 시계 비의존). 나중에 게임 본체가 재사용할 수 있게 상태·틱·정책을 분리한다.
2. **실행 스크립트:** `scripts/econ-calibrate.mjs` — 탐색 실행, 결과 CSV/JSON 저장. 설정 파일 `scripts/econ-calibrate.config.json`.
3. **보고서 (`docs/econ-sim/`)**
 - `REPORT_KO.md`: 요약, 합격 조합 수, **추천 후보 2~3개**(각각 장단점), 민감도 순위, 800만/1,500만C 질문에 대한 답(V별 도출 `M₀`), 통화 고정·가격 비연동 대조 실험 결과.
 - `report.html`: **휴대폰 세로 화면에서 볼 수 있는** 단일 HTML. 외부 네트워크·CDN 없이 인라인 SVG 차트로 추천 후보별 20년 그래프(실질/명목 GDP, 물가지수, 합금 가격, 정부 재량 예산, 민간/국영 합금 공급, 국고)와 시나리오 비교를 표시한다.
 - `runs.csv`(조합별 요약), `candidates.json`(추천 후보 매개변수 전체).
4. **테스트:** `tests/economy-model.test.js`
 - 같은 시드·설정 → 결과 해시 동일
 - 인구 정수·비음수, 이주 함수 인구 보존
 - 크레딧 흐름 장부 일치(세수 = 재량 + 고정 지출, 국고 변화 = 수입 − 지출)
 - 합금 재고 보존(생산 + 매입 − 사용 − 판매)
 - 시작 시점 `P₀ = 1`, 합금 가격 2.3C/U
 - 통화 고정 규칙에서 성장 시 물가 하락 방향 확인
 - 가격 상하한 준수, NaN 없음
5. **성능:** 20년 단일 실행 50ms 이하 목표, 전체 탐색 10분 이내. 실제 측정값 보고.
6. 문서: `docs/econ-sim/IMPLEMENTATION.md`(모델 식·가정·한계), `docs/DECISIONS.md`에 "탐색 결과, 미결정" 한 절.

## 10. 요약

> **인구·생산성·통화·합금 시장·정부 재정이 서로 영향을 주는 최소 모델을 월 단위로 돌린다. 통화는 성장에 맞춰 규칙적으로 늘고, 시설·함선 가격은 물가지수에 연동된다. 여러 조합과 정부 시나리오로 10~20년을 시험해 합격 기준을 통과한 후보 2~3개를 휴대폰으로 볼 수 있는 보고서로 제출한다. 숫자는 Codex가 정하지 않고, 사용자가 보고서를 보고 정한다.**
