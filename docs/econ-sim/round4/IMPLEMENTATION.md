## 단위·원가와 양론

기존 게임 registry를 복제한 **새 실험 registry**에만 물/산소를 추가한다. 게임 전역 registry·패키징 null 가격을 변경하지 않는다. 기존 H U 개수 계약(건설120·보조85·부산물100·융합 건설/기동 각5·정상2.5)은 그대로다.

R3 구10,000kg/U → H500kg/U의 단위 환산은 처리량×20·GWh/U÷20이다. 예:100U/월·.55GWh/U →2000U/월·.0275GWh/U로 같은 월1,000t을 보존한다. R3-rounded의 실제 .54GWh/U는 .027로 별도 기록한다. 이후 `hydrogenCapacityScale/CScale/AlloyScale` ±50%는 설비 능력/비용 변경 효과다. 구10t 물의 취수900,000U·탱크90,000U는 각각2,000,000U·200,000U(4500kg/U)로 환산한다.

전해·H 액화·H 지속 냉각·선택 O 액화는 별도 GWh다. 지속 냉각 .05–.2kWh/kg/월은 자료가 확정되지 않은 **추가 탐색 가정**이며 0으로 숨기지 않았다. 정상 boil-off0–.5%는 명시적 H sink다. O는 기본적으로 생산 후 방출하며 수익은0이다. O 보관 대조 arm만 액화 전력과 실제 O 재고를 기록한다. O 판매가격을 발명하지 않는다. 현지 H는 실제 산업 호스트와 연결된 탱크/파이프 경계로 가정하며, 장거리 SCU 포장 원가와 구분한다. 수소 금융표는 이 현지 경계와 SCU 출하 경계를 함께 낸다.

광석→합금/잔여물은 기존 기대 품질 수율과 난도 함수다. 게임의 실제 quality-lot을 운송하거나 섞는 엔진을 만들지 않는다. 이 실험의 실제 천체 간 보급은 합금/H이며, game 원광 lot API와 연결하지 않는다.

## 폐쇄 장부·포장·수송

C/물질은 기존0.001 정수 quanta, 에너지 감사는 kWh 정수다. 모든 현금 거래는 지급=수취이며 정상/전시 명시 발행·소각 외 C 원천은 없다. 자체 사용은 매출이 아니다. 전력/보수/직접 서비스는 실제 C/U로 분해하고 구11.5%/10% 프록시를 청구하지 않는다. 명목 비용에는 CPI를 한 번만 적용한다.

출발 보유량에서 내용물과 컨테이너 합금을 **따로** 차감한다. 기존 `quoteContainerPlan()`의 실제 규격/개수·occupiedSCU로 모든 실험 포장 C/GWh를 계산한다. .001U 광석도 최소1SCU 전액 비용이다. 컨테이너의 게임 미정 가격은 계속 null이며 실험의 양수 all-in C/SCU·kWh/SCU를 별도로 공급한다. 90% 회수는 실제 수취지로 반환하고 나머지는 loss, 분수는 규격별 정수 carry다. 운임0도 소재·직접 포장·전력을 지우지 않는다.

정부의 `ownerId`는 여러 천체에서 동일한 정부다. 별도 private 부문은 기본적으로 천체별 소유자이며 소유자 변경 시에만 C를 이전한다. 동일 민간 holding을 시험하려면 같은 명시적 ownerId를 공급한다. 즉시 도착은 가정이며 선체·항로·배송 엔진 구현을 뜻하지 않는다. 재고/C/포장/전력 조건은 모두 쓰기 전에 확인한다.

시설 건설 합금은 삭제하지 않고 `capitalAlloy`에 묶는다. 함선 건조 합금은 별도 `shipAlloy`다. 역사적 기존 자산의 R3 유지보수 기반도 명명된 초기 capital 계정에 보존하며 실제 확인된 과거 지질 매장량이라는 주장은 하지 않는다. 해체는 이 묶인 자본에서만 반환/손실 처리한다. 매월 `자유 합금+시설 자본+함선 자본+용기 소재 = 초기 총량+제련 생산−실제 소비/손실`을 독립 감사한다. 모든 H/O/물·광석/합금 전환, 로컬 주체와 출발지 재고·C, 전력/축전도 검사한다.

## 소/중/대 및 개량

대형 정격/융합 기동은 실제 R3 상수를 import한다. 중형/소형 정격 비율과 비용·공기 지수는 설정 범위에서 탐색한다. 태양광 비용 예외만 ON의 배율로 적용한다. 핵융합 소형은 전20년 금지, 중형은 명시된 해금 월 이후만 가능하다.

같은 부지 개량은 기존 출력은 남기고 추가 출력 부분만 실제 건설한다. 추가 C/합금에만 재사용 할인을 적용하고, 공사 중 기존 부분 감산은 별도다. 추가 부분은 완공 전 발전하지 않는다. fusion 추가 세그먼트에도 규모 비례96h 기동을 요구한다. 부지는 기존 모듈 siteId를 공유하며 시설을 무료 교체하지 않는다. 철거/교체 재무 비교는 정보다.

민간 발전의 투자 판단은 최대 단지35기 기반 공유를 보존한다. 민간의 R3 공사/허가 지연9개월 비교값은 규모 지수를 적용한 추가 지연으로 유지한다. 부지·모듈 실투입은 각각 실제로 선불 지불하며 무한 병렬 공사는 정부에 C 할증만 추가한다. 공기 수치 자체는 분수 월일 수 있으나 건설 발주/완료 의사결정은 월 경계에서 수행해 최대 한 정산 간격의 보수적 대기가 있다. 금융표의 명목 공기와 실제 월 스케줄을 구별한다. 2일/4일/96h 운전 사건은 아래 적분을 사용한다.

## 정지·재가동·해체·우선순위

활성 bill은 R3 고정+가동 비례 구조를 유지하되 정격 합계가 해당 환경 연2–5%다. 정지 중에는 정상률×잔존율이며 C 잔존율<합금 잔존율이다. 공사 전에는 가동 유지비가 없고, 해체 완료 후에는 유지비/생산이0이다. 해체 진행 중은 보존 비용을 계속 낸다.

채굴 재시작은 C를 한 번 낸 뒤 첫24h 낮은 산출·두 번째 날부터 급증한다. 제련은 첫96h 생산0/고정 부하2–6배 가열 후 기존 런타임에서 가져온 초기 램프 형태로1.5–4개월 회복한다. 월730h 중 해당 구간의 적분으로 생산/전력을 계산한다. 단순 감산에는 재시작 비용이 없다. 핵융합은 수입한24+72h 적분/외부 에너지/H 제약이며, 중형은 같은96h에 정격 비례 전력/H·비용 지수를 적용한 C다. H 기동은 누적 지불 quanta를 이월해 마지막 작은 분량이 무료 반복되거나 영구 정체되지 않게 한다(총1Q 미만 반올림 여유). 추가 핵분열 정지 모드/제약은 만들지 않고 R3 동작을 보존한다.

유지보수 부족은 정해진 순서로 실제 소재를 배분하며 부족분/건전도·유상 수리 비용을 남긴다. 민간은 연속 손실·정지 개월 수·재시작 회수 전망으로 판단한다. 해체는 C/기간을 요구하고 회수<투입·<컨테이너90%다. E5-X/E11의 정부 정책만 정부 해체를 허용한다. private/government lifecycle 및 dismantle control은 원인분해용 opt-out이며 기본 ON 행동을 바꾸지 않는다.

E6-R의 동일 산출 의무 비교는 정지 손실을 미납 생산처럼 빼서 이익으로 계산하지 않는다. 동일 산출의 추가 가동 서비스 비용을 계산한 보수적 하한과 실제 재시작 C/가열을 함께 보고한다. 여유 설비의 새 자본 조달까지 완전 최적화한 문제로 주장하지 않는다.

## 월 정산과 판정

이월 재고/boil-off → 성장/가격 → 세금/기존 정책·건설 → 완공/정지·해체 판단·보급 요청 → 유지보수/유상 수리 → H 사전 구매/예약 → 실제 발전/기동·보급 포장/배전 → 광석/합금·H/O 생산(새 H는 마감에만) → 시장/민간 투자/분배 → 명시 발행·소각 → 전체 무결성 감사.

S0/S1/S2/E0/E1/E2/E2-S만 평시 거시 조건, 식민지는 **각 천체·매 연도** 수요 가중 미공급을 적용한다. 전시 가격 상하 변동은 정보이며 기존4년 회복 조건은 유지한다. E5-X는 충격 종료84개월 이후≤5년 내 미공급≤1%·평균 건전도≥.8을 본다. 무결성·평시·제안 스트레스 조건은 따로 기록한다. 합격0이면0이며 범위를 몰래 줄이거나 기준을 완화하지 않는다.

탐색의 원래37축 전체 범위는 JSON에 그대로 유지한다. OAT 이후8개 민감 축만 조건부 집중 표본을 추가하되, 원래 넓은 범위를 대체하거나 불가능성 증명으로 사용하지 않는다. 최종 후보3개와 사람이 읽기 쉬운 반올림안은 모두22시나리오×5시드로 별도 실행한다. H .4·운임0/낮음/높음·해금시각·정부/민간 정책·직접 대형/증설·O 보관 등을 분리 대조한다.
