## 27. 식민지 재정·생명유지·얼음 채굴 (2026-11-07)

- **[사용자 확정]** 식민지 지출은 **초반엔 국가 금고가 자동으로** 대고, 이후 식민지별 예산 배정 기능을 연다.
- **[사용자 확정]** 세율은 **행성별·행정 섹터별**로 나눔. **행성에 따로 정한 세율이 없으면 그 행성이 속한 행정 섹터의 세율** 적용.
- **[사용자 확정]** **얼음 채굴**을 식민지 물 공급원으로 넣음.
- **[사용자 동의]** 생명유지에 **산소** 포함. 사람당 산소 약 0.84kg/일(NASA) → 1U(4,000kg)로 약 160인·월. 수전해 산소 부산물이 막대해 실제 병목은 물·전력. 재활용률은 기술로(Claude 제안 시작 50%).
- **[Claude 제안]** 돈은 국가 단일 금고(순간 이동), 물건만 물류. 세금 = 천체별 민간 경제 → 국가 금고, 지출 = 식민지 정부 시설 유지·생명유지·건설 ← 국가 금고. 민간 돈은 천체별. 식민지 파산 없음(국가 금고 고갈 시 빚·채권·구제금융 단계).
- **[현황 확인]** 표면 데이터의 수소원·얼음은 지구 2곳뿐, 달·화성·얼음 위성은 얼음 데이터 없음 → 얼음 매장 데이터 추가 필요.
- **[사용자 동의]** 세율 덮어쓰기 순서 **국가 기본 → 행정 섹터 → 행성**. 얼음은 공식 지질 파일 옆 **별도 얼음 데이터 층**(달 극지 소량·화성 극관/중위도 지하·얼음 위성 다량·이오 없음). 작업 순서: 설계 → ECON-SIM-4.3(국가 단일 금고·천체별 세율·생명유지 물/산소·얼음 채굴) → 얼음 데이터 층·M2 탐사 확장 → M3.
- **[사용자 확정]** 식민지 세금 기본값은 **감면**(Claude 제안 임시: 설립 후 5년 0%, 시뮬은 0·5·10년 비교). ECON-SIM-4.3 지시서 작성: 국가 단일 금고(정부 C 통합·실물은 천체별), 세율 계층, 생명유지 물 0.5L/인/일·산소 0.84kg/인/일×(1−재활용 0.5), 수전해 산소 부산물 원장 반영, 얼음 채굴소(천체 단위 임시 매장량, 물 시장), 식민지 순재정·흑자 전환 시점 보고. 식량은 범위 밖.
