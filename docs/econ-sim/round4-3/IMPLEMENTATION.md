2026-11-07 Asia/Seoul. PR #23 HEAD `0c4a8c135af7e30e55c02a7d1120790884b8fec1`에서 시작한 **오프라인 전용** 구현이다. [기존4.2.2 식](../round4-2-2/IMPLEMENTATION.md)은 보존한다. 수율0.09·h0.96·현금6개월·물 조건0.72/12개월·램프0.13은 사용자 채택값으로 고정한다. 기존37개R4·7개R4.1 수치, 채광량·광산 비율·H기준가0.4·정상 핵융합2.5U/월/5GW는 변경하지 않는다.

## 1. 정부 현금은 실제 계정 하나

`NationalLedger43`은 기존 원장의 초기 현금/expected/initial을 같은 합계로 옮겨 **`nation/government/C` 한 계정만** 보유한다. 기존 `earth|moon|mars/government/C` 문자열은 호출 위치의 라벨로 정규화하며 실제 balance에는 존재하지 않는다. 민간·가계 C와 모든 실물 계정은 천체별이다.

```text
국가 초기C = 기존 세 천체 정부 초기C 합계       # 100,000C, 추가 발행0
국가C 변화 = 모든 천체의 국가 현금 수입 − 실제 국가 현금 지출
천체 연간 순재정 = 그 천체 세수 − 그 천체 국가 지출
천체 현금 기여 = 세수·공기업 등 전체 국가 수입 − 그 천체 국가 지출
```

정부의 건설·유지·보수·전력 매입·물 매입·SCU 수입·구호는 같은 국가 잔액을 조회하고 지불한다. 여러 주문도 직전 실제 지출 후의 잔액으로 판정한다. 기존 천체별 지원금/명시적 C 이전과 H-CUT 준비용6만C 이체를 제거했다. 대신 실제 자산·물품 구매가 발생할 때 국가가 직접 지불한다. 6만C를 다시 지출로 차감하거나 두 금고 사이에 복제하지 않는다. 원래 준비 물량·tick0/24 요청·산업/전해 주문 순서는 유지하며, 생명유지에 필요한 별도 소재 조달도 기존 유상 SCU를 쓴다.

국가와 외부 사이의 원장 거래에는 `fiscalBody43`와 `fiscalTag43="천체:기존태그"`를 남긴다. SCU 서비스는 수입 목적 천체에 귀속한다. 보존 감사용 기존 합계 `turnover` 태그는 유지한다. 정부끼리의 같은 현금 계정 이동은 실제 이전·비용·매출로 기록하지 않는다. 스냅샷의 천체별 `governmentC`는 **null**이며, 국가C를 세 번 합산하지 않는다.

정부 현금 안전선은 같은6개월이며 **당시 모든 천체 정부 운영 자원가치 견적 합계**를 보호한다. 민간은 해당 천체 기준이다. 기존 운영 견적에 얼음의 독립 유지비·전력과 산소 액화비를 포함한다. 생명유지의 실제 물 구매·필수 운영은 현금이 있는 만큼 지급하고, 임의의 시설별 발전소 건설이나 예산 배정 기능은 추가하지 않는다.

국가 고갈 시 지불·주문은 실제 잔액으로 제한된다. 신규 식민지 빚·채권·구제금융은 없다. 전체4.1 시나리오 보존을 위해 기존 S3/E7의 명시적인 차입·전시 발행 **실험**은 그대로 두었으며, 이것을 신규 식민지 구제 정책으로 사용하지 않는다. 기존 성장에 따른 가계 통화 발행/소각과 전체 C 보존은 유지한다.

## 2. 국가 예산 기준의 재정의

기존 `budget17`은 지구의 명목 전략예산17년/1년이었다. 이번에는 아래 **국가 명목 전략예산**으로 바꾼다. 실제 계정의 잔액 증가율이나 공기업 매출 증가율을 예산 성장으로 세지 않는다.

```text
월 국가 전략예산 = Σ천체(실제 수납 세금 − 실제 고정 시민 지출)
budget17 = 월193~204 전략예산 합계 / 월1~12 합계
```

세금·고정 시민 지출의 기존 `strategyShare`/전시 몫 식은 유지하고, 미수납 세금을 가용 예산으로 만들지 않는다. 기준1.1~1.6은 그대로다. 기존4.1 결과의 정의나 수치를 다시 쓰지 않는다. 식민지 지출의 부담은 위 전략예산 대비 비중과, 고정 시민 지출을 포함한 전체 국가 지출 대비 비중을 둘 다 보고한다.

## 3. 세율 계층과 감면

`effectiveTax43()` 하나에서 `행성 값 ?? 행정 섹터 값 ?? 국가 기본`을 평가한다. 명시적인0%는 덮어쓰기이며 null/미지정만 상속한다. 감면은 행성·섹터의 실효값보다 먼저 적용되는 설립 초기의0% 규칙이다. 지구에는 감면하지 않는다.

```text
설립 월을 F, 현재 운영 tick을 m이라 하면
식민지이고 m−F < holidayYears×12 → 0%
그 외 → 행성 → 섹터 → 국가 기본으로 계산한 세율
월 세금 평가액 = GDP × CPI × 실효 세율 /12
```

천체 단위로 이미 인구가 존재하는 초기 상태이므로 설립F=0이다. 별도 실제 행정 섹터 지도를 만들지 않았고, 세 천체를 한 섹터/서로 다른 섹터로 두는 상속을 테스트했다. 스냅샷의 세율은 해당 **시점부터 적용할 다음 운영 월 세율**이며, 방금 끝난 월의 실제 세수는 fiscal 원장을 사용한다.

**입력에서 발견한 제약:** 기존4.1 `bodies.moon.taxRate`·`mars.taxRate`는 모두0이다. 종료 후 세율을 질문했지만 지정된 기존 값 유지 원칙을 따라 이번 실행의 국가 기본은0%, 지구 행성 덮어쓰기는 기존25%로 두었다. 따라서 감면0/5/10년은 숫자가 같을 수 있다. 국가 기본25%를 임의 확정하지 않았다. 명시적 양의 국가 기본에서 감면 종료·0% 덮어쓰기·섹터 상속이 실제 세수로 연결되는 것은 별도 테스트했다. 별도의 국가 기본 세율 결정이 있으면 해당 시나리오를 재검증해야 한다.

## 4. 물·산소 수요와 실제 사용

모든 수량은0.001U 정수Q로 올림해 수요를 만들고 실제 재고만 소비한다.

```text
물 순수요Q = ceil(인구 ×0.5L/일 ×30 /4,500kg ×1,000)
산소 순수요Q = ceil(인구 ×0.84kg/일 ×(1−재활용0.5) ×30 /4,000kg ×1,000)
지구의 두 수요 = 0
```

정부 재고의 물과 양의 시세로 매입한 같은 천체 민간 물을 생명유지에 먼저 쓴다. 민간의 물을 무료로 국유화하지 않는다. 같은 소유자의 환원 부산물 물 provenance는 유상 물 거래 때 함께 옮기며, 생명유지/재순환으로 나간 부산물만 해당 원장 풀에서 차감한다. 이후 전해 취수, 남은 물은 재고다. 새 얼음 물은 **월말 산출로 다음 월부터** 사용해 같은 전력/물 한 단위를 중복 약속하지 않는다.

수소 마진/회수 합격은 지구에만 적용한다. 식민지의 기존 수전해 견적 필드는 얼음/물 구매까지 합친 통합 H 원가가 아니며, 그 비용은 국가 지출 원장에 별도로 보고한다.

수전해 물1U→수소1U+산소1U의 고정 질량(4,500=500+4,000kg)을 유지한다. 산소를 버리는 대신 천체별 산소 재고에 올리고 그 월 생명유지에 쓴다. **[임시 회계 해석]** 정부→민간 산소 부산물 순으로 공공 생명유지에 배분하며 산소 매입/판매 시장·매출은 없다. 남는 산소는 소유자별 재고로 남는다. 저장할 산소에는 기존 **양의** 액화 전력 계수0.32kWh/kg를 적용하고 전력 정산·H 원가 견적에도 넣었다. 기존37개 수치나 산소 판매 이익을 바꿔 마진을 만들지 않는다.

산소용 공공 전해는 H 가격이 낮더라도 생명유지 의무량을 가동한다. H 수익을 보장하지 않으며 물·직접비·보수·전력 비용은 실제로 지불한다. 추가 생명유지 인건비를 임의의0C 시설로 만들지 않고 기존 도시 필수 서비스/전력, 물 구매와 실제 설비 운영비로 비용을 잡는다. **별도 탱크/창고 용량·증설비·사망·행복·연구 모델은 이번 모형에 없다.**

전력 배분은 기존 실제 기동 입력을 유지한 뒤 **명시적인 얼음 채굴·산소 의무 전해량을 도시 기본 부하보다 먼저** 보호한다. 선택적 유상 포장도 이 생명유지 전력을 유보한 범위에서만 처리한다. 다음으로 도시 기본 부하, 나머지 산업·전해·도시 선택 부하에 기존 규칙을 쓴다. 새 생명유지 자산을4.1 유지보수/유예/손상 경로에 연결했다. 수요·미충족을 각각 기록하며 최초12개월 뒤 매월99%를 판정한다. 연간 평균으로 나쁜 한 달을 숨기지 않는다.

## 5. 얼음 채굴 시설·물 시장

얼음 계정은 **회수 가능한 정제수 환산U**로 정의한다. 공식 지질/섹터 데이터와 분리된 임시 국가 시험값은 달100만U(물450만톤), 화성1,000만U(4,500만톤)다. NASA의 [달 극지 얼음 관측](https://science.nasa.gov/missions/mini-rf/nasa-radar-finds-ice-deposits-at-moons-north-pole/)과 [화성 Utopia 지하 얼음](https://www.jpl.nasa.gov/news/mars-ice-deposit-holds-as-much-water-as-lake-superior/)은 적음/많음의 정성적 근거다. 이 수치를 NASA가 정한 실제 채굴 가능량이라고 해석하지 않는다. 접근 가능한20년 시험 구역의 **[임시] 재고**이며 실제 얼음층·농도·탐사는 후속 작업이다.

```text
건설C/합금 = 기존 광산1세트 C/합금 × iceCapitalScale × 모듈수
월 유지비 = 기존 광산1세트의 직접비/환경별 합금 보수 × iceMaintenanceScale × 모듈수
예정 물 = 정격 산출 × 모듈수 × 건강 × 실제 C 가동비율 × 기존 채광 재가동 계수
실제 물Q = min(유일한 천체 얼음잔량Q, floor(예정 물 × 실제 채굴 전력 비율 ×1,000))
채굴 전력 = 예정 물U × iceGWhPerU
```

건설C/소재를 원자적으로 지불하고 기간 후 완공한다. 정부·민간 모두 같은 API를 쓴다. 자본 원가와 월 유지비의 배율은 **독립**이다.4.1 구호·수입의 보수 목표/기증자 유보량에도 새 유지비 기준을 적용하며, 실제 자본합금은 건설금고에 그대로 남긴다. 냉간 재가동은 기존 광산의 양의 C 비용과 `restartProfile().mineFactor`, 민간 중단/재개/철거 규칙을 재사용한다. 건강·전력·유한 잔량을 무시한 정격 source는 없다.

정부는 건설기간+2개월에 필요한 물/산소용 취수의 부족을 예상할 때 우선 주문한다. 이미 매입 가능한 현지 민간 재고도 고려해 불필요한 채굴소를 짓지 않는다. 유지 소재가 부족하면 기존 양의 대금·포장재·실제 포장전력을 쓰는 SCU 경로로 조달한다. 실물은 공유하지 않으며 비용·물량·포장 전력 검사를 통과한 기존 실험용 SCU 거래로만 옮긴다. 이 오프라인 거래는 같은 월에 정산하며 실제 항행/배송시간 엔진은 없다. 민간은 현지 물 시세·전해 수요, 잔여 판매수요로 제한한 기대 매출과 양의 유지/전력비, 기존 투자 회수/수명주기 규칙 및 실제 자금을 확인한다. 판매나 진입 자금을 보장하지 않는다.

물 시장은 기존 H 시장의 재고 목표 기간·가격 조정/복귀·현금/판매 재고 제한을 재사용한다. **[임시] 물 기준가0.2C/U**, 양의 범위0.001~40C/U다. 이 값은 사용자 확정 시세가 아니다. 정부의 생명유지·전해 물 구매와, H 가치가 비용을 덮는 민간 전해 구매만 실제 거래한다. 정부 공급의 생명유지 유보분을 민간에게 먼저 팔지 않는다.

기존 초기 물은 보존한다. 특히 **화성 민간 초기 물20만U**는 얼음 금지에서도 남는다. 화성의 생존을 전부 새 얼음 덕분으로 보고하지 않는다. 민간의 기존 월말 현금 배분도 보존하므로 작은 식민지의 민간 투자 자금 축적이 제한될 수 있다.

## 6. 고정 물 건설 조건의 얼음 연결

기존0.72/12개월 조건과 완공 뒤 검사 창은 고정한다. 새 예측은 이미 지불한 얼음 설비의 완공 시점·건강·최근 채굴 전력/가동비율과 유일한 남은 얼음을 포함한다. 알려진 공사 완료는 예측하지만 미래 H-CUT/재고 파괴는 읽지 않는다. 후보 전해가 만들 H로 자기 물을 승인하지 않는다. 생활·기존/예정 전해를 예약하고 같은 물·공유 취수원·얼음 매장량을 두 소유자에게 중복 약속하지 않는다. 미래의 건강·전력·재정까지 보장하는 예보가 아니며 실제 월 공급과 별도로 감사한다.

## 7. 비교·탐색·판정과 보존

새 국가/생명유지/얼음 구조 안에서 H-OFF/ON을 같은 정책·시드로 비교한다. OFF에서도 새 생명유지 설비의 물/현금 조건은 유지한다. 얼음 정책이 달라지므로32 LHS+기준안의 OFF도 후보마다 따로 실행한다. E0·E2-S 선별 후 후보1개와 새로운 반올림1개를 전42시나리오·얼음 유무×감면0/5/10년·H-CUT18개·동일 준비 무차단·자력/구호에서 검증한다. 반올림은 새 얼음5축만 한다.

4.1 criteria는 위 국가 예산 정의 외 그대로다. 기존 분류상 정보용인 극단경로의 옛 기준은 정보용으로 남기고, **이번 새 생명유지 기준은 얼음 사용을 허용한 모든 식민지에서 충격/차단 경로도 유예 후99%를 요구**한다. 얼음 금지 비교에는 물·산소 충족률을 보고하되 얼음 생존 합격을 부여하지 않는다. 지구 수소 마진·회수는 E0, 기존 순증 유지의 누적>1은 E0와 준비 무차단에 적용한다. 최신4.3 기준표에 따라 이전 '모든12개월 ON≥OFF'와 H-CUT95%는 정보로 남긴다. 기존 결과의 판정을 다시 쓰거나 기준 수치를 낮추지 않는다.

별도로 불변4.2.2 반올림 구조의 같은 시드/천체/시나리오 결과를 재사용하고 대표 경로를 원래 해시와 재현한다. H-OFF 곡선을 옛 천체별 정부 금고로 오인하지 않도록 HTML에도 구분했다. 원장·대조·정식 실행 source manifest·기존1,465개 SHA/Git blob 보존을 검사한다. 게임 런타임/UI·M3·공식 지질/표면/프리셋·기존 보고서는 수정하지 않는다.
