## 3. 모델 변경

### 3.1 국가 단일 금고
- 천체별 `government` 현금 계정을 **국가 계정 하나**로 통합한다(정부 실물 재고 — 합금·수소·물·산소·광석 — 는 천체별 유지).
- 식민지 정부의 모든 C 지출(시설 유지비·생명유지 운영·건설·수입 구매·4.1 구호 등)은 국가 계정에서 지불. 천체별 정부 지출 내역은 원장 태그로 구분해 **식민지별 순재정**(그 천체 세수 − 그 천체 정부 지출)을 계산할 수 있게 한다.
- 4.2 H-CUT 시험용 식민지 유상 준비의 '지구 국고 6만C 이체'는 **국가 계정 직접 지출**로 바꾼다(이체 단계 제거). 준비 물량·순서는 그대로.
- 4.1의 천체별 예산 기준(`budget17` 등)은 국가 계정 기준으로 재정의하고, 재정의 방식을 `IMPLEMENTATION.md`에 적는다. 기존 4.1 결과를 고치지 않는다.

### 3.2 세율 계층
- 기존 `earthTaxRate`·`bodies[id].taxRate`를 **국가 기본 + 행정 섹터 + 행성** 계층으로 해석하는 함수 하나로 감싼다. 이번 시뮬레이션은 천체=행성 단위이므로 행정 섹터는 데이터 자리만 두고(지구·달·화성을 각각 다른 행정 섹터로 두거나 하나로 묶는 두 설정을 테스트로 확인), 결과에는 행성 실효 세율만 쓴다.
- **식민지 감면 기본값:** 설립 후 `holidayYears`년 세율 0%, 이후 국가 기본(4.1 식민지 세율). [임시 기본 5년]
- 시나리오: 감면(기본) / 감면 없음 / 감면 10년 비교.

### 3.3 생명유지 물·산소
- 천체별 인구 기준 월 수요:
  - **물 순보충** = 인구 × 0.5 L/인/일 × 30 (4.2 값 그대로, 1U = 4,500kg).
  - **산소 순보충** = 인구 × 0.84 kg/인/일 × (1 − 산소 재활용률) × 30, 재활용률 **0.5** [임시, 연구 연결은 이후]. 1U = 4,000kg.
  - 지구는 둘 다 0.
- **산소 공급:** 그 천체 수전해 산소 부산물(물 1U → 수소 1U + 산소 1U, 사용자 확정 단위)을 먼저 생명유지로. 남는 산소는 산소 재고(이번엔 판매처 없음, 정보 지표). 4.1/4.2에서 버려지던 산소 부산물을 원장에 올린다.
- **물 배분 순서:** 생명유지 → 수전해 취수 → 재고(4.2 규칙 유지, 얼음 채굴 물 포함).
- 생명유지 미충족(물·산소 각각)은 4.1 트리아지 규칙의 '생명유지 우선'과 연결해 기록하되, 사망·행복 모델은 만들지 않는다(정보 + 합격 기준).

### 3.4 얼음 채굴소 (새 시설)
- 식민지(달·화성)에 지을 수 있는 정부·민간 시설. 산출 = **물 U/월**.
- 매장량: 실제 얼음 데이터 층이 아직 없으므로 **천체 단위 임시 매장량**(달 적음·화성 많음, 근거와 함께 [임시]). 이번 20년에서 고갈 여부만 보고.
- 비용 [임시 탐색]: 건설 C·합금, 월 유지비 C·합금, 전력(물 1U 융해·정제 약 0.001 GWh 기준 + 채굴 동력), 건설 기간, 냉간 재가동은 4.1 채광 규칙 준용.
- 건설 판단: 국가(정부)는 생명유지 부족 예상 시 우선 건설(자동 정책), 민간은 4.1 투자 규칙(물 시세·수전해 수요 가치)으로 판단. 4.2.2 물 조건(수전해 건설)은 얼음 채굴 산출을 예상 가용 물에 포함한다.
- 천체별 **물 시장**(4.1 시장 규칙 준용)을 연다. 산소 시장은 열지 않는다.
