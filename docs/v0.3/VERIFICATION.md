## 자동 테스트 범위

1. 행성별 게임 궤도 53/79/100/142/280/420/570/730과 정수 Planet Size 9/15/15/11/50/45/30/29.
2. 태양 G2V·90 Star Size·고정 월드 지름 70, 별도 크기 변환 및 거리 AU 역환산.
3. 게임 장반경이 날짜 변경이나 실제 JPL 장반경 변화로 덮어써지지 않음.
4. 타원 폐곡선, 3D 경사·근일점 방향, 트리톤 역행, 모행성 추적.
5. IAU 자전축·자전 방향·주기 및 일시정지·배속·프레임 분할.
6. 게임 AU 전용 눈금과 픽셀 길이.
7. 항성·행성·고리·위성·인접 시스템의 방사상 포락선 여유거리. 0/+10/+50/+100년 검사.
8. 잘못된 항성 크기·교차 궤도·행성 내부 위성·토성 고리 침범이 정상 검출됨.
9. 보조 선택의 가시성·화면 거리·깊이·마우스/터치 반경 구분.
10. 53 AU → 140 월드 단위 변환, AU 표기와 Size 유지, 좌표/거리/충돌 반지름 역환산.
11. 별도 참고 좌표에서 기존 Horizons 지구 벡터 비교, 현실 km/AU, 현실 위성 좌표·주기 유지.

## 브라우저 증거

Chromium + Playwright, WebGL 소프트웨어 렌더러 사용. PC 1440×1000, 터치 가로 화면 844×390와 667×375.

- HTTP 200 및 WebGL 로딩, 천체 20개·입자 영역 2개.
- 전체/내행성/지구/달/목성/토성 시점과 게임 AU 눈금.
- 카메라 회전·휠 확대 후 실제 지구 메시 클릭 선택 및 해제.
- 화면상 작은 달을 **메시 바깥에서 마우스 클릭·모바일 터치**하여 보조 선택 성공.
- 가려진 지구가 보조 후보에서 제외됨.
- 모든 접근·줌 단계에서 행성·항성·위성의 월드 반지름 유지. 지구 7.5 월드 단위, 태양 35 월드 단위. 수성 표기 53 AU를 유지하면서 렌더링 장반경은 140 월드 단위.
- 천체 선택/위성 선택/소행성대 경계 강조/이름·궤도·황도면 전환.
- 시간 정지 시 좌표 고정, 재개·배속 시 진행.
- 실제 지구 2K 지도 로딩, 토성 고리와 위성·축 프레임 유지.
- 모바일 상세 패널 접기·펼치기, 위성 선택 버튼, 수평 오버플로 없음.
- 최종 소스에서 전체보기 최소 줌 42 월드 단위 확인.

## 검증하지 않은 항목과 범위

실제 모바일 GPU·Safari·Firefox 성능, 장기 실기기 플레이는 검증하지 않았습니다. 소행성 입자는 장식용이며 개별 입자 물리 충돌은 구현하지 않았습니다. 100년 검사는 게임 여유거리 설정 검사로서 미래 천체력 정확도를 보증하지 않습니다. 함선·전투·생산·건설·연구·저장은 이번 버전의 구현 범위가 아닙니다.
