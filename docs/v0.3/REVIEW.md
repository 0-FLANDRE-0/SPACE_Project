## 2. 최종 게임 거리·크기

1 월드 단위 = 1 게임 AU. 모든 장반경은 중심 간 거리이며 순간 거리는 이심률에 따라 변합니다.

| 행성 | 궤도 장반경 (게임 AU) | Planet Size / 게임 지름 (AU) | 게임 반지름 (AU) |
|---|---:|---:|---:|
| 수성 | 53 | 9 | 4.5 |
| 금성 | 79 | 15 | 7.5 |
| 지구 | 100 | 15 | 7.5 |
| 화성 | 142 | 11 | 5.5 |
| 목성 | 280 | 50 | 25 |
| 토성 | 420 | 45 | 22.5 |
| 천왕성 | 570 | 30 | 15 |
| 해왕성 | 730 | 29 | 14.5 |

Planet Size = `Math.round(15 * Math.sqrt(realRadiusKm / 6371))`. 모두 정수이며 별도 동적 시각 확대 없이 지름으로 적용합니다. 가스 행성의 큰 Size로 지상 건설 가능성·개발 한도를 추론하는 로직은 없습니다.

## 3. Star Size

태양 / Sol: G2V, G형 주계열성, 광도계급 V, 5,772 K, 실제 반지름 696,340 km, 1 R☉. Star Size = 90.

`starDiameterGameAU(star)`는 광도계급 프로필의 `70 / 90` 계수를 적용합니다. 태양 지름은 70 AU, 반지름은 35 AU입니다. Star Size 자체를 지름으로 취급하지 않습니다. O/B/A/F/G/K/M 분광 계열과 별도 광도계급 필드가 있으며, 이번 버전의 천체는 Sol 하나만 있습니다.

## 4. 위성·고리·입자 영역

Planet Size와 구분한 위성 지름 규칙: `max(0.3, round(0.8 * sqrt(realRadiusKm / 1737.4) * 10) / 10)` AU. 달 기준 0.8 AU와 하한 0.3 AU는 검토 가능한 프로토타입 조정값입니다.

| 위성 | 모행성 중심 장반경 (게임 AU) | 게임 지름 (AU) |
|---|---:|---:|
| 달 | 9.4 | 0.8 |
| 포보스 | 7 | 0.3 |
| 데이모스 | 9.5 | 0.3 |
| 이오 | 30 | 0.8 |
| 유로파 | 33 | 0.8 |
| 가니메데 | 36 | 1.0 |
| 칼리스토 | 39 | 0.9 |
| 엔셀라두스 | 54.5 | 0.3 |
| 타이탄 | 59 | 1.0 |
| 티타니아 | 21 | 0.5 |
| 트리톤 | 21 | 0.7 |

위성은 기존 이심률·궤도 방향·위상·주기를 유지하며 부모 게임 위치를 따라갑니다. 실제 위성 거리를 일률적으로 100배 하지 않았습니다. 토성 고리 반지름은 토성 반지름의 1.24–2.32배, 즉 27.9–52.2 AU입니다.

소행성대: 195–235 AU, 1,800개 인스턴스. 카이퍼대: 795–900 AU, 1,400개 인스턴스. 입자 선택·영역 강조를 유지하며 개별 입자의 물리 충돌은 구현하지 않았습니다.

## 5. 겹침 검증

최소 여유거리 1 게임 AU. 근일점·원일점으로 만든 보수적 방사상 포락선을 사용하므로 특정 스크린샷 시점만 확인하는 검사가 아닙니다. 고리와 가장 바깥 위성까지 포함한 시스템 간 여유도 검사합니다.

- 태양–수성 최소 표면 여유: **2.601025 AU**. 수성 근일점 중심거리 42.101025 > 태양 35 + 수성 4.5 + 여유 1.
- 행성 구체끼리의 최소 여유: **2.566534 AU**, 수성–금성.
- 위성·고리를 포함한 인접 시스템 최소 여유: **1.015049 AU**, 금성–지구 시스템.
- 모행성/고리–위성 최소 여유: **1.019484 AU**, 지구–달.
- 목성–토성 시스템 여유: **2.963549 AU**. 엔셀라두스와 토성 고리 여유: **1.841223 AU**.
- 시작 시점과 +10/+50/+100년 설정 검사 통과. 천문 참고 정확도 보증과 게임 충돌 여유 검사는 구분합니다.

지구 100 AU, 모든 Planet Size, 지정한 8개 초기 행성 거리 및 태양 지름 70 AU를 변경하지 않고 통과했습니다. 잘못된 항성 크기·궤도 교차·행성 내부 위성·고리 중첩을 주입하면 검사가 실패하는 회귀 테스트도 있습니다. 세부 수치: [clearance-report.json](clearance-report.json).

## 6. 실제 천문 데이터 보존

`realRadiusKm`, `realOrbitAU`, `jplElements`는 천문 참고입니다. `orbitGameAU`, `planetSize`, `starSize`, `satelliteDiameterGameAU`는 게임 데이터입니다. 모호한 `radius`/`orbit` 필드를 섞어 쓰지 않습니다.

`referenceElementsAt()`, `referenceOrbitalPoint()`, `referenceOrbitPosition()`, `referenceWorldPosition()`에서 기존 실제 AU 계산을 유지합니다. 별도 참고 좌표 테스트에서 JPL Horizons 비교를 계속 수행합니다. 게임용 `elementsAt()`은 이심률·방향·위상은 보존하되 실제 장반경으로 게임 장반경을 덮어쓰지 않습니다. IAU 자전, 구름, 실제 표면 지도와 토성 고리를 유지합니다.

## 8. PC·모바일 선택과 카메라

불투명 천체 메시의 실제 교차 판정을 우선합니다. 놓친 작은 천체에는 마우스 12px·터치 18px 보조 영역을 사용하되, 실제 크기·충돌 반경은 바꾸지 않습니다. 가려진 천체를 제외하고 화면 거리, 같은 거리에서는 깊이로 결정합니다.

카메라: 전체 약 1,813 AU, 내행성 약 491 AU. 화면 비율에 따른 전체 범위 보정, 최소 거리, 최대 줌 8,000 AU 이상, 원거리 클리핑 60,000 AU, 별 배경 18,000–24,000 AU. 표면/위성 보기와 공전 추적·로그 거리 전환을 유지합니다. 전체보기의 최소 줌은 태양 표면 바깥 42 AU입니다.

## 9. 실행·검증

`npm run dev` → `http://localhost:5173`. Node 20+, Python 3, 별도 설치/빌드 불필요.

`npm run check`, `npm test` 및 Playwright 회귀를 수행합니다. 최종 결과와 재현 명령은 [검증 기록](../VERIFICATION.md)에 있습니다. 실제 모바일 기기·Safari·Firefox 성능은 검증 대상에 포함하지 않았습니다.

## 10. 발견 문제와 후속 과제

- 기존 동적 반지름과 실제 장반경 재계산이 게임 크기·거리 결정을 덮어쓰던 경로를 제거했습니다.
- 가로 화면 정보창의 잘림과 위성 이름의 중첩을 관찰해 패널 높이·스크롤 초기화·라벨 배치 검사를 보완했습니다.
- 금성–지구 시스템과 달의 여유가 최소 기준에 가까우므로 위성 크기·궤도를 바꿀 때 `validateSystem()`을 함께 실행해야 합니다. 설정 오류는 조용히 크기를 바꾸지 않고 검출합니다.
- 입자는 장식용 분포이며 별도 충돌 반경·실제 천체력 목록이 아닙니다. 형제 위성의 화면상 밀집은 가림·라벨 숨김·선택 보조로 처리합니다.
- 현실 천체력과 게임 지도 위치는 다릅니다. 눈금은 타깃 깊이의 화면 평면 기준입니다.
- 함선·전투·생산·개척·건설·연구·유물·성간 이동·외교는 구현하지 않았습니다. Planet Size로 건설 수량을 자동 결정하지 않습니다.
