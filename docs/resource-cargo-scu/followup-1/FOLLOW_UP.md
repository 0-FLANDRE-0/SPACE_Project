# 남은 결정 및 후속 연결

1. 기본 포장 C·전력은 **미정(null)** 유지. 다음 경제 보정/사용자 승인에서 결정해야 하며 이번 테스트용 1 C/1 kWh를 기본값으로 채택하지 않았다.
2. 복수 로트 합포장과 내용물 부분 인출은 미지원. 향후 명세 배열별 분배/소비 규칙을 정한 뒤 확장해야 한다. 이번에는 현지 단일 로트 및 정수 컨테이너 전체 개봉만 제공한다.
3. 원광 자동 현대화는 미지원. 먼저 현지 개봉 후 명시적으로 새 규격 포장할 수 있다. 광맥/품질을 보존하는 자동 선택 정책은 별도 설계 대상이다.
4. 실제 선체/배송·도착·운송 중 재고·경로·시간 계산은 미구현. 이번 원광 어댑터는 현지 전용이며 배송 추상 영수증을 사용한 원격 원광 이동도 차단한다.
5. 민간 원광 산업 공급/소유권 원장과 현지 패키징 UI 실행 폼은 후속 연결 대상. 현재 정부 원광 실재고 API와 기존 재고 표시를 연결했고, 미정 비용 때문에 기본 실행은 견적 보류다.
6. ECON-SIM-4 및 소형 발전모듈 추가/정격출력 변경은 수행하지 않았다. 기존 ECON1/2/3 자료·공식 프리셋은 그대로 보존한다.
7. Chromium PC/모바일 크기와 터치 에뮬레이션을 검증한다. 실물 Android/iOS·Safari, 별도 GitHub Actions 결과는 로컬 브라우저/Node PASS와 구별한다. 자동 실행 가능한 CI workflow는 현재 저장소에 없다.
