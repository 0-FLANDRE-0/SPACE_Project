# 미결정과 후속 경계

## 미정 — 이번에 숫자를 채택하지 않음

- 컨테이너 직접 C/전력 및 수소 극저온 추가 C/전력. null을0으로 취급하지 않는다. 기본 정식 SCU 포장은 실행 보류다.
- 검사/하역 취급비, 계속되는 냉각·보관 전력, 운송 시간·연료·운임. 실제 공급/처리 시스템을 구현하지 않았으며 무료로 확정하지 않았다.
- 추가 특수 소재의 종류/양, 안전성·파손/수리, 민간 재정 공급자. 빈 컨테이너 상품/무한 재사용은 없다.
- residue/물/산소/반물질/아스트로지늄의 kg/U·SCU/U. 미정 상태에서 물리/화물 견적은 거부한다.
- 수소0.4/1.2C/U는 기존 비교 후보이며 어느 것도 채택하지 않았다.

## 실제 물류 연결

현재는 순수 배송 계약/인접 검사와 도착 확인에 따른 원장 정산만 있다. 함선/트럭/우주항/sector 배송, 경로 탐색, 운송 중 예약의 실제 생성·도착 처리, 권한/취급망 공급자, 항로 시간·운임은 없다. 실제 구현은 출발 차감→shipment 보관→도착 인도의 원자성과 목적지 이중 반영 방지를 담당해야 한다.

새 컨테이너 계정 이전은 외부 공급자가 일치하는 delivered 상태를 확인해야 하며 live에는 공급자가 없다. 테스트용 도착 확인을 실제 물류로 재사용하면 안 된다. 저장된 인도 참조는 최대10,000개를 검증하며 향후 실배송의 영속 보관/압축 정책이 필요하다. 현재 이를 넘으면 실패하며 기록을 지워 중복을 허용하지 않는다.

광석 운송 포장은 전체 물리 견적을 지원하지만 실제 산업 lot 어댑터를 연결하지 않았다. 광맥 출처·품질·가공 난도·남은 양을 유지하는 차감/인도/개봉 정책이 필요하다. 현재는 명시 보류이며 generic ore를 만들어 우회하지 않는다.

수소는 실제 현지 탱크/소비자/배관 receiver 공급자가 필요하다. 현재 SCU의 명시 receiver 설정은 엔진 연결 인터페이스/테스트용이며 실제 냉각 설비를 건설한 것이 아니다. 산업 per-U 보관과 운송 포장을 중복 과금하지 않아야 한다.

## 자동화와 최적화

규격별 승인/해금 ID 주입은 가능하지만 연구 트리·해금 비용은 없다. 자동 현대화는 실제 처리량·순편익·소비 예측·필수 자유 재고를 주입해야 한다. 기본ON이어도 미정이면 보류한다.

현재 기본 목적함수는 소재량 최소다. 시장가격/C/Wh/취급비를 넣는 순수 objectivePolicy 훅은 제공하지만 승인된 경제 비용 정책 자체는 없다. 영속 큐에 사용자 정의 함수를 저장하는 정책 레지스트리도 미연결이며 그런 요청은 거부한다. 여러 소재의 기본 Q 가중치1을 경제적 가치 동일성으로 해석하지 않는다.

미래 SCU/U가 표준4/8과 크게 달라 정수 Q/외형 공간의 다차원 상태나250,000상태 초과 탐색이 필요하면 명시 거부한다. 해당 물리 규격에 맞는 제한/다차원 알고리즘이 후속이다. 이번 표준은 정확한 최적화를 검증했지만 모든 미정 미래 자원까지 인증한 것은 아니다.

## 물리와 ECON-SIM-4

SCU 치수는 외부 규격이며 실제 내부 체적·최대 하중·선체 가속·컨테이너 강도·충돌/3D 적재 인증은 아니다. 특히 ore4SCU/U는 원광 종류/벌크 밀도에 따라 후속 검토할 잠정 기준이다. 합금은 여러 산업용 금속의 추상 자원이다.

기존 ECON-SIM-1/2/3 소스·설정·원시 산출물·보고서·해시는 보존했고 새 SCU 계약으로 재승인하지 않았다. ECON-SIM-4의 장기 경로/후보 탐색·C/전력/수소 가격 보정은 실행/구현하지 않았다.

기존3차 `물9U→수소1U+산소8U`는 현재 자원별 질량 보존식으로 쓸 수 없다. 수소1U=500kg일 때 손실 전 양론은 물약4,500kg→수소500kg+산소약4,000kg이다. 물/산소 U는 미정이며 수전해 공정 에너지와 포장/극저온/운송 비용은 분리해야 한다. 이 후속 문제는 유지하며3차 결과를 덮어쓰지 않는다.
