## 3. 탐사 모델 (순수 시뮬레이션)

### 3.1 기존 데이터 연결
- 섹터 광맥: `depositKind`(surface/vein/deep), `discoveryTier`(0~5), `accessDepth`, `initialReserveU`, `gradeProbabilities`. 섹터 환경: `terrainObstacle`, `surfaceType`, 대기 메모.
- 시작 지식: `initialResourceKnowledge`(`detectedFraction`, `confirmedFraction`, `gradeConfidence`, `estimatedGradeProbabilities`, `tiers`). 예: 지구 표층·광맥 0.9/0.7, 달 0.3/0.15, 화성 0.2/0.1. **이 값은 하한으로 유지**하고 탐사는 올리기만 한다.
- 수소원: 각 천체의 `hydrogenSources`(현재 지구 2개, 달·화성 0개). 데이터에 있는 곳만 대상.

### 3.2 탐사 능력 단계 [임시, 연구 연결은 M4]
- `surveyCapability = { revealTier: 2, veinConfirmCap: 0.6, deepEnabled: false, speedMultiplier: 1 }`를 데이터로 둔다.
  - `discoveryTier ≤ revealTier`인 광맥만 탐사로 드러난다. 그보다 높은 광맥(대부분의 심부, 일부 표층 t3 등)은 **존재 자체를 드러내지 않는다**.
  - **표층:** 정밀 100%에서 확정(확인 비율 1).
  - **광맥:** 정밀 100%에서도 확인 비율은 `veinConfirmCap`까지, 예측 범위도 0까지 좁혀지지 않고 남는다(§3.4).
  - **심부:** `deepEnabled=false`면 공개하지 않음.
- 채굴 정책 `INDUSTRY_POLICY.maximumDiscoveryTier`(현재 1)·`maximumDepth`(25)는 **바꾸지 않는다**. 탐사로 보여도 채굴 정책 밖이면 채굴 불가로 표시한다.

### 3.3 진행과 시간
- 진행은 **게임 시간 적분**: `진행 += 경과 × 속도`. 고배속에서도 완료 시각을 프레임과 무관하게 정확히 처리(M1a 시계 규칙).
- **대략 탐사**(천체 단위 진행 0→1):
  - 기본 소요 = `sqrt(섹터 수) × 1일` × 천체 난이도 [임시]. 참고: 달·화성(42) 약 6.5일, 지구·금성(92) 약 9.6일, 천왕성·해왕성(252) 약 15.9일, 목성(642) 약 25일.
  - 함선이 그 천체 **행성권 안**에 있으면 진행. 밖으로 나가면 정지(진행 유지).
- **정밀 탐사**(섹터 단위 진행 0→1):
  - 기본 소요 = **섹터당 4일** × 섹터 난이도 × 기술 배율 × (그 천체 대략 탐사 미완료 시 **1.25** [임시]).
  - 섹터 난이도 [임시] = `1 + terrainObstacle`, 두꺼운 대기·가스 행성 추가 배율은 데이터로(기본 1, 보고).
  - 함선이 **그 섹터에 붙은 저궤도 모서리 점**(M1b 궤도점)에 정지해 있을 때 진행. 이동 중·다른 층에서는 정지.
- **협업:** 같은 섹터(또는 같은 천체 대략 탐사)에 있는 탐사함들의 **속도를 더한다**(2척 = 2배).
- 대상 함선은 **탐사함만**. 건설지원함은 탐사 명령 거부.
- 진행 기록은 섹터별 **누적 작업량 절대값**으로 저장해 이후 기술 배율이 바뀌어도 이미 한 일이 줄거나 늘지 않게 한다.

### 3.4 예측 범위 (단조 수렴)
- 광맥마다 결정적 시드로 `u ∈ (0,1)`을 하나 정한다(세계 시드+광맥 ID).
- 진행 `p`(그 광맥 기준 유효 진행)에서 폭 `w(p) = w0 × (1 − p)` [임시 w0 = 1.5].
  - 표시 범위 = `[T × max(0, 1 − u·w), T × (1 + (1 − u)·w)]` (T = 실제 매장량).
  - **항상 실제값을 포함**하고, `p`가 커질수록 **좁아지기만** 한다(넓어지거나 튀지 않음).
  - 광맥은 `p`의 상한을 `veinConfirmCap`으로 잘라 최종 범위가 남는다.
- **확인량(채굴 가능):** `confirmedFraction = max(시작 값, 상한 × p)`. 확인량 = `T × confirmedFraction`.
- **품질:** 추정 확률 = 천체 평균 사전분포 × (1 − g) + 실제 `gradeProbabilities` × g, `g = gradeConfidence`가 `p`에 따라 시작 값에서 상한(표층 1, 광맥 `veinConfirmCap`)까지 상승.
- **빈 섹터:** 드러날 광맥이 없으면 범위 `[0, Z × (1 − p)]`(Z = 천체 평균 섹터 매장량 [임시]), 정밀 100%에서 **'확인된 0'**(기존 `confirmed-zero` 상태 사용).
- **대략 탐사 결과:** 천체 전체 `detectedFraction` 상승(상한 [임시]), 섹터별 **가능성 등급**(높음/보통/낮음/거의 없음) = 넓은 범위의 중앙값 기준. 정밀 탐사 전에도 볼 수 있는 우선순위 지도.
- **수소원:** 그 섹터 정밀 진행이 일정 이상(예: 0.5 [임시])이면 존재 공개, 1에서 확정. 대략 탐사는 '수소원 가능성 있음'까지만.

### 3.5 대기열·전체 스캔
- **섹터 지정:** 여러 섹터를 대기열에 넣으면 탐사함이 M1b 궤도 그래프(추진/자동 방식 선택)로 다음 섹터의 저궤도 점으로 **자동 이동**해 조사한다.
- **전체 정밀 스캔 버튼:** 그 천체의 미완료 섹터 전부를 대기열에 넣는다. 순서 = 대략 탐사 가능성 등급 높은 순 → 가까운 순.
- **여러 척:** 같은 천체 대기열을 공유하면 각 함선이 **가장 가까운 미배정 섹터**를 가져간다. 남은 섹터가 함선 수보다 적으면 같은 섹터에 합류(협업 속도).
- 이동 명령을 내리면 탐사는 멈추고 진행은 보존. 다시 탐사 명령 시 이어서.
- 대기열 완료·섹터 완료 시 알림(toast), 도착 자동 일시정지와 같은 방식의 '탐사 완료 시 일시정지' 옵션(기본 꺼짐).

### 3.6 산업 연결
- 정부 산업의 채굴 가능 광맥/확인량 계산이 **탐사 결과(새 확인 비율)를 읽도록** 연결한다. 현재 `depositKnowledge` 덮어쓰기는 개발 픽스처 전용 검증이므로, 탐사 지식은 **별도 런타임 지식 층**으로 두고 산업 조회가 `max(시작 지식, 탐사 지식)`을 쓰게 한다. 기존 픽스처 동작은 그대로.
- 수소원도 탐사로 확정되면 `hydrogenKnowledge`와 같은 의미로 산업에서 인지되게 한다(같은 방식의 별도 층).
- **플레이어 화면은 실제값을 절대 노출하지 않는다.** 개발자 모드의 실제값 패널은 기존대로 개발자 전용.

## 4. UI

1. **함선 하단 버튼의 돋보기 = 탐사.** 탐사함 선택 시 활성. 누르면 작은 메뉴:
   - **대략 탐사**(현재 행성권 천체)
   - **정밀: 섹터 지정** → 섹터 선택 모드
   - **정밀: 전체 스캔**
2. **섹터 선택 모드:** 표면/저궤도 단계에서 섹터를 눌러 여러 개 선택(다시 누르면 해제) → 확인. 뒤로가기 = 취소. PC는 클릭, `C` 취소.
3. **탐사 상태 겹쳐보기:** 표면 섹터 색 = 미탐사 / 대략(가능성 등급) / 정밀 진행 중(진행률) / 완료 / 확인된 0. 기존 상단 `지도 모드`의 **'탐사 섹터'** 모드와 표면 분포 보기 체계에 맞춰 넣고, 중복 메뉴를 만들지 않는다.
4. **섹터 정보 패널:** 광석 확인량, **추정 총량 범위**, 품질 확률 막대, 수소원 상태, 진행률·남은 시간(현재 함선·배속 기준), 채굴 가능 여부(채굴 정책 밖이면 사유).
5. **함선 정보:** 상태에 `대략 탐사 · 지구 · 43%`, `정밀 탐사 · 달 섹터 12 · 2/8` 등.
6. 모바일 가로·세로, PC 모두. 기존 표면 지도 버튼·산업 패널 동작 유지.

## 6. 자동 테스트

1. 시간: 대략 `sqrt(섹터 수)일`, 정밀 섹터당 4일 × 난이도, 대략 미완료 1.25배, 협업 속도 합산, 탐사함 외 거부.
2. 위치 조건: 대략 = 행성권 안에서만 진행, 정밀 = 해당 섹터에 붙은 저궤도 점 정지 시에만 진행, 이동 중 정지·진행 보존.
3. 예측 범위: 항상 실제값 포함, `p` 증가 시 단조 축소, 결정적 시드, 광맥 상한에서 범위 잔존, 표층 100% 확정, 빈 섹터 → 확인된 0.
4. 공개 단계: `discoveryTier > revealTier` 광맥과 심부는 어떤 플레이어 조회에도 안 나옴(존재·범위·개수 모두).
5. 시작 지식 하한 유지(지구 0.9/0.7 등이 탐사로 내려가지 않음).
6. 대기열·전체 스캔: 순서(가능성 → 거리), 두 척 자동 분배, 남은 섹터 < 함선 수 → 합류, 중단·재개.
7. 산업 연결: 정밀 탐사 후 확인량 증가가 채굴 가능량에 반영, 채굴 정책(`maximumDiscoveryTier`·`maximumDepth`) 밖은 여전히 채굴 불가, 픽스처 기존 결과 불변.
8. 고배속 결정성: 같은 게임 시간을 1프레임/여러 프레임으로 진행해도 진행·완료 시각 동일.
9. 기존 전체 테스트·경제 시뮬 결정성·공식 산출물 바이트 불변.
